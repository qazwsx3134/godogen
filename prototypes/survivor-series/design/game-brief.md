# 行人反擊：既有原型摘要

手機直式夜市割草遊戲。保留十分鐘一局、自動攻擊、武器與融合、局外成長、像素素材與可編輯 Godot 場景。

設計與操作細節以 [README](../README.md) 及其連結的既有規格為準。

## 本輪建置順序

1. Godot 4.7 匯入與既有測試，建立可重跑的 CPU 微基準。
2. 依 [Studio quick spec](quick-specs/studio-polish-2026-10-16.md) 實作同等行為的效能改善。
3. 回歸存檔／戰鬥與場景，保留原生畫面與可比的量測紀錄。
4. 真機輸入、GPU 幀時間與真人試玩另由裝置驗收；不以 headless 數字代替。
