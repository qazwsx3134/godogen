# 第二輪可玩性：擊殺成長與攻擊變化

> 2026-10-07 起由 [horde-spec.md](horde-spec.md) 取代（10 分鐘割草版）。本文件保留為 90 秒測試場的歷史紀錄。

2026-10-07，使用者試玩後回覆「初步還可以 繼續做」。這輪落實前次已確定的後續方向：其他攻擊模式透過升級加入。仍使用 90 秒、不死計次、手機單指移動的測試場。

```text
致命揍飛 → EXP → 升級三選一（暫停） → 新招式／強化 → 繼續戰鬥
                         │
                         └─ 多次升級逐次選；最後一幀結算優先
```

## 成長

抽菸者、機車、汽車分別給 1、2、3 EXP，擊殺時直接取得。Lv.1→2 需 5 EXP，每下一級增加 3，剩餘經驗保留。數值與升級卡用 Resource 編輯，一局的選擇不寫回共享資料。

第一輪固定提供「衝擊波／回旋踢／橫掃拳」，讓第一次成長就改變攻擊方式。之後隨機給最多三個互異、未達上限、符合前置條件的選項；最多三個不代表必須捏造已滿級卡來湊數。沒有合法選項時直接繼續。

玩家選卡時敵人、煙霧、投射物與遊戲計時暫停，釋放原有觸控，選完需重新拖曳。不能透過快速雙點選兩張；有多個待選升級時逐次顯示。結算與重試清空所有局內成長。

## 攻擊

- 基礎拳擊繼續自動找附近敵人。橫掃拳增加同次攻擊的前方目標數，上限三個；重拳每第三拳增傷。
- 衝擊波每第二拳向出拳方向發射，可穿過多個敵人，每個投射物對同一敵人只命中一次；以移動線段檢查命中，避免快移動穿透判定。
- 回旋踢每第四拳命中周圍敵人；只有實際存活目標參與傷害。招式強化卡需先解鎖對應招式。
- 同一拳的多個命中結算完才開升級畫面。致命擊飛依舊是死亡後的演出，不變成連鎖傷害來源。
- 連續揍飛顯示短時間連殺與最高連殺，不作另一套資源條。音效與畫面仍受數量與播放間隔上限約束。

## 本輪視覺與流程

主角以獨立 Motion node 做走路起伏，Visual 做出拳位移，兩者不覆蓋彼此或角色物理位置。新增可編輯的攻擊弧線、回旋踢圓環、衝擊波、升級卡 item 與升級面板。敵群做有限的重量分離，機車預警／衝刺時不被分離運算推離已顯示路線。

HUD 增加等級、經驗、連續揍飛與已選招式摘要，結算列出本局 Build。圖片繼續使用佔位，既有 opt image 選擇保持有效，這輪沒有生成 AI 美術。

## 驗收

第一輪能看到三種不同招式；選擇會實際改變傷害或攻擊模式。滿級、前置、互異、經驗溢出、雙點、連續選擇、選卡暫停、失焦、最後一幀與重試有驗證。手機真觸控能選卡，再次拖曳正常；一局能從 Lv.1 成長並在 90 秒結算。既有場景與共用 kit 保持可編輯與一致。
