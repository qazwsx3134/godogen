# 美術方向：像素風夜市

更新：2026-10-07。依使用者畫好的參考圖 [reference/art-direction-night-market.png](reference/art-direction-night-market.png) 與文字說明訂定。圖片提示詞見 [opt-image-prompts.md](opt-image-prompts.md)。

## 方向

- 保留像素遊戲的製作效率。
- 角色比傳統像素更容易辨認：略大頭的 Q 版比例、深色輪廓、清楚的色塊與剪影。
- 台灣夜市、騎樓、機車與煙霧都能融入場景。
- 男生厭世、女生冷酷，用表情和動作直接表現。
- 適合手機直式畫面與倖存者類的大量敵人。

## 兩位主角（開局二選一）

一局只操控一位，選擇記在存檔（`hero`），下次開選單會停在上次的選擇。外觀由 `scenes/player.tscn` 的 `BodyMan`／`BodyWoman` 呈現，起手武器、數值與揮擊手感由 `data/heroes/*.tres`（HeroDef）決定。

| | 男：厭世西裝 | 女：冷酷外套 |
|---|---|---|
| 外型 | 頭稍大、肩膀下垂、黑髮往後梳；深藍西裝配醒目的紅領帶 | 酒紅髮、黑短外套、淺藍衣服與白靴；眼睛用簡單銳利的線條，避免甜美可愛型 |
| 待機 | 微駝（BodyMan 微傾） | 站姿挺直 |
| 攻擊 | 突然大幅揮動：揮擊距離 38、揮完回彈（`swing_overshoot`）——「平常很累，打起來很兇」的反差 | 動作乾脆：揮擊距離 22、不回彈 |
| 起手武器 | 拳頭（參考圖：大弧線揮擊） | 衝擊波（參考圖：掌勁漣漪） |
| 數值（提案，待試玩調整） | 血量 ×1.1、移速 ×0.95 | 血量 ×0.9、移速 ×1.08 |

男女的差異靠起手武器、血量與移速、揮擊手感，不改成長系統：兩人共用同一組卡片、進化與商店。起手是衝擊波時，拳頭仍在卡池裡，可以升級時取得。

## 敵人與場景

- **抽菸者**：被自己的煙吞噬的黑紫煙團，紅色發光雙眼，帶一點菸頭火光。玩法不變（留煙霧、數量最多的雜兵）；現在的 scene 先用黑色幾何加紅眼代替，等像素圖換上。
- **機車、汽車、臭臭胖子**：沿用既有玩法。機車也是場景道具：街區邊緣停一排深色機車。
- **街區**：軸對齊的矩形，邊緣是騎樓攤位的紅白條紋遮陽棚、紅燈籠與串燈、盆栽、紅白交通錐、黃黑色警示柱；地磚帶燈光倒影的暖灰褐色，中央低對比、不放障礙。參考圖裡街道是斜向的等角視角；原型維持軸對齊矩形，因為敵人生成、邊界、預警線與格子都以矩形座標運作，改成斜向要重做這些。
- **配色**：暖色燈籠（橘紅）對冷色暗地面；主角（深藍西裝、酒紅髮）與敵人（黑紫＋紅眼）色相要分得開，敵海裡仍看得到自己。

## 畫面與視角

用斜俯視 sprite，不建 3D 模型。主角與一般敵人各一張，左右靠水平鏡像；只有機車、汽車做 5 方向＋鏡像。動作由程式的位移、縮放與擠壓補，需要時再加單一方向的 2～4 格走路循環（逐格 PNG，不用 GIF）。素材共 14 張。

2D 斜俯視、近似正交，約 50 度；角色高約 80～100 px。像素放大一律最近鄰，專案預設貼圖過濾是 Nearest（`project.godot`）。
