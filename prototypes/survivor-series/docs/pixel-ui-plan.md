## 2. 核心規則：像素格怎麼統一

- 鏡頭維持 `zoom` 0.72。每個 Sprite2D 的 `scale = P ÷ zoom`（P＝2，等於 2.778），貼圖換成像素版。
- **大小不變**：像素版的尺寸＝「現在在畫面上的高度 ÷ P」，所以碰撞半徑、陰影、血條位置、gameplay 數字都不用動。

| 物件 | 現在畫面上的世界高度 | 像素版目標（P=2） |
|---|---|---|
| 男／女主角 | 90 | 約 32 px 高 |
| 流氓／臭臭胖子 | 80／84 | 約 29／30 px |
| 機車／汽車 | 92／144 | 約 33／52 px |
| 攤位／燈籠柱 | 202／173 | 約 73／62 px |
| 停放機車／花台／護柱 | 88／64／52 | 約 32／23／19 px |
| 三角錐／水果箱 | 32／32 | 約 12／12 px |
| 地磚 | 512 一塊 | 184 px 一塊（仍需無縫） |
| 寶石／金幣／寶箱 | 18／20／30 | 約 7／8／11 px |
| 介面圖示（武器格、選卡） | — | 24 px，顯示成 48 px |

- 換算：像素版高度 ≈ 世界高度 × zoom ÷ P ＝ 世界高度 × 0.36。
- 平滑圖形維持平滑（PokéSurvivor 也是）：腳底陰影、光環、預警範圍、煙霧、衝擊波、套圈圈。
- 手機螢幕寬度通常不是 540 的整數倍，像素會差一點點大小；PokéSurvivor 也接受這個。不開整數縮放（會出現黑邊）。

## 3. 分階段

```

                           │
```

P1 和 P3 互不相依，可以同時做。P2 的生圖可以跟 P3～P6 同時進行，重畫好的角色直接替換 P1 的自動縮小版。

### P1 像素工具與換圖

1. 新增 `tools/pixelize.py`（可重跑）。流程依 TODO 已試做的做法：面積平均縮到目標高度 → 量化到約 32 色 → alpha 門檻（無半透明邊）→ 外加 1 px 深色描邊。
   - 參數：一張表列出每張圖的目標高度（就是第 2 節的表）。
   - 原圖留在 `assets/art/`；像素版輸出到 `assets/pixel/`（同樣的子資料夾）。
   - 地磚另外處理：縮到 184 px 後再跑一次無縫檢查（`extract_terrain_tiles.py --edge-policy seamless --strict-qc`）。
2. 新增一次性的 `tools/build_pixel_scenes.gd`：把所有場景裡的貼圖換成像素版、`scale` 改成 P ÷ zoom。它改動的場景包括：
   - 道具（`scenes/props/*`）
   - 角色（`player`、`smoker`、`fatty`、`bike`、`car`）
   - 掉落物（`pickup`）
   - 投射物（`slipper`、`pearl`、`firecracker`、`incense`、`lantern`、`cane`）

   比照 `build_feedback_scenes.gd` 的寫法，跑完以場景為準。
   - P 和 zoom 寫在工具開頭的常數；之後改鏡頭距離要重跑。
   - 交通工具的 `direction_textures` 也換成像素版 5 方向。
3. 驗收：
   - 產出對照圖 `art_src/pixel-style/p1-before-after.png`。
   - 用 `capture.sh` 錄一段，跟改版前同一個 seed、同一個時間點各截一張。
   - 測試全過；碰撞與數值完全沒改，所以 `growth` 的數字應該不變。

### P3 字型與主題

1. **字型**：俐方體 11 號（Cubic 11，OFL）。
   - 記錄來源、版本與授權到 `assets/fonts/`，用 `subset_font.py` 做子集，確認「source font lacks: none」。
   - 匯入設定：`antialiasing` 關、`hinting` 無、`subpixel_positioning` 關；字級只用 11 的倍數。
   - 22：一般內文（1 字型 px＝2 畫面 px，跟 P 一致）
   - 33：數字與標題
   - 44：大標
   - 11：只用在最小的註記
   - 數字容易看錯的話，在主題裡把計時與傷害數字改用 33。
2. **面板貼圖**：新增 `tools/make_ui_frames.py`，用程式畫出幾張小 PNG，已經放大成 2×，輸出到 `assets/ui/`：
   - 雙框盒子
   - 按鈕（一般／按下／停用，底下 4 px 厚度）
   - 主要按鈕
   - 卡片
   - 進度條底與填色
   - 武器格（一般／選中）

   照 D2 的配色，參考 PokéSurvivor 的雙框結構：外圈深色、白或金 3 px、內框淡色，圓角用階梯狀像素轉角。
3. **主題**：改寫 `data/ui_theme.tres`，StyleBoxFlat 換成 StyleBoxTexture（9-slice）。
   - 改的類型：Panel、Button（normal／hover／pressed／disabled／focus）、ProgressBar、CheckButton。
   - 另外用 theme type variation 做 `PrimaryButton`、`GlassCard`、`TagPill`。
   - 文字：白字加 2 px 深色硬陰影（`shadow_offset` 2,2、`shadow_outline_size` 0）。
4. **稀有度／種類色**（選卡標籤用）：
   - 新武器：藍 `#4fb4ff`
   - 升級：灰藍 `#9fb1c9`
   - 被動：綠 `#5fe08a`
   - 進化：紫 `#c47bff`
   - 隱藏融合：金 `#ffcb3d`
   - 補給：白

## 5. 風險

- **自動縮小臉會糊**（`art_src/pixel-style/auto-downscale-compare.png` 已看到）：所以角色要重畫，自動縮小版只是過渡。
- **非整數縮放**：手機上像素會有 1 device px 的大小差，可接受；真的很明顯再考慮 `snap_2d_transforms_to_pixel`。
- **俐方體缺字**：子集工具會報缺字；缺的字改寫法，或那幾個標籤改用 Noto。
- **9-slice 貼圖在不同尺寸的按鈕上**：轉角要留在 `texture_margin` 外，不然會被拉伸；P3 做完先在編輯器拉幾種尺寸看。
- **畫面變小變暗**：像素字 22 px 在小手機上的可讀性要在 P7 的三種尺寸確認。
