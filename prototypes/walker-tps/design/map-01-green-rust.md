# 首張地圖提案：綠鏽戰線

日期：2026-11-10。狀態：地形初版已實作並設為預設入口；以下任務、AI 與戰鬥規劃仍為提案。

已實作：240 × 220 m 起伏地形、中央凹路、西側高地、東側廠房、斷橋、14 組殘牆、10 台長草裝甲殘骸、30 區草叢，以及越界返回出生點。入口 `scenes/battlefield.tscn`，細節見 README。

**使用者指定方向：世界大戰結束一段時間後的殘破地形，戰爭殘骸上長出雜草。** 建議具體化為被植被逐步覆蓋的工業交通樞紐；戰爭的輪廓仍清楚，大自然已重新長進裂縫與機械內部。地名、時間、尺寸與任務規則均可調整，尚非定案。

## 氣氛與畫面

建議以虛構世界的大戰結束約 20–30 年後作美術時間感，不綁定真實戰爭或特定年代。主角仍是現有四足機甲。

- **遠景：** 斷裂高架橋、工廠空殼與傾斜煙囪，形成一眼可辨的輪廓；遠方山坡逐漸轉綠。
- **中景：** 鏽蝕車體、傾倒貨車、破碎混凝土護牆、被炸斷的道路，夾雜灌木與矮樹。
- **近景：** 草從履帶、機甲關節、車殼破洞積土與柏油裂縫冒出；水線留下暗苔，裸露鋼板有掉漆與鏽痕。
- **配色：** 灰褐混凝土、暗鏽橘、褪色軍綠，搭配低飽和草綠；讓活動敵機的輪廓與提示容易分辨。
- **光線：** 陰天間隙的柔和斜光、薄霧、潮濕暗面，保留足夠對比辨認地形。老殘骸以冷卻、沉寂的狀態呈現；新戰鬥產生的煙火另有視覺語意。
- **聲音：** 風穿過鐵架、稀疏鳥聲、草葉聲與偶爾的金屬晃動；開火與腳步能明顯打破寂靜。

植被按積土、濕氣與遮蔽分布：裂縫長草、車體凹槽長灌木、陰濕面長苔；乾燥金屬表面保留鏽。主通道草較矮、兩側較密，讓玩家從植被分布讀到道路。主砲視線與弱點附近避免密集草葉。

## 玩法與範圍

第一張圖主要驗證三件事：掩護前進是否有用、側擊是否比正面硬打有利、四足機甲能否順暢通過破損地形。

以單機對 AI 為暫定提案：玩家奪回一座廢棄中繼站，scout 在周邊巡邏與反擊。先做到 1 對 1，再增加到同時最多 3 台敵機；不需要先造三種新模型。若後續選 PvP，出生區、左右優勢與佔領規則必須重新驗證。

| 項目 | 灰盒起始值／原則 |
|---|---|
| 可玩範圍 | 約 240 × 220 m；外圍遠景只補深度，不增加可走面積 |
| 第一場長度 | 目標 5–8 分鐘；以實際路程、敵人與佔領時間調整 |
| 任務 | 一個中央據點；先定義敵我爭奪時暫停進度、玩家毀損失敗與重試，再調整佔領／守備時長 |
| 路線 | 三條互通路線，每條有不同射界與掩護；避免一條路包辦所有優點 |
| 道路淨寬 | 常用通道先取 6–8 m，依 4.16 m 機體與鏡頭掃掠驗證；不拿 2.2 m 膠囊當道路標準 |
| 掩護間距 | 先取 15–25 m；以現有衝刺 6.5 m/s 約需 2.3–3.8 s 穿越，未計加速與障礙 |
| 射界 | 常見交戰約 40–90 m，少量 100–140 m 長射線；手機上需驗證敵機及部位辨識 |
| 高差 | 可走路線以平緩坡與約 3–6 m 起伏開始；常用坡先控制在 25° 內，保留調整餘裕 |
| 掩體高度 | 低矮殘骸只能遮部分部位；完整掩護以實際 3.15 m 機體與砲口視線量測，高度先取 3.5–4.5 m |
| 出生區 | 有實體土堤或建物遮擋，進入交戰路線後才暴露；不依賴草叢保護出生點 |

上表為試作初值，並非已量測的平衡結果。大地圖尺寸不能從 War Thunder 直接照搬：現有最高速度 6.5 m/s，跑 1 km 即使全速直線也需約 154 秒，還未計轉彎、交戰與障礙。

## 配置草圖

```text
                           北
                 [敵方入口：斷牆後方]
                     /          \
          [西側鐵路高地]------[東側廠房殘牆]
                |       \      /       |
          遠射／暴露       [B 中繼站]   近距／側擊
                |       /      \       |
          [斷橋土坡]----[凹陷道路]----[長草排水道]
                \          |          /
                 [玩家入口：土堤後方]
                           南
```

- **西路／鐵路高地：** 利用鐵路路基與翻覆車廂遠射，能看部分中央據點；車側較暴露，中央土坡遮住近距離死角，東路能繞側。坡頂不要看穿整張圖。
- **中路／凹陷道路：** 最直接通往中繼站；大型殘骸將長射線切成數段，玩家能換掩體，但開闊路口會受側面壓力。據點旁必須有可退回的掩體。
- **東路／廠房與排水道：** 用破牆、乾涸排水溝與草覆瓦礫提供側擊機會。最窄處仍能完整容納機體與鏡頭，殘牆提供真正遮擋；草僅補時間感與柔化邊緣。
- **跨線連接：** 至少在南段與中央各有換線口。每個優勢射擊位置都有離開與反制路線，不讓單一高地控制出生點。

## 地形、碰撞與視認規則

1. **完整掩體、半身掩體、裝飾物要能看出差異。** 大型殘骸與斷牆阻擋移動／砲彈；小碎屑與草不形成看不見的阻力。第一版採固定掩體，避免可破壞場景同時增加導航與效能變數。
2. **行走表面連續。** 破碎路面以少量平順碰撞面表達；視覺碎石覆在其上。彈坑邊緣留緩坡，避免每塊碎磚都影響 IK 與移動。
3. **腳只採樣有效承重表面。** 現有 `_ground()` 從腳上方 3 m 往下射線且只排除自身；未命中時還會回傳身體高度。正式地圖需要承重遮罩、表面法線與探地失敗的明確處理，避免踩到懸空樑板或裝飾物。
4. **邊界按跳躍能力設計。** 目前約 2.56 m 跳高能越過 2 m 外牆；正式地圖以不可通行地形／明確邊界配合越界恢復，不讓玩家永遠下墜。
5. **草的視覺遮蔽與 AI 感知一致。** 第一版讓矮草負責美術，實體掩體負責遮擋；若日後高草提供隱蔽，就需另訂雙方一致的發現規則。低畫質不能移除影響戰術的遮蔽物。
6. **手機優先保留目標可讀性。** 擊中區、敵我標示、砲口和據點提示不能被裝飾淹沒。煙與飛屑須有密度上限；草不能在瞄準鏡前閃爍成一片。

|---|---|---|

| 工業廢墟 | 6 個可重組零件：斷牆、角牆、立柱、樑、破地板、土坡／瓦礫堆 | 組成工廠、據點與路口遮擋 |
| 戰爭殘骸 | 2 種輪廓 × 2 種擺放；可先用現有 Walker 的靜態倒伏版本與車廂灰盒 | 遠近區分，殘骸不啟動步態或控制腳本 |
| 植被 | 3 種草叢、2 種灌木、1 種藤蔓／苔覆片 | 依地形群聚；先少量驗證，再擴密度 |
| 地標 | 1 段斷橋、1 個煙囪或水塔輪廓 | 導航與遠景定位 |

## Godot 落地方式

保留現有 `arena.tscn` 作移動測試場，另存可編輯的首圖場景。建議場景樹如下；實際場景已有 Terrain、Ruins、Wrecks、BrokenViaduct、Factory、Vegetation、RouteMarkers；下圖中的 Navigation 與 Objectives 是後續規劃。

```text
Map01GreenRust (Node3D / map_01_green_rust.tscn)
├─ Terrain            地表與簡化承重碰撞
├─ RoutesAndCover     斷牆、土坡、車廂等實體掩護
├─ Navigation         配合機甲體積烘焙的導航區
├─ SpawnPoints        玩家／敵人出生標記
├─ Objectives         中繼站與任務區域
├─ SetDressing        靜態殘骸、草、灌木、碎片
└─ Landmarks          斷橋、工廠輪廓與遠景
```

主要掩體與重複道具做成小 scene。用 Godot 保存與檢查 owner／instance 關係；正常執行不重新生成場景。照 repo 規則，只有內容與行為留腳本，場景位置、材質、燈光和裝飾可在編輯器直接調整。

效能先從節制的可見數量開始：分區的重複草叢實例、距離淡出與低細節版本、有限陰影、靜態遠景。沿用 Compatibility；先在指定手機量測，再決定草密度與同屏敵人數，不能使用 xvfb FPS 作為手機證據。

## 驗收順序

```text
路線灰盒 → 機體／鏡頭／AI走通 → 射界與任務能打完
                                           ↓
                          局部美術樣板 → 手機測量 → 擴全圖
```

- 灰盒：三條路都能通行，至少兩處換線口；鏡頭不穿牆、腳不假踩懸空板；越界能恢復。
- 交戰：中央點至少有兩個攻擊方向，每處強勢位置有反制路線；出生點不在直接射線上。
- 任務：能勝、能敗、能重試；玩家能說出這次為何選這條路、為何被擊毀。
- 美術：玩家一眼能說出「戰爭已結束多年、植物重新長回來」；近景有積土與鏽層，中景有殘骸，遠景有破碎地標；路線和敵人仍清楚。
- 平台：指定手機完整一局，確認操控、畫面、聲音與交火時效能。通過後才增加植被密度和新場景內容。
