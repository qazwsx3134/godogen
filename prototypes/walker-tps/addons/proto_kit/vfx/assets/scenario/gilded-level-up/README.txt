Gilded Level Up
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: level up

Frames: 24 at 64x80 px, 15 fps, plays once.
Sheet: gilded-level-up.png, 24 columns x 1 rows, no padding.

Files
  gilded-level-up.png            sprite sheet
  frames/              one PNG per frame
  gilded-level-up.gif / @4x.gif preview GIFs
  gilded-level-up.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  gilded-level-up.tres         Godot 4 SpriteFrames. Put it next to gilded-level-up.png at res:// (or edit the path).
  gilded-level-up.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 64x80.

You can use these frames in commercial and non-commercial projects.
