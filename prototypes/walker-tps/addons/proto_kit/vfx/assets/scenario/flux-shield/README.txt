Flux Shield
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: hex shield barrier

Frames: 16 at 64x64 px, 12 fps, seamless loop.
Sheet: flux-shield.png, 16 columns x 1 rows, no padding.

Files
  flux-shield.png            sprite sheet
  frames/              one PNG per frame
  flux-shield.gif / @4x.gif preview GIFs
  flux-shield.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  flux-shield.tres         Godot 4 SpriteFrames. Put it next to flux-shield.png at res:// (or edit the path).
  flux-shield.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 64x64.

You can use these frames in commercial and non-commercial projects.
