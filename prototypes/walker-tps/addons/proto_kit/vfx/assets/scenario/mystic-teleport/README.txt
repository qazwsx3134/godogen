Mystic Teleport
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: teleport blink

Frames: 20 at 48x80 px, 15 fps, plays once.
Sheet: mystic-teleport.png, 20 columns x 1 rows, no padding.

Files
  mystic-teleport.png            sprite sheet
  frames/              one PNG per frame
  mystic-teleport.gif / @4x.gif preview GIFs
  mystic-teleport.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  mystic-teleport.tres         Godot 4 SpriteFrames. Put it next to mystic-teleport.png at res:// (or edit the path).
  mystic-teleport.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 48x80.

You can use these frames in commercial and non-commercial projects.
