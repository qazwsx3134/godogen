Night Aura
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: dark shadow aura

Frames: 16 at 96x112 px, 12 fps, seamless loop.
Sheet: night-aura.png, 16 columns x 1 rows, no padding.

Files
  night-aura.png            sprite sheet
  frames/              one PNG per frame
  night-aura.gif / @4x.gif preview GIFs
  night-aura.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  night-aura.tres         Godot 4 SpriteFrames. Put it next to night-aura.png at res:// (or edit the path).
  night-aura.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 96x112.

You can use these frames in commercial and non-commercial projects.
