Bloom Heal
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: healing with rising crosses

Frames: 20 at 48x64 px, 15 fps, plays once.
Sheet: bloom-heal.png, 20 columns x 1 rows, no padding.

Files
  bloom-heal.png            sprite sheet
  frames/              one PNG per frame
  bloom-heal.gif / @4x.gif preview GIFs
  bloom-heal.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  bloom-heal.tres         Godot 4 SpriteFrames. Put it next to bloom-heal.png at res:// (or edit the path).
  bloom-heal.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 48x64.

You can use these frames in commercial and non-commercial projects.
