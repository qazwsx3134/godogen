Aether Beam
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: blue energy beam

Frames: 16 at 176x48 px, 15 fps, seamless loop.
Sheet: aether-beam.png, 16 columns x 1 rows, no padding.

Files
  aether-beam.png            sprite sheet
  frames/              one PNG per frame
  aether-beam.gif / @4x.gif preview GIFs
  aether-beam.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  aether-beam.tres         Godot 4 SpriteFrames. Put it next to aether-beam.png at res:// (or edit the path).
  aether-beam.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 176x48.

You can use these frames in commercial and non-commercial projects.
