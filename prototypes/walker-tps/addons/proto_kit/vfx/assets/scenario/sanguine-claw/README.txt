Sanguine Claw
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: feral claw scratch blood

Frames: 12 at 64x64 px, 18 fps, plays once.
Sheet: sanguine-claw.png, 12 columns x 1 rows, no padding.

Files
  sanguine-claw.png            sprite sheet
  frames/              one PNG per frame
  sanguine-claw.gif / @4x.gif preview GIFs
  sanguine-claw.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  sanguine-claw.tres         Godot 4 SpriteFrames. Put it next to sanguine-claw.png at res:// (or edit the path).
  sanguine-claw.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 64x64.

You can use these frames in commercial and non-commercial projects.
