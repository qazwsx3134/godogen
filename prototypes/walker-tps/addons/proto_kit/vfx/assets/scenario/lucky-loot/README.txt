Lucky Loot
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: gold coins loot drop

Frames: 24 at 48x64 px, 15 fps, plays once.
Sheet: lucky-loot.png, 24 columns x 1 rows, no padding.

Files
  lucky-loot.png            sprite sheet
  frames/              one PNG per frame
  lucky-loot.gif / @4x.gif preview GIFs
  lucky-loot.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  lucky-loot.tres         Godot 4 SpriteFrames. Put it next to lucky-loot.png at res:// (or edit the path).
  lucky-loot.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 48x64.

You can use these frames in commercial and non-commercial projects.
