Cyclone Dash
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: dash speed lines

Frames: 10 at 64x48 px, 18 fps, plays once.
Sheet: cyclone-dash.png, 10 columns x 1 rows, no padding.

Files
  cyclone-dash.png            sprite sheet
  frames/              one PNG per frame
  cyclone-dash.gif / @4x.gif preview GIFs
  cyclone-dash.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  cyclone-dash.tres         Godot 4 SpriteFrames. Put it next to cyclone-dash.png at res:// (or edit the path).
  cyclone-dash.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 64x48.

You can use these frames in commercial and non-commercial projects.
