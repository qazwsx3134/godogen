Ember Damage Number
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: critical hit damage 999

Frames: 16 at 48x32 px, 15 fps, plays once.
Sheet: ember-damage-number.png, 16 columns x 1 rows, no padding.

Files
  ember-damage-number.png            sprite sheet
  frames/              one PNG per frame
  ember-damage-number.gif / @4x.gif preview GIFs
  ember-damage-number.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  ember-damage-number.tres         Godot 4 SpriteFrames. Put it next to ember-damage-number.png at res:// (or edit the path).
  ember-damage-number.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 48x32.

You can use these frames in commercial and non-commercial projects.
