Ember Projectile
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: fireball projectile

Frames: 8 at 64x32 px, 12 fps, seamless loop.
Sheet: ember-projectile.png, 8 columns x 1 rows, no padding.

Files
  ember-projectile.png            sprite sheet
  frames/              one PNG per frame
  ember-projectile.gif / @4x.gif preview GIFs
  ember-projectile.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  ember-projectile.tres         Godot 4 SpriteFrames. Put it next to ember-projectile.png at res:// (or edit the path).
  ember-projectile.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 64x32.

You can use these frames in commercial and non-commercial projects.
