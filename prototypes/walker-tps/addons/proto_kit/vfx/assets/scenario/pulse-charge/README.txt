Pulse Charge
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: charge up energy

Frames: 16 at 48x48 px, 15 fps, seamless loop.
Sheet: pulse-charge.png, 16 columns x 1 rows, no padding.

Files
  pulse-charge.png            sprite sheet
  frames/              one PNG per frame
  pulse-charge.gif / @4x.gif preview GIFs
  pulse-charge.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  pulse-charge.tres         Godot 4 SpriteFrames. Put it next to pulse-charge.png at res:// (or edit the path).
  pulse-charge.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 48x48.

You can use these frames in commercial and non-commercial projects.
