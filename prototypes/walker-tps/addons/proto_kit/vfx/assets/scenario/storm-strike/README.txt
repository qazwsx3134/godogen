Storm Strike
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: lightning strike from the sky

Frames: 16 at 64x96 px, 18 fps, plays once.
Sheet: storm-strike.png, 16 columns x 1 rows, no padding.

Files
  storm-strike.png            sprite sheet
  frames/              one PNG per frame
  storm-strike.gif / @4x.gif preview GIFs
  storm-strike.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  storm-strike.tres         Godot 4 SpriteFrames. Put it next to storm-strike.png at res:// (or edit the path).
  storm-strike.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 64x96.

You can use these frames in commercial and non-commercial projects.
