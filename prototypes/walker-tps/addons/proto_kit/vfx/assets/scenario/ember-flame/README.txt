Ember Flame
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: campfire

Frames: 12 at 32x48 px, 12 fps, seamless loop.
Sheet: ember-flame.png, 12 columns x 1 rows, no padding.

Files
  ember-flame.png            sprite sheet
  frames/              one PNG per frame
  ember-flame.gif / @4x.gif preview GIFs
  ember-flame.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  ember-flame.tres         Godot 4 SpriteFrames. Put it next to ember-flame.png at res:// (or edit the path).
  ember-flame.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 32x48.

You can use these frames in commercial and non-commercial projects.
