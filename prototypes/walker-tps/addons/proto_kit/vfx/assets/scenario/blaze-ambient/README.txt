Blaze Ambient
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: embers rising

Frames: 24 at 128x96 px, 12 fps, seamless loop.
Sheet: blaze-ambient.png, 24 columns x 1 rows, no padding.

Files
  blaze-ambient.png            sprite sheet
  frames/              one PNG per frame
  blaze-ambient.gif / @4x.gif preview GIFs
  blaze-ambient.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  blaze-ambient.tres         Godot 4 SpriteFrames. Put it next to blaze-ambient.png at res:// (or edit the path).
  blaze-ambient.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 128x96.

You can use these frames in commercial and non-commercial projects.
