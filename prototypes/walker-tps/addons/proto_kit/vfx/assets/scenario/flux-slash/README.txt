Flux Slash
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: triple slash combo with blue energy

Frames: 21 at 64x64 px, 18 fps, plays once.
Sheet: flux-slash.png, 21 columns x 1 rows, no padding.

Files
  flux-slash.png            sprite sheet
  frames/              one PNG per frame
  flux-slash.gif / @4x.gif preview GIFs
  flux-slash.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  flux-slash.tres         Godot 4 SpriteFrames. Put it next to flux-slash.png at res:// (or edit the path).
  flux-slash.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 64x64.

You can use these frames in commercial and non-commercial projects.
