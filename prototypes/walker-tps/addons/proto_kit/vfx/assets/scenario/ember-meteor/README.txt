Ember Meteor
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: meteor strike

Frames: 26 at 96x96 px, 15 fps, plays once.
Sheet: ember-meteor.png, 26 columns x 1 rows, no padding.

Files
  ember-meteor.png            sprite sheet
  frames/              one PNG per frame
  ember-meteor.gif / @4x.gif preview GIFs
  ember-meteor.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  ember-meteor.tres         Godot 4 SpriteFrames. Put it next to ember-meteor.png at res:// (or edit the path).
  ember-meteor.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 96x96.

You can use these frames in commercial and non-commercial projects.
