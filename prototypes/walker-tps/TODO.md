## 下一步（建議順序）

1. [ ] **手機實測（R8）：** 匯出到手機，跑移動測試場（12 台 scout）和 battlefield，記錄 FPS、雙指觸控與 JUMP／BOOST 的手感、背景切換後回來的狀態。目前所有效能數字都來自電腦。
2. [x] **主砲瞄準＋射擊（R1）：**
   - `Turret` 跟著鏡頭繞 Y 軸轉，限制 ±30°，再大會撞到後腿。超過限制時帶動車身原地轉向（評審的建議）。
   - `Cannon` 跟著鏡頭俯仰。
   - 從 `Muzzle` 發射砲彈，檢查整段飛行路徑；近牆開火要打在牆上，不能穿過去。
   - 回饋：裝填、砲口焰、後座力、鏡頭震動、命中特效。
   - 鏡頭看的方向和砲管實際指的方向要分開顯示。
3. [x] **scout 能被打掉（R2 簡化版）：** 血量、受擊閃白、擊毀爆炸。部位損傷（腿、砲、核心）之後再加。
4. [x] **scout 的 AI（R3）：** 巡邏 → 看見玩家 → 找射擊位置 → 開火 → 失去視線後搜索。被牆擋住時不能隔牆射擊。先做 1 對 1，再做 1 對 3。
   - 動畫：目前只有 `walk`、`idle`，還要轉向、開火、死亡。模型在 `docs/86/enemy/scout/`，用 `build_scout.py` 加動畫。
5. [x] **單局流程（R4）：** 一個目標、勝敗結算、一鍵重試，重試時清空砲彈、AI 和損傷狀態。
6. [ ] **手動大幅近戰迴旋：** 自動刀片（短幅扭身＋刀光）已完成；另行手動整圈左右迴旋與獨立刀片動畫仍待做。

## 程式碼檢視（2026-11-11，靜態閱讀，未實作、未跑測試）

每一項的實作方式、程式草稿、驗證方法與建議順序見 [design/code-improvements.md](design/code-improvements.md)。建議順序：A6 → A1 → A3 → A2 與 C5；再 G1 → G2 → G5；再 A7 → A4 → A5 → A8；最後 C4 → C3 → C2 → C1。

敵人 AI（`scripts/scout.gd`）：

- [x] **A1 射擊不預判：** `shoot()` 瞄玩家當下位置，彈速 36 m/s、預警 0.8 秒；玩家橫移就永遠打不中，站著必中。改成解攔截點（彈速、玩家速度），再乘一個可調的誤差係數當難度。（2026-11-12 完成）
- [x] **A2 瞄準時完全不動：** `aim` 狀態只轉身，不移動、不找掩體、不後退。加「開火後換位」：射完往側向或最近掩體移動一段再瞄。（2026-11-12 完成）
- [x] **A3 被打不會警覺：** `apply_damage` 不更新 `last_seen`／`memory`，視野外被打照樣巡邏。受擊時把攻擊來向寫進 `last_seen`。（2026-11-12 完成）
- [x] **A4 沒有協同：** 各自尋路到同一點會擠成一團，一台看到其他台不知道。在 battlefield 放共用資料（最後目擊位置），並依台數分配繞玩家的角度站位；開 NavigationAgent 的 avoidance。（2026-11-12 完成）
- [x] **A5 搜索形同虛設：** `memory` 4 秒在走過去的路上就扣完，搜索速度又用巡邏的 1.6 m/s。改成抵達最後目擊點才開始計時，再看一兩個方向。（2026-11-12 完成）
- [x] **A6 狀態每幀重算、沒有遲滯：** 距離在 `attack_range` 邊界會在 chase／aim 間來回跳並清掉 `charge`。改 enum 狀態＋進出條件分開（例如進 38 m、出 44 m）。（2026-11-12 完成）
- [x] **A7 感知：** 360° 視野、單一射線打玩家中心；每台每幀一次射線。加視角錐、多打一兩個點，並改成每 0.1–0.2 秒錯開檢查（台數多時才有感）。（2026-11-12 完成）
- [x] **A8 輕重型只差 HP 與質量：** 把偏好距離、預判準度、連發數做成 `@export`，兩種敵人才有不同打法。（2026-11-12 完成）
- [ ] **A9 雜項：** 巡邏點沒貼到導航網格（用 `NavigationServer3D.map_get_closest_point`）；死亡後 `set_physics_process(false)`；遊蕩模式與戰鬥模式同一支腳本用旗標切換，拆開或刪掉遊蕩。（2026-11-12 部分：巡邏點貼網格、死亡停 physics 已做；遊蕩模式要改 main.tscn，等 Arena 問題一起處理）
