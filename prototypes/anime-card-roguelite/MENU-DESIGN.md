# 裂界牌局選單與續玩

## 流程

主選單 → 進入遊戲 → 繼續上次進度／新的遊戲。
新遊戲 → 排除流派與種子設定 → 選角色與起始牌 → 開始登塔。
已有當局時，在最後開始步驟確認取代進度；取消仍可續玩原局。

主選單另提供成就、收藏、共鳴／蓄氣教學。成就依實際冒險與收藏解鎖，共九項，角色勝利分開記錄。

## 視覺與操作

使用 game-ui-ux skill：大幅場景配圖、左側集中主選項，子頁一次處理一項決策。參考 [Interface In Game 的 Slay the Spire 選單與角色頁](https://interfaceingame.com/games/slay-the-spire/) 的資訊層級，使用本作自己的構图、標題與素材。

主選單配圖為 `assets/menu/title-rift.png`，生成工具與完整提示詞記於 `assets/menu/generation.json`。左側暗色留白保持文字可讀，右側三名旅人面向裂界之門。角色頁呈現職業特性、固定牌與起始配置。

按鈕有鍵盤焦點；主選單支援上下方向鍵、Home／End，Escape 返回前頁。桌面、手機直向與橫向分別排版，較長設定頁可垂直捲動。

## 流派與固定牌

六種流派可任意勾選排除。混合流派卡命中任何被排除標籤即排除；相關遺物也從商店、事件與菁英獎勵移出。角色固定牌保留，即使它屬於被排除流派。起始組自動補足可用牌，開始時仍驗證十張與候選池至少三張非基礎牌。

個別卡排除與本次流派排除分開追蹤；新的冒險預設不沿用上一局的流派排除。收藏與免費開包不受局內排除限制。

## 保存

使用 save-systems skill。收藏延用 profile.v3；冒險快照與成就使用 campaign.v1，保存完整牌區、亂數、回合特性、敵人、地圖與當前節點。還原時驗證版本與內容，並重新連接當前地圖節點。

每次進度更新寫入本機 localStorage，保留上一份有效備份。讀不到主檔可恢復備份；未知版本或無有效備份時提示使用者，直到明確開始新冒險前不覆寫原資料。結算後清除主檔與備份的續玩狀態，結算次數不重複增加。

僅有一個當局欄位，存檔限同一瀏覽器，沒有雲端同步。儲存失敗會顯示提示，仍可繼續當次頁面。
