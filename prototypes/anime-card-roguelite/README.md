# 裂界牌局

文字為主的單人登塔卡牌原型。選擇角色與職業，沿路用卡牌、遺物和消耗品發展流派；跨宇宙出牌會切換火影、七龍珠、銀魂的介面畫風。

## 開始

在此目錄執行 `npm start`，開啟 <http://localhost:5178>。不需前端套件，也可執行：

```bash
python3 -m http.server 5178 --bind 0.0.0.0
```

1. 選角色，查看職業特性；到起始配置保留兩張固定牌，再選八張自選牌。也可套用通用配方。
2. 開始登塔後選地圖節點，看敵人意圖安排出牌。
3. 不同宇宙交替出牌累積共鳴。已有三點時，可手動強化一張攻擊／格擋牌。
4. 戰利品卡面會說明它如何接上現有牌組；也能拿跨界卡開展另一條流派。
5. 在營火休息／升級、商店購卡／遺物／移除卡，保留生命挑戰首領。

共鳴與蓄力教學可隨時重開。蓄力在卡面稱為「蓄氣」：特定牌累積它，消耗型招式把它轉為傷害；它與跨宇宙接力累積的共鳴分開計算。

## 起始配置與排除

每位角色有兩張固定牌，各保留一份，可升級但不能移除；額外同名副本可移除。其餘八張從收藏中選擇，基礎同名最多五張、其他最多兩張。

排除卡牌會讓該卡不進入本局起始牌、戰利品與商店。若它已在自選起始組，會先移出草稿，補滿十張後再保存或開始。角色固定卡不能排除，至少保留三種非基礎候選卡。開包和指定取卡仍可取得被排除卡的收藏。

切換角色會套用該角色預設組並清空排除；套用配方保留角色固定牌並避開排除。配置只影響新冒險。

## 角色

| 角色／職業 | 生命 | 特性 | 起步方向 |
| --- | ---: | --- | --- |
| 影丸／忍者 | 72 | 每回合第三張攻擊牌後抽1張 | 連擊力量、毒術消耗 |
| 空悟／武鬥家 | 76 | 每回合第一張費用至少2的牌後獲得2蓄氣 | 蓄氣爆發、連擊力量 |
| 銀桑／浪人 | 80 | 每回合第一張格擋牌後額外獲得3格擋 | 格擋反擊、放逐循環 |

職業特性不會因畫風切換而改變；所有角色都能使用全部宇宙的牌。武鬥家需要較多蓄氣時機規劃。

## 構築與道具

目前38張卡、12種遺物、3種戰鬥消耗品，六個可混搭方向：

- 連擊力量：力量提升每一段傷害，低費攻擊能接第三張攻擊收益。
- 毒術消耗：毒針／毒霧施毒，以格擋與弱化等待毒傷，毒華可將既有毒層翻倍。
- 蓄氣爆發：蓄氣上限9、跨回合保留；流星氣功消耗全部蓄氣放大傷害。
- 格擋反擊：格擋保命，木刀盾擊按當前格擋造成傷害，荊棘反傷。
- 放逐循環：灰燼護持讓放逐牌提供格擋，燃燼手札補牌並精簡本場循環。
- 跨界共鳴：交替宇宙或共鳴卡累積資源，強化裂界合擊等攻防雙效果牌。

卡牌與遺物標示流派；地圖和獎勵頁列出當局構築。戰後三張牌分別偏向職業、現有主流派與跨界機會；抽樣依普通／進階／稀有權重3／2／1。所有非基礎牌都能由任何角色取得。局外測試卡包則等機率。

毒霧瓶施加6毒、氣力藥補1能量、護身藥提供12格擋。每角開局帶一瓶，背包最多兩瓶；普通戰40%掉落、菁英必掉，背包滿時改為10金幣。使用不耗能量，也不算出牌或觸發職業特性。毒霧瓶需要點敵人，其餘立即使用。

## 登塔規則

- 每回合3能量、抽5張、手牌上限10；回合結束棄牌，抽牌堆空時洗回棄牌。
- 中立牌不累積也不中斷接力。共鳴上限3、跨回合保留、每場重置；畫風跨節點延續。
- 強化消耗出牌前已有的3共鳴，第一段傷害+4、第一個格擋+4；多段攻擊只加成一次。接力透鏡可將兩者加成提高至6。
- 七層路線每層只選一個節點。初始70金；普通戰+25金、菁英+40金並給遺物。
- 生命跨戰鬥保留。營火可恢復最大生命25%（向上取整），或將一張牌升級一次。
- 商店卡牌50金、遺物100金、移除一張牌60金。事件可用8生命換遺物，或恢復6生命。
- 力量、荊棘、蓄氣與放逐護持在本場持續，下一場重置。格擋在各自下一次行動開始時消失。
- 局內卡牌、升級、遺物和消耗品限本局。收藏決定下局十張起始牌。

## 收藏與保存

全部角色與起始牌免費提供。100測試幣開三張非基礎卡，36種等機率、每抽獨立，可同包重複。基礎牌上限五張，其他兩張；超額每張退20幣。另有免費補幣與指定取卡。

角色選擇、收藏、測試幣、起始牌組、排除清單與結算次數存本機 `rift-cards.profile.v3`。支援v1／v2遷移，保留舊存檔。重新整理不續接當局；儲存被封鎖仍可玩當次頁面。

## 驗證

```bash
npm test
node balance.mjs
```

瀏覽器驗證需要已安裝的 Playwright／Chromium；在repo根目錄執行：

```bash
node prototypes/anime-card-roguelite/browser-check.mjs \
  --playwright /path/to/node_modules/@playwright/test \
  --url http://127.0.0.1:5178
```

截圖位於 `/tmp/rift-character-browser/`。驗證紀錄見 VALIDATION.md，真人試玩流程見 PLAYTEST.md。模擬勝率不代表真人勝率。

本原型隔離在此目錄，不參與 Godogen 發布。現行角色 API 見 CHARACTER-CONTRACT.md；通用登塔規則見 CONTRACT.md。Sprite 演出與後期跨界取得方向記於 [DESIGN-DIRECTION.md](./DESIGN-DIRECTION.md)，尚未實作。
