# 裂界牌局：玩法與演出方向

記錄日期：2026-09-06。以下區分使用者確認的方向、目前原型規則，以及尚待試玩的提案。

## 使用者確認的樂趣

- 選擇一名角色，以其職業、特性與招牌卡開始冒險；不同角色能發展不同流派，卡牌與道具可讓流派產生派生組合。
- 關卡的敵人是不同宇宙的反派或小兵。玩家持續操控所選角色破關，跨宇宙出牌帶來畫風與技能的碰撞。
- 攻擊演出使用 Sprite。例如「新八吐槽」會叫出新八完成吐槽攻擊，讓卡牌效果成為角色表演。
- 角色可以借用其他宇宙的招式，例如銀桑施放龜派氣功。素材與開發方式要能支援更多角色、招式組合。
- 前期獎勵先提供角色的正規成長路線，後期由玩家選擇取得其他宇宙的卡牌及道具。
- 開局可選起始卡牌與排除卡牌；角色固定卡牌不能排除。需要教學說明共鳴與蓄力。

## 起始配置的原型規則

每副起始牌十張：兩張固定招牌卡各一份，加上八張自選牌。固定牌的具體名單是本輪原型選擇，可在試玩後調整。

| 角色 | 固定卡牌 ID | 起步方向 |
| --- | --- | --- |
| 影丸 | `kunai_barrage`、`venom_needle` | 連擊、毒術 |
| 空悟 | `ki_focus`、`meteor_release` | 蓄氣、爆發 |
| 銀桑 | `wooden_guard`、`shield_bash` | 格擋、反擊 |

固定的一份不能從起始組移除，也不能在局內商店刪除；可正常打出、棄置、放逐與升級。額外取得的同名副本仍可移除。排除以卡名為單位，角色固定卡的卡名不能加入排除清單。

排除清單適用於該局起始牌、戰後獎勵和商店卡牌。排除一張已放入起始組的自選牌，會先將它移出配置草稿，玩家須補滿十張才能保存或開局。至少保留三種非基礎卡供戰利品抽選。開包與指定取卡仍可收藏被排除的牌。

起始組與排除清單一起保存；開局後使用獨立快照。切換角色會換成該角色預設組並清空排除；套用配方則保留當前角色固定牌並避開排除項目。

教學中「蓄力」對應目前介面的「蓄氣」資源。共鳴來自跨宇宙接力，蓄氣由特定卡牌與特性產生；兩者的上限、消耗條件和收益分開呈現。

## Sprite 素材與演出提案

建議把演出拆成「角色動作、招式特效、命中效果、文字／聲音」四層，由卡牌指定演出配方。規則先算好結果，演出只呈現結果；加速或略過演出不應改變傷害。

| 範例 | 演出順序 | 可重用素材 |
| --- | --- | --- |
| 新八吐槽 | 新八短暫入場 → 吐槽姿勢與文字框 → 命中字樣／衝擊 → 退場 | 新八入場及吐槽 Sprite、通用文字框、通用漫畫衝擊 |
| 銀桑龜派氣功 | 銀桑施法姿勢 → 手部聚氣 → 光束 → 敵方命中 | 銀桑施法 Sprite、聚氣球、光束、命中特效 |

新八是該次技能的客串演員；演出結束離場，不占持續作戰的隊友位置。銀桑的施法動作可供其他遠程招式重用，龜派氣功特效也可由其他角色的施法錨點發出。

第一批已接入三名角色四格待機、兩類敵人四格待機、新八四格吐槽、光束與命中特效。每格 256×256，2×2 透明圖集；三套橫向背景隨宇宙切換。角色位移與受擊閃光由 CSS 驅動，三名角色的專用攻擊／受擊四格圖集已於 visual-v2 接入；逐招施法與手部發射點校準留待後續。素材規格與原始生成 prompt 位於 assets/visual-v1/。

宇宙畫風可由背景、介面、配色與特效語彙共同改變。保留角色辨識度；先測試共用動作搭配不同宇宙特效，是否已足以表現風格碰撞，再決定是否值得追加每種畫風的角色動畫。

## 後期跨宇宙取得：尚未選定入口

目標節奏是「理解角色正規流派 → 做出跨宇宙選擇 → 用異宇宙卡牌與道具發展混搭」。入口仍未決定，可試比較：

- 路線上的宇宙門：從地圖預先規劃是否跨界。
- 特殊事件：當場評估報酬與代價。
- 首領後選擇：完成一段角色成長後，再挑新的宇宙方向。

尚需決定跨界是否有代價、能否重複選擇、解鎖多久，以及玩家事先自組的跨宇宙起始牌如何與前期正規成長搭配。這些都是待試玩的設計問題。

目前原型仍允許從前期獎勵拿跨宇宙牌；已實作 Sprite 演出，上述解鎖入口仍待設計。現有收藏和起始配置保留自由測試能力，後續確定入口後再調整獎勵進程。
