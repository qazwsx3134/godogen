# 起始配置、排除與教學契約

相關 API 優先於 CHARACTER-CONTRACT.md 與 CONTRACT.md 的舊配置描述。玩法和固定牌名單見 [DESIGN-DIRECTION.md](./DESIGN-DIRECTION.md)。

- `CHARACTERS[].fixedCards`：兩個不同 card ID，每個在起始組至少一張。
- `profile.excludedCards`：卡名 ID 陣列，預設空，沿用 v3 保存。載入舊資料時補上並修復配置。
- `setLoadout(profile, deck, excludedCards = profile.excludedCards || [])`：原子驗證並保存起始十張與排除清單；檢查收藏數量、同名上限、固定牌最低數量、不含排除卡。排除不得含當前角色固定 ID，至少保留三種非基礎候選卡。
- `applyCharacter`：原子切換角色，套用預設組並清空排除。
- `applyPreset`：保留角色固定牌，按配方順序填入自選格，避開排除和持有量限制，必要時補入合法收藏牌。
- `createRun({ deck, seed, characterId = 'shadow_ninja', excludedCards = [] })`：獨立驗證配置與排除，快照清單到冒險。收藏持有數量由 profile 負責。
- 起始組中每種固定 ID 的第一個實例標示 `fixed: true`，其他為 false。升級及戰鬥複製保留標示；商店拒絕移除固定實例，額外同名副本可移除。
- 戰利品和商店抽樣先過濾排除；加入牌組的公開操作也檢查排除。開包和指定取得收藏不受影響。
- 介面保存起始組與排除清單兩份草稿。排除已在自選組的牌會移出所有副本；補滿十張後才能保存或開局。失敗不覆蓋上次有效配置。冒險進行中鎖定配置。
- 教學使用獨立範例，不改實戰。共鳴從忍術起點0，接氣功1、武士2、忍術3；中立牌不打斷。強化須出牌前已有3點，首段傷害與首個格擋各+4（接力透鏡+6）。
- 蓄力即蓄氣，上限9，僅特定招式消耗。無其他加成時，3蓄氣的流星氣功造成8 + 3 × 3 = 17傷害並耗盡；空悟若本回合首次重費特性尚未觸發，結算後才補2。共鳴與蓄氣都跨回合保留、每場重置。
- 敵人提高攻擊的意圖稱「強化攻勢」，與玩家蓄氣分開。

Sprite 與前期正規／後期跨界獎勵依 DESIGN-DIRECTION.md 記錄，尚未實作解鎖入口。
