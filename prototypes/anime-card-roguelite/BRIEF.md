# 裂界牌局：跨宇宙接力原型

本輪設計問題：角色職業特性能否引導玩家做出不同的拿牌與出牌決策，並用戰利品開展可混搭的流派？

## 已確認方向

- 網頁、繁體中文、文字為主，少量 CSS 紋理與回饋。
- 以 Slay the Spire 2 式的單人出牌／登塔構築為核心：三名可選角色、每局一名角色、敵人意圖、分支路線、戰後選牌、營火、商店與遺物。
- 使用者接受跨宇宙接力：打出不同宇宙的牌累積共鳴，再主動選一張牌強化。
- 成功出牌切換火影、七龍珠、銀魂的視覺語彙；規則狀態與畫面主題一致。
- 收藏組成十張起始牌；局內獎勵與升級僅限當局。三名角色都有免費起始牌，也有兩副通用配方。
- 免費測試幣開包、指定取卡均保留，方便測試組合。
- 起始十張由兩張角色固定牌與八張自選牌組成；可排除本局卡牌，固定牌保留。共鳴與蓄力提供分步教學。
- 38種攻擊／技能／能力牌、12種遺物、3種消耗品，七層路線，一局目標 10～20 分鐘，實際時間待真人測量。
- 收藏存本機；支援舊存檔遷移。重新整理不續接當前冒險。

## 視覺原則

火影：卷軸紙、筆刷框、忍術印記。七龍珠：高彩度、粗輪廓、放射線。銀魂：紙感、墨線、漫畫框。這輪用 CSS 與字體呈現視覺方向，完整角色圖與動畫留待玩法驗證。使用者可以從目前宇宙標籤與出牌紀錄確認切換原因。

## 保留／調整標準

- 保留：玩家能自行說明接力觸發原因，在第一至第二場主動改變出牌順序，至少使用一次共鳴強化，並願意試另一副牌。
- 調整：能理解宇宙切換，但換牌順序沒有實際取捨，或畫風變化妨礙閱讀。
- 重新設計接力：提示調整後仍只按能量把牌打完，或為湊共鳴而做明顯無聊的拖延。
- 自動測試驗證規則與流程；模擬勝率僅供比較。趣味、節奏、主題辨識仍需無提示真人試玩。

## 實作範圍

原生 HTML/CSS/ES modules，規則、畫面、收藏分離；固定種子重現。所有程式隔離於本原型目錄，不參與 Godogen runtime 發布。完整 API 與數值見 CHARACTER-CONTRACT.md 與 CONTRACT.md，現行名詞見 CONTEXT.md。

本輪保留標準：玩家能說明所選職業的特性，主動拿一張能延伸現有牌組的戰利品，並願意用另一名角色或第二種流派重玩。三角色／六方向仍屬可拋棄原型，真人趣味結論待試玩。

後續 Sprite 客串攻擊、借用異宇宙招式、前期正規獎勵與後期跨宇宙選擇，記錄於 [DESIGN-DIRECTION.md](./DESIGN-DIRECTION.md)。演出素材方案與跨界入口仍屬提案；目前獎勵從前期即可出現跨宇宙牌。
