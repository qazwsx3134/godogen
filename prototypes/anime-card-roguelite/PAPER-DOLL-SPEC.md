# 裂界牌局：紙娃娃冒險設計稿

日期：2026-09-09。狀態：使用者已確認核心設計，明列的未定事項留待後續內容與實作準備階段收斂。本文描述目標設計，不代表原型已全部實作。

## 核心體驗

玩家以自己的主角開始冒險，帶著一個被動天賦與各流派基礎牌，在三個宇宙區域中取得卡牌與道具，逐步形成當局打法。道具全部持有生效，也能展示在主角身上，讓最終形象呈現這趟冒險的收穫。

主角與主線故事獨立，內容可包含原創設定，以及能讓玩家辨認具體動漫作品的道具與招式。所在區域決定主角與背景的整體畫風。

## 戰鬥版面

版面參考《Slay the Spire 2》：完整橫向戰場、主角在左、敵方在右、手牌在底部。主角與每名敵人的血條、目前／最大生命及格擋數字都出現在各自角色附近；敵人意圖位於頭頂，狀態貼近各自血條。

細節、參考來源與驗收條件見 [戰鬥版面規格](BATTLE-LAYOUT.md)，美術工作範圍見 [素材修改清單](ASSET-MIGRATION.md)。

## 開局與主角

- 可選髮型、髮色、膚色與基本服裝。
- 選一個起始被動天賦，當次冒險中固定。
- 配置十張基礎起始牌；各流派基礎牌先開放，自由混搭，同名最多兩張。
- 進階卡解鎖後進入冒險獎勵池，起始自選仍限基礎牌。
- 開始新冒險消耗一次遊玩機會；續玩同一趟不再次扣除。

## 三區冒險

一趟目標為 15–25 分鐘，包含三個區域，每區有分支節點與區域首領。第一區宇宙隨機，前兩區擊敗首領後由玩家選擇下一個宇宙，第三區首領後直接通關結算。

後續宇宙的候選數、是否允許重複，以及區域節點數尚未確定。

| 來源 | 已確認的取得／調整方式 |
| --- | --- |
| 普通戰鬥 | 三張候選卡擇一，也可跳過 |
| 菁英與區域首領 | 卡牌獎勵之外，額外提供道具三選一 |
| 事件與商店 | 可取得道具，具體內容另行設計 |
| 調整節點 | 刪除一張牌或強化一張牌，二者擇一 |

牌組在冒險中透過取得、刪除與強化改變。局內的牌組調整透過指定節點進行。

## 被動道具與外觀展示

道具放進背包即生效，背包不限數量，同名道具只持有一件，獎勵避開已持有道具。不同道具的搭配與卡牌互相配合，形成流派。

玩家選擇哪些持有道具顯示在主角身上，顯示選擇不影響效果。展示部位分手持、背部、頭部、身體與飾品，同部位可呈現多件。

系統先自動排列；玩家可調整位置、角度與前後順序，並一鍵還原排列。整套外觀配置隨角色動作一起移動。

木刀可採格擋後追加傷害或增加素質等效果方向；確切效果、數值與演出尚未指定。

## 戰鬥效果

- 力量為每段攻擊傷害增加等量數值。例如 3 力量搭配「2 傷害、攻擊三次」，結果為 5 × 3 = 15。
- 每個玩家回合開始時力量減少 1，最低為 0。
- 每個玩家回合開始時清除剩餘格擋；持有保留格擋效果時依該效果保留。
- 力量與格擋每場戰鬥重置。
- 共鳴由可選天賦或道具效果提供，屬於可選構築方向。
- 允許道具互相觸發，同一條連鎖中同一道具最多觸發一次。

結算例：本回合有 3 力量與 12 格擋，敵人消耗 5 格擋。下個玩家回合開始時力量為 2；剩餘 7 格擋預設清除，若有完整保留效果則留下 7。

## 結算與紀錄

依本趟完成的戰鬥與進度給予局外遊戲幣，通關額外加成；敗北仍可取得已完成進度的收益。

冒險紀錄供回顧與分享，保存使用過的牌組與道具。第三區首領後直接通關結算；下一趟重新構築，當局取得的牌組與道具不作為下一趟的起始持有物。

最終造型、續命標記等額外紀錄欄位曾提出，尚未逐項確認。

## 遊玩機會

| 項目 | 規則 |
| --- | --- |
| 初始次數 | 3 次 |
| 持有上限 | 3 次，自然恢復與廣告補充共用 |
| 開局消耗 | 每趟新冒險 1 次 |
| 自然恢復 | 每 60 分鐘 1 次，離線時間計入 |
| 廣告補充 | 一次完成廣告補 1 次；滿額不提供入口 |
| 續玩 | 同一趟不再扣除 |

未滿時持續計時，再次消耗不重置已有恢復進度。滿額停止計時；滿額後再次消耗，從新的恢復週期開始。

## 廣告回溯續命

每趟限一次，須完成廣告。第一關敗北回到第一關開始；其餘回到實際走過的上一節點開始，包含商店與事件。

生命、牌組、道具與局內金幣一起還原至該節點開始時。敵人與獎勵候選保持相同，玩家可改選、改打法，例如重新購買或選擇事件選項。

局外幣依本趟不重複的完成進度計算，重打不重複領取。

廣告未完成不發獎勵，也不消耗續命次數。保留待續命冒險，可稍後重試，或由玩家自行選擇結算。

## 局外解鎖與廣告

基本流派起始牌先開放；可解鎖額外天賦、造型，以及加入冒險獎勵池的新卡與道具。解鎖道具代表之後有機會遇到，取得仍發生在冒險中。

解鎖分玩法池與造型池。只抽尚未解鎖的內容，抽到即永久解鎖。整池解鎖後關閉該池抽取，不扣幣、不要求看廣告；新增內容後重新開放。

已確認廣告入口包括補充遊玩機會、回溯續命與抽包／造型解鎖。遊戲幣也可用於抽取解鎖。各池詳細組成、每包內容數、機率、廣告使用額度與是否另有指定造型解鎖尚待設定。
