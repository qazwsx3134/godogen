# madara-survivor：宇智波斑戰場支配倖存者（手機 2.5D）

狀態：**進行中**。成長系統已接到須佐能乎與地爆天星；美術換成 AI 生成的正式圖（暫定選擇）。

- 設計來源：[docs/naruto/doc/](../../docs/naruto/doc/)，技能成長設計見 [skill-progression.md](../../docs/naruto/skill-progression.md)。
- 渲染底層複製自 [horde-25d 灰盒](../horde-25d/README.md)。

> 火影是集英社的 IP。這個原型只用來驗證手感，不公開發布；商品化前要先處理授權，或換成原創角色。docs/naruto/doc 裡的兩張圖只當參考，不放進遊戲。

## 要驗證的假設

1. **第一關**（doc3）：斑＋體術／團扇＋100 個忍者＋擊飛＋停頓＋擊殺數，這 30 秒會不會讓人想一直砍下去？
2. **成長與爽感**（skill-progression.md）：斑一開局就很強，接下來會長的是招式數量、規模和機制。這樣能不能每 60～90 秒就給一次明顯的躍升？

## 怎麼跑

用 Godot 4.7 開 `prototypes/madara-survivor/project.godot`，按 F5。

| | 移動 | 瞬身 |
|---|---|---|
| 桌面 | WASD 或方向鍵 | 空白鍵；須佐 E、地爆天星 R |
| 手機 | 按住螢幕左側 42% 出現浮動搖桿 | 右下「瞬身」按鈕，可以邊用另一隻手指移動邊按 |

忍術都會自動施放。

```bash
GODOT_BIN=/Applications/Godot.app/Contents/MacOS/Godot bash prototypes/godot-kit/tools/run_tests.sh prototypes/madara-survivor core:60
GODOT_BIN=/Applications/Godot.app/Contents/MacOS/Godot bash prototypes/godot-kit/tools/web/build_web.sh prototypes/madara-survivor
```

QA 參數：命令列寫在 `--` 後面；網頁版寫成網址參數，例如 `?stress=400&learn=fireball:5,gunbai:3`。

| 參數 | 作用 |
|---|---|
| `autoplay` | 自動駕駛 |
| `stress=<n>` | 開局就放 n 個敵人 |
| `seed=<n>` | 固定亂數 |
| `duration=<秒>` | 縮短一局 |
| `pitch=<度>`、`distance=<m>` | 換鏡頭角度與距離 |
| `learn=fireball:5,gunbai:3` | 開局直接學會指定忍術和等級（id 見 `data/jutsu/`） |
| `dominance=100` | 開局支配值 |
| `no-hud-perf` | 隱藏效能列 |

## 目前有的

```
體術（起手）：近身三連擊，第三下踢飛
   ↓ 升級卡學新忍術（Lv.2、Lv.4 必出新忍術）
團扇              扇形重擊；敵人的火遁、水遁會被扇回去，反打敵群
火遁・豪火球      從拳頭大長到兩人高；Lv.3 燃燒地面 → Lv.5 燒死會爆炸傳火
木遁・樹界降誕    樹根把一整圈敵人綁在原地；Lv.5 與火遁合用時樹根著火
寫輪眼            快被打中時留下紅色殘影、自動閃開（有次數與冷卻）；Lv.3 殘影爆開震飛敵人
須佐能乎（Lv.5 起）按「須佐」召出紫色巨人：擋七成傷害、自動巨斬，越升級越大
輪迴眼・地爆天星（Lv.8 起）支配值滿時按「地爆天星」：整片敵人被吸上天壓成一顆星
   ↓
被打飛的人翻滾撞進人群（最多連鎖 3 層），撞到岩柱停下
擊殺數＋連殺稱號；支配值（擊殺、精英、閃避都會加）
```

- **忍者軍團**：
  - 按預算生怪，數量隨時間 20 → 300。
  - 2:00 起加入**火遁忍者**：吐火球，被打中會爆炸。
  - 2:30 起加入**水遁忍者**：射水彈，被打中會減速。
  - 3:30 起加入**土遁忍者**：先在你腳下畫紅圈，1.1 秒後岩刺竄出，團扇擋不了。
  - 施術忍者會和你保持距離。
  - 4:00、7:00 各出現一次精英。
- **美術**（Codex 生成，Claude 挑選的暫定版，可換）：
  - 原圖在 `art_src/round1/`，選定的放在 `art_src/selected/`。
  - `tools/build_atlas.py` 把選好的圖放進圖集格子。
  - 岩柱、巨石、枯草仍是佔位圖。
- **姿勢**：Codex 生成 7 張斑的姿勢，暫定選擇：待命 01、跑 A 01、跑 B 02、直拳 02、飛踢 02、揮扇 01、結印 01。
  - 原圖在 `art_src/round2/`。
  - 會跟著動作切換：移動時兩張跑步交替；體術出直拳，收尾飛踢；團扇用揮扇；火遁、木遁、須佐用結印。
  - 同一角色的姿勢共用一個縮放比例（`atlas.json` 的 `group`），跑步、踢腿時人物大小不會跳動。
- **回饋**：停頓只在重擊時觸發；寫輪眼閃避時有短暫慢動作；地爆天星會壓暗畫面再白閃；須佐與地爆天星會拉遠鏡頭。

## 可在編輯器調整的地方

| 想調的東西 | 位置 |
|---|---|
| 敵人、忍術卡片文字、被動 | `data/enemies/`、`data/jutsu/`、`data/passives/` |
| 每個等級的數值 | `jutsu.gd` 開頭的表，例如 `BALL_SIZE`、`BALL_BLAST` |
| 擊飛、連鎖、燃燒傷害 | `horde.gd` 的 Launch 和 Burn 群組 |
| 停頓、連殺、軍團曲線、新忍術保底等級 | `main.gd`；`upgrades.gd` 的 `new_jutsu_levels` |
| 瞬身 | `player.gd` 的 Dash 群組 |
| 鏡頭 | 俯角 42°、距離 13 m、FOV 50；比較過 30°、48°、62° |
| 美術 | `assets/sprites/atlas.png`：高清手繪風佔位圖，4×2 格、每格 256 px、四周留透明邊，用 `tools/make_placeholder_art.py` 產生 |

## 已驗證（2026-10-19）

- **核心測試全部通過**，涵蓋：
  - 開局只有體術。
  - 重擊一下秒殺並擊飛；扇形打不到背後的敵人。
  - 連鎖撞人至少波及 3 人；岩柱會擋。
  - 連殺與稱號。
  - Lv.2 選卡一定有新忍術；選卡時時間停止，選完後生效。
  - 火球 Lv.3 會留下燃燒地面，並點燃敵人。
  - **兩指操作**：左手指操控搖桿時，右手指按瞬身會觸發；放開瞬身那根手指，搖桿不會跟著放開。
  - 瞬身與冷卻；自動攻擊會擊殺；死亡後結束。
- **兩種渲染器**：同一幀在 Compatibility（網頁）與 Mobile（原生）下畫面一致。
- **效能**：
  - 網頁版（無頭 Chromium）175～266 個敵人、60 fps、模擬約 1.1 ms，下載包 1.83 MB。
  - 圖集改成無損格式：原本被壓成桌面專用格式，手機 WebGL 讀不了。
- **還沒驗證**：
  - 真機上用 `?stress=400` 跑。
  - 真機兩指操作。
  - 手感是否通過第一關。
