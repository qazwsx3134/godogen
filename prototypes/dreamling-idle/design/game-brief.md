# 夢靈遠行：可玩切片基準

2026-10-27使用者授權先做遊戲。Godot 4.7／GDScript／Compatibility，一般單一視窗；桌面置頂、透明、特殊焦點與桌面殼延期。

玩家幻想：照看一支會自己冒險的小隊，短暫回來換人、升級或換裝，就能看出戰鬥差異。核心驗證是隊伍輸出、承傷、治療與種族搭配的取捨。

```text
選關 → 自動戰鬥 → 金幣／經驗／掉落
 ↑                         ↓
 └──── 編成／升級／換裝 ────┘
```

本輪交付：6種夢靈（3種起始持有）、2～3格編成、6個關卡、3波遭遇／關、首領、角色EXP／金幣訓練、兩部位裝備與待領容量、6項永久升級、基本羈絆、治療觸發傷害、圖鑑、戰報、本機原子存檔與備份。關閉後暫停收益；不製作離線戰鬥模型、進化及工坊。

重用：kit AutoCaster處理普攻／攻擊技能排程、UpgradeTree處理永久升級、AtomicFile處理底層存檔、SceneBuilder用於一次性saved scenes製作、TestKit用於測試。水平追打、清場後行軍與視差參照Taskbar Hero；純domain與command／event分離參照Skybound Blades。保留單一模擬權威，不匯入其他遊戲的整個runtime。

素材：沿用Skybound的3種原創怪物動作圖與Erwin Run的既有環境圖作內部切片暫用素材；不生成AI圖片，不直接使用參考遊戲截圖當遊戲畫面。來源清單另記assets/README.md。

scene是可維護來源，執行／匯入／測試均不重建。主要畫面、卡片、裝備列、天賦、地圖和actor均保存為`.tscn`；一次性工具以Godot pack／save並驗證owner、節點數與子scene參照。

驗收：可完整跑戰鬥→新資源→調整隊伍／裝備→過關→存檔→重啟；同tick／seed與command在不同render FPS結果一致；不重領首通、不中途扣一半資源、滿包有待領；UI透過真實node操作測試；人工編輯scene靜態文字／間距後執行保留。試玩樂趣仍須作者體驗，不由自動測試代替。
