# 六頁 UI 整合驗收（2026-09-28）

本輪是**可操作的圖稿 UI 原型**，不是逐像素 1:1 驗收通過，也不是完整遊戲 MVP。

[開啟原圖／實際渲染並排與透明疊圖](index.html)。選擇頁面後可切換重疊模式檢查布局差異。所有交付 PNG 都來自 Godot 實際主場景，透過滑鼠輸入切頁；沒有使用原圖冒充執行結果。

## 證據

- 每頁三種尺寸：檔名為 `941x1672-{page}.png`、`390x844-{page}.png`、`320x568-{page}.png`；page 是 overview/train/backpack/monster/adventure/store，共 18 張。
- 截圖使用明確的 `reference_preview=true`、暫停戰鬥，讓參考金幣固定為 12,480；玩家存檔不受影響。
- [測試原始結果](test-results.txt)：存檔復原、真實場景戰鬥、六頁輸入／狀態、序列化與編輯器預覽、文字／布局編輯保留、600 秒模擬戰鬥。
- 場景製作工具 pack 後直接實例化，比對節點數；最後主場景預先含 696 個節點，不由啟動程式建立頁面。正常啟動前後 `.tscn`／`.tres` 雜湊一致。
- [工作者中途交接紀錄](worker-handoff.md) 已收回；後續修正和驗收由主 session 完成，該工作者窗格已關閉。

## 已驗證的行為

初始總覽、五頁導覽、頭像返回、背包篩選與物品資訊、怪獸選取、訓練進度、關卡鎖定與 1-1 出發、商店示範、設定暫停／繼續與手動存檔。切頁沿用相同 CombatArena 與單位；出生座標保留編輯器設定。損壞存檔警告可在設定面板持續查看。

測試操作真實按鈕輸入，並在三個尺寸確認導航能操作與留在畫面中。600 秒是加速模擬，不是實機長時間效能測試。渲染使用 Mesa llvmpipe 軟體 OpenGL，不代表 Android／iOS FPS。
