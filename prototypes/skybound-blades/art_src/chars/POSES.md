# 動作姿勢（從核准的 master 用 edit 改出）

每張：`master_still.py edit --master <角色>/master --change "<下方英文>" --keep "<共同 keep>" --takes 2 --route codex-cli --output-dir <角色>/poses/<pose>`。

共同 keep（每張都加）：`same character identity, face, hair, outfit, colours, equipment, proportions and HD illustration style; same elevated three-quarter view; the character still faces the lower-right; flat magenta backdrop; no ground shadow; nothing cropped`
