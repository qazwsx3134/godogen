# RO 戰鬥切片（M0）

2026-10-24。第一個可玩交付物：一層風庭遺跡的狩獵區，在 Web 桌機與手機橫向上驗證「RO 式 HD 2.5D＋自動追打＋兩名 AI」的手感。機制閉環（任務／物品實例／倉庫／遠征結算／死亡傳承）接在切片之後，依 [mechanism-plan.md](mechanism-plan.md) 進行。

## 範圍

| 包含 | 不包含 |
|---|---|
| 一個狩獵區 scene：平坦地面、障礙物、3 種第一層怪物（slime／boar／hound） | 城鎮、營地、Boss、第二層以後 |
| 隊長（單手劍）＋盾衛＋補師，HD billboard 角色 | 其他流派、換裝、強化 |
| 點地／WASD 移動、點敵人追打、自動狩獵開關、1 個技能（cleave） | 技能格、熟練度成長、AI 戰術切換 UI |
| EXP 與升級、金幣與素材計數、一件討伐任務 | 物品實例、背包、倉庫、商店 |
| 普通藥（HOT）、瞬補、自動喝藥門檻 | 自動撤退、補給購買 |
| 隊長倒下：結束本輪並顯示摘要，可重開；**不寫入任何存檔** | 永久死亡、紀念碑、傳承、離線委託 |

## 操作

| 輸入 | 結果 |
|---|---|
| 左鍵／點按敵人 | 鎖定該敵人，自動追到射程內並持續普攻，直到敵人倒下、玩家改令或目標不可達 |
| 左鍵／點按地面 | 取消鎖定並移動到該點；途中被擋住時停下並清除移動意圖 |
| WASD／方向鍵 | 依鏡頭方向移動，取消點地移動；放開後若自動狩獵開著，就繼續狩獵 |
| 空白鍵／自動狩獵按鈕 | 切換持續意圖：沒有鎖定目標時，自己找最近、可到達的敵人 |
| Q／技能按鈕 | 對目前鎖定的目標施放 cleave；沒有鎖定時，打射程內最近的敵人 |
| E／藥水按鈕 | 喝普通藥 |
| 滾輪／縮放按鈕 | 改鏡頭遠近；方位與俯角固定 |

- 盾衛與補師不論自動狩獵是否開著都會參戰：盾衛在隊長或補師被鎖定時使用 taunt，補師依 `bandage_ally` 的條件治療（最低血量隊員低於 45%，有距離限制）。
- 目標重算有間隔（tuning 的 `search_ms`），被攻擊時可以改打攻擊者。
- 按鈕與快捷鍵走同一條命令路徑；手機觸控按鈕至少 44 px。

## 規則與數字

戰鬥規則與數字讀 [tuning-draft.json](tuning-draft.json)，不寫死在 scene 腳本裡。切片用到的部分包括：`simulation`、`hero`、`combat`、`automation.potion_threshold`、`items` 的 `tonic_small`／`emergency_kit`／`bandage`、`party.roles`／`utilities`、`skills.cleave`、`monsters` 第一層 3 種、`loot`，以及一件 `hunt_1_*` 任務。

- 戰鬥結算放在 `domain/`：固定步進（`simulation.step_ms`）、與 render FPS 無關、用可注入的 RNG seed；scene 只把事件轉成動畫、浮字與音效。
- 切片不必一次實作 §5 的全部公式。命中率、爆擊與格擋可以先關掉，但介面要讓它們之後能直接加進來，不需要重寫。

## 美術與 scene

- 角色圖先 import 成外部 Texture2D／sheet 資源，scene 只引用它們；`.tscn` 不內嵌 Image。單一角色 scene 檔應在 100 KB 以下。
- `field.tscn`（世界＋隊伍＋怪物配置）、`hud.tscn`、`party_actor.tscn`、`monster_actor.tscn`、`floating_text.tscn` 都是可編輯的 scene。HUD 的 `%名稱` 屬於 `hud.tscn` 自己；主場景透過 HUD 腳本公開的屬性或 `$HUD.get_node("%…")` 取得，不要直接用 `%名稱`。
- 鏡頭固定約 35° 俯角、45° 方位（implementation-plan §10）。

## 驗收

1. headless 測試：固定 seed 與命令序列，在 30／60／144 FPS 下得到相同的擊殺數、EXP 與 HP 結果。
2. 正面撞上障礙物不會卡死：卡住時清除移動意圖，或繞過障礙物。
3. 動畫：走路影格會推進，攻擊動畫播完才回 idle，倒下時會溶解。
4. 手動模式：點敵人能追打到擊殺；關掉自動狩獵時，盾衛和補師仍會作戰。
5. 隊長倒下：畫面顯示摘要，重開後所有數值回到 tuning 的初始值；`user://` 底下沒有任何寫入。
6. 編輯器：在 `field.tscn` 改一隻怪的位置、在 `hud.tscn` 改一個間距，執行後兩者都保留。
7. Web 匯出：桌機 Chromium 60 fps，手機橫向至少 30 fps（3 名隊員＋8 隻怪＋技能與 UI 同時在畫面上）；首包 25 MiB 以下。
