# M1・單層閉環

2026-10-24。接在 [RO 戰鬥切片](ro-slice.md) 之後：同一個風庭遺跡，補上「出城 → 狩獵 → 補給／撤退 → 回營地 → 守層者 → 死亡」的完整循環與本機存檔。技能串聯另見 skill-links（研究中），不在本文件範圍。

## 資料歸屬（mechanism-plan §1）

| 資料 | 位置 | 隊長倒下時 |
|---|---|---|
| 等級、EXP、身上金幣、背包、穿戴、任務進度、kill receipt | Run | 失去 |
| 倉庫（金幣與物品）、紀念碑、已見過的怪物 | Profile | 保留 |
| 配發品（初始藥水、繃帶、見習裝備） | Run，標記 `issued` | 失去；不可出售、不可存倉 |

## 規則要點

- **獎勵只結算一次**：每次擊殺有 `kill_id`（run id＋事件序號），Run 記下已結算的 id；重放同一事件不重複給 EXP、金幣、掉落或任務進度。
- **任務只在營地回報**：回報時重新檢查條件，扣除收集品、發獎、寫 receipt 是同一個提交；同一份素材不能同時交給兩個委託。
- **裝備實例不改模板**：能力＝模板 bonus ×品質倍率（tuning `equipment_generation`），取整數。
- **營地安全**：怪物的追擊與 leash 都不進營地範圍；營地內不能被攻擊。
- **撤退**：開始後 2 秒才完成，重複按不延長也不縮短；完成時全隊移到營地，Run 產生一份遠征結算（本趟擊殺、EXP、金幣、素材、裝備、用掉的補給、停下原因）。
- **存檔時機**：進出營地、每次擊殺結算後、每 10 秒、倒下時。死亡先寫 tombstone 再寫主檔；讀檔時有 tombstone 的 Run 不能復活。

## 驗收

1. `test_run`：同一 kill 事件餵兩次只結算一次；回報委託重新驗證並一次扣除；配發品不能賣或存倉；裝備能力＝模板×品質。
2. `test_save`：存檔→讀檔得到相同 Profile／Run；主檔壞掉時用 `.bak`；有 tombstone 時舊 Run 讀不回來。
3. `test_field`：撤退 2 秒後全隊在營地；營地內怪物不追；在營地能買藥、存倉、回報。
4. 守門者的兩招在命中前至少 1.2 秒有地面預警；盾衛在蓄力時使用 cover；首通後主線委託可回報。
5. 隊長倒下：紀念碑多一筆、倉庫內容不變、下一代從配發品開始；重新整理網頁後狀態一致。
6. 網頁版：關閉分頁再開，倉庫與 Run 都還在（IndexedDB）。
