# 營地：裝備比較、分頁提示、治療貢獻

2026-10-24。依[流浪仙境](../../../research/ragnarok-wanderer/2026-10-24/README.md) §10、§12 與[守城英雄傳](../../../research/castle-heroes/2026-10-24/README.md)的 UI 研究修改營地介面。同一輪的戰鬥改動見 [boss-warnings.md](boss-warnings.md)。

| 研究發現 | 改動 |
|---|---|
| 流浪仙境：換裝前顯示「輸出／有效生命」兩軸差值與「較佳裝備」篩選 | 裝備頁每件背包裝備除了能力差，也顯示預估**輸出**與**耐久**的變化百分比。兩軸都不降、至少一軸上升的標 `▲較佳`，一升一降的標 `取捨`。排序是較佳在前、取捨其次，同類依總提升排 |
| 守城英雄傳：鎖定入口與新內容要直接提示，不要讓玩家逐一點開找 | 營地分頁標上數字：`委託 N`＝可回報、`裝備 N`＝任一隊員的較佳裝備件數、`技能 N`＝現在就能學 |
| 守城英雄傳：貢獻統計要包含治療等非傷害貢獻，否則玩家只會留下高輸出角色 | 遠征結算多一行「治療：援護用繃帶救回 N 生命」 |

## 預估公式（`camp_menu.power`）

- 輸出＝攻擊 × 每秒揮擊數 × 平均爆擊倍率。
- 耐久＝最大生命 ÷ 守門者一擊扣掉防禦與格擋後剩下的比例。
- 只用來比較裝備，不是戰鬥預測：不計技能、連招與敵人防禦。目前只用第一層守門者一種參考敵人，有第二層後改成用當層的敵人。
- 例：硬皮護甲換掉旅人上衣時少了敏捷 +2，攻擊變慢，所以顯示「輸出 −2% · 耐久 +21%」（取捨）。

## 驗收結果（2026-10-24）

- `test_camp`：稀有見習長劍（+8，取代 +6）＝輸出 +10%、耐久 ±0%，排第一並標較佳；取捨排第二；相同的劍不標記；分頁數字在沒事時為 0，背包有一件較佳時 `裝備 1`。
- 1440×900 截圖：分頁數字與兩軸差值都在列內，沒有溢出。
- 全部測試通過：`battle run save camp field:60 text sprites skills`。
