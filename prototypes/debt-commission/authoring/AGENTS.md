# 人類確認的人格與記憶

先讀 README.md 與 REVIEW.md。人格與記憶 JSON 的存在不代表作者已採納。

- 用 tools/persona_context.py context 取得正式寫作上下文；如果確認缺失或雜湊不符，先展示現有草案並等待人類決定。
- 新增、修訂人格與記憶後必須由協作人類確認具體內容。使用者同意建工具、測試或一般開發，不等於確認草案內容。
- 只有人類明確確認相應內容後，才能更新 confirmations.json；保留真實確認語句或可追溯位置，禁止捏造證據或自我核准。
- 測試確認紀錄只能寫在暫存 fixture，不能複製到正式資料。
- 已確認的同一內容不必反覆要求確認；內容改變時重新送審。
