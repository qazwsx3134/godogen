# 創作者美術規格

用這套系統做自己的故事時，背景、立繪、表情與線索圖要怎麼準備。規格依遊戲實際的顯示方式訂；第一章的手繪蠟筆圖是範例。對話框、按鈕、名牌等介面由介面風格提供，不用畫。

## 畫面怎麼擺

```
┌──────────── 1080 ────────────┐  設計寬固定 1080 px；高度隨手機
│ 地名・HUD                     │  1920（16:9）到約 2340（19.5:9）
│                              │
│    背景：等比放大蓋滿整個畫面  │
│        立繪站在對話框上方      │
│      left  center  right     │
├──────────────────────────────┤  閱讀時下方約 38% 被對話框蓋住
│ 對話框（介面風格提供）         │  （調查時玩家可以收起）
└──────────────────────────────┘
```

## 背景

| 項目 | 規格 |
| --- | --- |
| 格式 | PNG 或 JPG，不透明 |
| 顯示 | 等比放大蓋滿整個畫面、置中裁切 |
| 建議尺寸 | 高 ≥ 2340 px、寬 ≥ 1080 px |
| 調查用背景 | 畫寬一點（寬高比 4:3 以上，例如 3120×2340）。調查時玩家左右拖曳，能拖的範圍＝圖比畫面寬出來的部分 |
| 構圖 | 主要內容放在上方約 60%；下方會被對話框蓋住 |

- 範例 `assets/image/yorosuya-inside.png` 是 1448×1086，在長手機上放大約 2.15 倍。蠟筆的粗筆觸撐得住，細線條或寫實畫風會糊，請照建議尺寸。
- 調查點的位置與大小寫成整張圖的比例（`pos`、`size`，0–1），所以之後換更高解析度的同一張圖，劇本不用改。
- 個別背景的取景微調在 `scenes/stage.tscn` 的 `Backgrounds/<背景 id>` 節點；沒有同名節點就用 `Default`。
- 沒有圖的背景用 catalog 的 `top`／`bottom` 漸層，可以先寫劇本、後補圖。

## 立繪

| 項目 | 規格 |
| --- | --- |
| 格式 | 透明底 PNG（RGBA），去背乾淨、沒有白邊 |
| 一個角色一張定稿 | 平常的表情（`neutral`）；其他表情另外畫，見下節 |
| 腳底線 | 腳底（或畫到的最下緣）貼齊圖的底邊，人物左右置中 |
| 留白 | 上下左右不要留大片透明空白：空白會一起被縮放，人就變小 |
| 顯示 | 每個站位是 480×1560 的站姿框，圖等比縮進框底中央 1040×1560 的範圍 |
| 建議尺寸 | 高 ≥ 1600 px |

- 所有角色用同一套縮放規則，所以角色之間的身高與頭身比，要在原圖裡就畫成你想要的比例。範例：`shin-pa-chi.png` 941×1672、`gintoki.png` 1024×1536。
- 站位有 `left`、`center`、`right`；catalog 的 `slot` 是角色的預設站位，劇本可以換。
- 某個角色要個別放大、縮小或移位：調整 `scenes/characters/<角色 id>.tscn` 裡 `Art` 的位置與大小。新角色有圖、還沒有 scene 時，跑 `tools/make_character_scenes.gd` 建一個。
- 角色熱區（調查時點角色本人）預設是整張立繪；只要點臉或手上的東西時，在熱區寫 `art_region: [x, y, w, h]`，同樣是立繪的 0–1 比例。

## 表情

- 表情 id 只能用 `scripts/story_runner.gd` 的 `VALID_EXPRESSIONS`；每個 id 的用途與畫法見 [表情清單](../../../docs/story-telling-game/EXPRESSIONS.md)。
- 檔案放 `assets/image/expressions/<角色 id>_<表情 id>.png`，並在 catalog 角色的 `expressions` 登記。
- 表情圖和定稿用同一個畫布大小、同一條腳底線、同一條中線，換表情時人才不會跳動。姿勢比定稿大時，畫布往左右與上方加大。生成或手繪的原圖放 `art_src/expressions/`，`tools/fit_expressions.gd` 會自動對齊成這個規格。
- 劇本用到、還沒有圖的表情會先顯示定稿；`tools/list_expressions.gd` 列出缺哪些。

## 線索圖

- 可以不給圖：沒有 `path` 的線索顯示名稱第一個字的色塊（第一章目前都是這樣）。
- 要給圖：正方形透明 PNG，建議 ≥ 512 px，在 catalog `items` 的 `path` 登記。HUD 上約 133 px，案件檔裡較大。

## 登記與檢查

1. 檔案放 `assets/image/`（表情放 `assets/image/expressions/`）。原圖、生成時的提示詞、沒採用的版本放 `art_src/`，不要放進 `assets/`。
2. 在 `data/asset_catalog.json` 加上 id 與 `path`：id 用英文小寫加底線，顯示名稱（`label`、`name`）寫中文。
3. 劇本引用那個 id，跑一次檢查（見 [故事編輯器](STORY-EDITOR.md) 的 check_story）；缺圖、id 打錯都會在這一步報出來。故事包的圖放作品資料夾的 `art/`，登記在作品的 `catalog.json`，路徑可寫 `art/xxx.png`。
4. 在手機尺寸實際看一次：背景的主要內容有沒有被對話框蓋住、角色之間比例對不對、換表情時人有沒有跳動。

## 授權

每張交出去的圖（和音樂、音效）在編輯器「素材設定」那一筆填授權（或在 catalog 那一筆加上 `license`），製作名單會自動列出作者：

```json
"license": {"author": "你的名字", "source": "委託繪製", "license": "自有", "approved": false}
```

`author` 可以是一個名字或名字陣列；`approved` 由主編確認後改成 `true`。角色的 `license` 也涵蓋它的表情圖。欄位說明見 IMPLEMENTATION.md「素材授權」。

## 投稿檢查

交稿前在 Godot 點「檔案系統」裡你的作品資料夾（`stories/<作品>`；本作不用選），再按「專案 → 工具 → 作品：投稿檢查」。報告會自動打開，分成：

- **錯誤**：一定要修，例如 `path` 寫了但檔案不在。
- **美術待辦**：劇本用到、還沒有圖的背景、角色與表情，附上該畫的尺寸與檔名。可以當成你的工作清單。
- **建議**：尺寸、透明底、腳底線、留白等不合本頁規格的地方。
- **缺授權**、**劇本沒用到的素材**。

報告在 `build/art_check/`，不會進 git，不用提交。
