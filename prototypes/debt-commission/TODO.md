## 後續實作順序（2026-10-06）

### C 文字演出

- [ ] 對話框正文改成 `RichTextLabel`，保留四款 scene 的字型、顏色、陰影、行距與留白。
- [ ] 重點字上色、放大與抖動；句中停頓、指定段落慢速、標點自然停頓。打字、快轉、補完、紀錄與 QA 都按可讀字元計數。
- [ ] 依角色音高播放打字音；心聲／旁白的音效政策，以及靜音、音量與略讀行為一併驗證。

### D 閱讀便利

- [ ] 段落內回滾：還原台詞、旗標、素材、舞台、音樂和對話紀錄；不能越過 choice／吐槽回合／調查／章節結算；換章節與讀檔清除回滾歷史。
- [ ] 獨立快速存讀格：與自動檔及 18 格手動檔隔離，沿用版本驗證、備份還原與錯誤提示。
- [ ] 字級與對話框底色透明度設定：立即套用並記住，字與按鈕不跟著變透明；窄手機的設定項目可捲動。
- [ ] 對話紀錄、存讀檔面板／欄位／覆寫確認、結尾按鈕轉成 `.tscn` 與重複 item scene；版面用 anchor／Container，保留現有風格。
- [ ] Godot 存 scene 後檢查 owner、子 scene 參照與 pack 前後 node 數；驗證編輯器改字／間距後執行仍保留。
- [ ] 回歸存讀檔分頁、覆寫、毀損備份、跨故事隔離與倒數暫停，並用 Web 實點新入口。
