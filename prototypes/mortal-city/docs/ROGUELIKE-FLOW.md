# Roguelike 流程設計（2026-11-06 討論定稿）

方向轉換見 [ADR 0001](adr/0001-single-player-roguelike.md)，術語見 [CONTEXT.md](../CONTEXT.md)。本檔記錄 grill 討論的 26 項決定。

## 重玩的理由與冒險目標

- 重玩的主要動機是用另一套流派重走街區，去接上一段生涯不敢接的案。驗收時觀察不同流派是否改變接案、加骰與撤離的選擇。
- 危險節點的設計目標是讓玩家知道可能失去傭兵，仍覺得這次值得冒險。死亡率可用來診斷規則，試玩時也要記下玩家是否理解風險，以及他願意為哪個報酬承擔風險。
- 劇情案撤離後，生涯可繼續前往後案或下一街區。後案須明確承接撤離留下的局勢。[ADR 0002](adr/0002-story-withdrawal.md)

## 流派、獎勵與後案的設計原則

- 同走一條路線的流派也應有各自擅長的場面解法。例如狂暴大猩猩能扛著火力撞開封鎖，雙持能趁守衛換彈時搶先制伏。驗收時用兩個流派試玩同一件委託，觀察玩家是否會換解法。解法用實際裝備或卡牌提供的能力解鎖。混搭傭兵可以同時使用多種能力，每個場面保留一條基礎解法。
- 精英委託的致命選擇前，先說明通過後能保證出現的獎勵種類與對應流派。具體品項在生還後揭曉，保留三選一。保證流派由委託決定，在街區地圖即可看到。三選一至少一格符合預告的種類與流派，其餘兩格沿用正常抽選。
- 第一批劇情案以增加取得線索的代價來承接撤離。後案保留原本的做法，玩家可以付錢、欠人情或額外冒一次險來補線索。每件案的具體代價由劇情設計決定，並須有一條在零現金、高神經壓力時仍能採取的補線索途徑，例如從後案報酬扣抵。

## 新宿切片的驗收

- 先沿用開打前選戰術、自動播放，聚焦場面解法造成的決策差異。讓狂暴大猩猩、雙持與無專長傭兵走同一件委託，記錄各自選的解法。
- 精英委託完成時兌現地圖預告，重傷生還也算完成。玩家若選擇丟下一切脫身，該案沒有戰利品。
- 由同一位玩家試兩個危險節點情境。第一個情境的預告獎勵能補足流派缺口，傭兵也有餘裕承擔代價。第二個情境的獎勵與流派無關，或傭兵傷勢已過重。兩次都先請玩家說出可能失去什麼、成功可得什麼，再記錄他選冒險或撤離的理由。觀察他是否會隨情境改變選擇。

### 試玩用案件

| 比較 | 遊戲內的入口與記錄 |
|---|---|
| 同一場面，不同流派 | 「清空幫派據點」第一個場面。皮下護甲、強化肌腱或硬骨頭可撞開封鎖，反射加速器、成對手槍或快拔可搶換彈空檔。再試一次同時具備兩種能力的傭兵，記錄選用的解法、骰數與可以承擔的代價。 |
| 同一位玩家面對兩次致命選擇 | 以正在湊速駭裝備的傭兵為起點。先看「盜取企業伺服器」的速駭獎勵，再看另一件精英委託的非速駭獎勵。兩個情境盡量保留相近的傷勢、神經餘裕與骰數，分別請玩家說出會不會賭、原因及預期所得。 |
| 從前案撤離後繼續 | 在「終電包裹」交出箱子撤離，再進「診所不收現金」。霧補上夜班班表，費用從後案實得報酬扣兩成，當下可零現金開始。 |

## 一段生涯

```
建立傭兵（起始背景；首次只有無名傭兵）
   ↓
┌─→ 街區地圖（10～12 層、每層 2～4 節點，只能走到下一層相鄰的節點）
│     委託／精英委託／事件／黑市／診所／休息／劇情委託（中段固定）
│     ↓ 名聲升級 → 卡牌三選一；掉寶 → 道具三選一；經驗升級 → 屬性點
│   劇情大案（街區終點）
│     ↓
│   安全屋 ──退休──→ 傳奇檔案＋解鎖（有一批只有退休能拿）
│     ↓ 繼續
│   下一個街區：新宿 → 灣岸 → 秋葉原 → 丸之內
└── 最後一區之後回到新宿，警戒等級 +1（無限循環）
任何時候死亡 → 刪除存檔、寫進傳奇檔案＋解鎖
```

## 規則

| 項目 | 決定 |
|---|---|
| 多人 | 單機為主體；每日挑戰（同一個 seed）加排行；頻道首版只在本機（NPC、夜鴉、私訊、自己的傳奇檔案、寫死的假玩家貼文），真人聊天等接上登入之後再做 |
| 節點類型 | 委託（舊街頭工作）、精英委託（舊第 4 階：可能永久死亡、撐過去保證掉寶，每區 2 個）、事件（短文字＋2～3 選項，可能要求屬性）、黑市、診所、休息（回傷勢或降通緝擇一）、劇情委託、劇情大案 |
| 地圖產生 | 依 seed 程序產生；精英委託不早於第 4 層、劇情大案前一層一定有診所或休息、劇情委託固定在中段、每區至少一個黑市 |
| 等待 | 自動段 10～30 秒：像素橫幅播主角跑步與節點場景，文字逐行出現；同一種節點看過後可以 2 倍速。一般委託的自動段只剩開場，之後是要玩家擲骰的場面（[DICE-POOL-SPEC.md](DICE-POOL-SPEC.md) 第 3 節）。戰鬥每回合約 0.6 秒，可以 2 倍速 |
| 戰鬥 | 開打前選戰術（正面／駭客／迷彩）、自動播放；流派靠卡牌與道具改變數值與戰術效果 |
| 成長 | 經驗 → 等級 → 屬性點；名聲 → 卡牌三選一；掉寶 → 道具三選一。熟練度拿掉，由卡牌負責對應效果 |
| 名聲 | 只屬於這段生涯；也是這局分數 |
| 風險 | 傷勢、通緝保留，作為這局的壓力資源；委託與劇情做法的場面用骰池判定，成功但付代價與失敗都從傷勢、通緝、神經壓力、報酬四種資源扣；危險節點的冒險選項是一次致命判定（骰池，失敗＝致命傷），神經錯亂改成看得到的錯亂骰；救命保單＝黑市的一次性道具；抵押與贖回拿掉；危險節點維持「一定有不會死的選項」 |
| 跨生涯 | 解鎖＝成就條件（例：以火力為主流派撐過灣岸 → 解鎖「街頭打手」背景）；不繼承數值 |
| 好感 | 生涯內：做某中間人的委託加好感，到門檻後地圖出現他的專屬節點；跨生涯只解鎖「他的獨特任務線可以出現」 |
| 存檔 | 每走一個節點自動存檔，只有一欄；結果由 seed 決定、重新整理不會重擲；不能讀檔回到過去 |
| 每日挑戰 | 固定無名傭兵、只用基本抽選池；分數＝生涯結束時的名聲總經驗，死亡打 8 折；每天第一次才算分 |
| 技術 | 維持 React 網頁版；每日挑戰與排行之後接 Cloudflare Workers |
| 現有內容 | 02「診所不收現金」＝新宿劇情大案；01「終電包裹」＝新宿中段劇情委託；測試案留在開發工具 |
| 舊系統 | 排隊、離線結算、離開期間報告、週榜、熟練度、抵押／贖回、城市封鎖線事件：刪除程式，README 改寫；`docs/cyberpunk-text-mmo/` 保留並標註以 ADR 0001 為準 |

## 第一個可玩切片

- 新宿一個街區：程序地圖、委託模板（現在難度 1～5 各 3 個，共 15 個）、精英委託 2 個、事件約 10 則、黑市、診所、休息、01 劇情委託、02 劇情大案、安全屋（退休）。
- 名聲卡牌三選一、掉寶三選一（規則層已完成並有測試）、無名傭兵、傳奇檔案。
- 先不做：灣岸、警戒等級循環、起始背景解鎖、好感與私訊、每日挑戰、頻道。
- 插圖：現有 sprite 場景＋6 種節點類型各一張（生成前先說明批次內容，等使用者選直接生成或給提示詞）。
- 要回答的問題：「走地圖、湊流派、決定要不要冒險」好不好玩。
