# 骰池判定改版規格（2026-11-11）

目標：讓每個節點有事可做、一局撐得更久、重玩有新東西。使用者選定判定方式 B（骰池＋代價），痛點三項：節點太快沒事做、一局太短、重玩沒有新東西。流程與術語以 [ROGUELIKE-FLOW.md](ROGUELIKE-FLOW.md)、[CONTEXT.md](../CONTEXT.md) 為準，本檔只寫改動的部分。

標「已實作」的是 2026-11-11 寫進工作區、尚未提交也尚未試玩的程式；其餘是待做。**所有數字都是 Claude 定的起始值**，寫成常數，試玩後再調。

## 1. 設計原則

1. **骰子擲在玩家面前**。畫面顯示擲幾顆、每顆幾點、哪一顆決定結果；不顯示機率百分比。
2. **結果有四級**：大成功、乾淨成功、成功但付代價、失敗。失敗多半是付更重的代價並讓狀況惡化，不直接結束生涯。
3. **擲之前有決定**：花壓力資源加骰。**擲之後也有決定**：付哪一種代價。
4. **代價只用現有的四種資源**：傷勢、通緝、神經壓力、報酬。不新增資源。
5. **死亡只發生在玩家押過頭之後**：自己選了致命場面、又擲出失敗、又沒有保單。
6. **結果由 seed 決定**，重新整理不重擲（沿用現有存檔規則）。

## 2. 核心判定（已實作：`src/rules/core.ts`「骰池判定」）

擲 N 顆六面骰，只看最高那顆：

| 最高點數 | 結果 | 代號 |
|---|---|---|
| 兩顆以上的 6 | 大成功 | `crit` |
| 6 | 乾淨成功 | `clean` |
| 4～5 | 成功，但付代價 | `cost` |
| 1～3 | 失敗 | `fail` |

- N ≤ 0 時擲兩顆取**低**的，且不會大成功。
- 一次最多 6 顆（`POOL_MAX`）。
- seed：`hashSeed(角色 id, 節點 id, 'beat', 場面索引)`。加骰只是多抽一顆，前面幾顆的點數不變。

### 2.1 骰池怎麼組（`jobPool`）

| 來源 | 骰數 |
|---|---|
| 場面指定的屬性 | 屬性 3 → 2 顆、5 → 3、7 → 4、9 以上 → 5（`attrDice`） |
| 該路線的裝備與卡牌加成（`dirBonus`） | ≥5% → +1；≥20% → +2 |
| 難度 3 以上 | −1 |
| 重傷（傷勢 ≥70%） | −1 |

待做：精英委託與劇情案加「對手等級」修正（見第 5 節）；卡牌與義體的骰子效果（見第 7 節）。

### 2.2 擲之前加骰

| 選項 | 效果 | 代價 |
|---|---|---|
| 硬撐 | +1 顆 | 神經壓力 +8（`PUSH_STRESS`） |
| 鋌而走險 | +1 顆 | 通緝 +1（`GAMBLE_HEAT`）；通緝已滿不能選 |

兩個可以一起用。

### 2.3 代價（`CostKind`）

| 種類 | 成功但付代價 | 失敗（加倍） |
|---|---|---|
| 受傷 | 傷勢 +max(4, 委託 injury × 0.5)% | ×2 |
| 通緝 | +1 | +1 |
| 神經壓力 | +8 | +16 |
| 報酬打折 | −20%（`COST_PAY`） | 不會出現在失敗 |

- 成功但付代價：場面提供兩個選項，玩家選一個。
- 失敗：直接吃場面指定的那一種，加倍。
- 通緝已滿時，通緝代價改付神經壓力。
- 每次大成功報酬 +15%（`CRIT_PAY`）。

## 3. 一般委託（已實作：`state.ts`、`content/beats.ts`、`Node.tsx`）

```
開場文字（自動，約 6 秒）→ 神經錯亂判定（沿用舊規則）
   ↓
場面 1 → 場面 2 → 場面 3      每個場面：看情境 → 決定加不加骰 → 擲 → （選代價）
   ↓
駭入、潛行：三個場面走完＝完成；失敗兩次＝被逮到，打一場，打贏才算完成
武力：兩個場面之後一定打一場；每個成功場面對手 HP −12%（大成功再 −12%），每次失敗 +15%
   ↓
結算：報酬（打折與加成）、每個場面的骰與結果、經驗、名聲、掉寶
```

| 路線 | 場面與屬性 |
|---|---|
| 武力 | 逼近（反應）、壓制（體能） |
| 駭入 | 接入（智力）、破冰（技術）、斷線（沉著） |
| 潛行 | 潛入（沉著）、得手（技術）、脫身（反應） |

場面文字依路線共用（每個場面：情境一段、四種結果各一句、兩個代價選項）。舊規則的「路上小傷」「失手時隨機通緝 +1」已拿掉，改由代價負責。

**已知問題**：`pnpm test` 66 過、1 失敗——「謹慎型機器人一定活著退休」有一局死了（`state.test.ts:191`），原因還沒追。屬於第 8 節的平衡工作。畫面還沒有實際開起來看過。

待做：
- 場面文字的變化：每個場面至少 3 組情境，依 seed 挑，避免每件委託讀到同一段。
- 擲骰的演出：骰子逐顆翻出（約 0.8 秒，可跳過）、決定結果的那顆亮起、四種結果各一個音效。
- 場面之間可以選路：例如「得手」可以改用智力（駭開電子鎖）或體能（硬撬），讓屬性配點有不同解法。

## 4. 戰鬥：逐回合對擲（待做）

取代現在的全自動播放。打鬥本身仍然不會死（HP 低於 20% 撤退）。

- 每回合玩家選一個行動，再擲骰池：

| 行動 | 屬性 | 成功時 | 適合 |
|---|---|---|---|
| 強攻 | 反應 | 造成武器傷害；大成功 ×1.5 | 一般情況 |
| 掩護 | 技術 | 這回合受傷減半，下一回合 +1 顆 | 血少、等機會 |
| 駭入干擾（要終端，駭入強度 ≥ 防火牆） | 智力 | 對方下一回合不能還擊 | 速駭流派 |
| 迷彩繞背（要迷彩，隱匿 ≥ 感知，每場一次） | 沉著 | 傷害 ×繞背倍數，對方這回合打不到你 | 流浪者流派 |

- 結果對應：乾淨成功＝你打中、對方沒打中；成功但付代價＝雙方都打中；失敗＝只有對方打中。
- 對手用固定數值（HP、每次傷害），不擲骰；難度來自 HP 與傷害，名聲與通緝的加成照舊。
- 目標長度：一般遭遇 3～5 回合、精英 5～8 回合。
- 加骰（硬撐、鋌而走險）在戰鬥中同樣可用。
- 現有的命中率、爆擊率修正要換算成骰子效果（見第 7 節）。

## 5. 危險節點：精英委託與劇情委託（待做）

拿掉畫面上的「死亡 X%・重傷 Y%」，改成一次致命判定：

| 結果 | 效果 |
|---|---|
| 大成功／乾淨成功 | 撐過去，報酬與名聲全拿（冒險選項名聲 ×1.5 照舊） |
| 成功但付代價 | 撐過去，但重傷：傷勢至少 70%＋一道舊傷 |
| 失敗 | 致命傷：有保單被救（照保單等級），沒有就死亡 |

- 骰池＝選項指定的屬性＋該路線的裝備與卡牌 − 對手等級修正（精英 −1、劇情大案 −2）。
- 器材與屬性門檻選項改成「+2 顆」而不是另一條不會死的路；代價照舊（報酬七五折、名聲減半）。
- 一定保留一個不擲骰、不會死的撤離選項（沒有報酬）。
- 選項旁顯示「這是致命判定：失敗＝致命傷」與擲幾顆，不顯示百分比。
- 劇情委託的「做法」（武力／駭入／潛行）改成 2 個場面，用第 3 節的規則，場面結果影響最後致命判定的骰數（每個成功 +1、每次失敗 −1）。

## 6. 事件與神經錯亂（待做）

- **事件**：11 個有 `chance` 的選項改成擲骰池。屬性由選項指定；現有的「60%」這類數字換成骰數修正（60% 約等於 2 顆、75% 約 3 顆）。成功但付代價＝拿到成功效果，再加一個小代價。
- **神經錯亂**：拿掉「每件任務擲一次隱藏機率」。改成：
  - 警戒（餘裕 20～39）：硬撐的壓力代價 +4。
  - 臨界（1～19）：每次**硬撐**後擲一顆錯亂骰，1＝這個場面直接失敗。
  - 失控（≤0）：每個場面開始前擲一顆錯亂骰，1～2＝任務中斷，並再擲一次致命判定（2 顆）。
  - 用意：錯亂變成玩家看得到、能迴避的風險，而不是突然發生。

## 7. 卡牌與義體改成骰子效果（待做）

現有效果大多是戰鬥數值（攻擊、命中、爆擊）。第 4 節改掉戰鬥之後，要換成骰子語言。換算原則：

| 現有效果 | 改成 |
|---|---|
| 委託成功率 +3%／級（`bonus`） | 照舊累加進 `dirBonus`，達門檻 +1 顆、+2 顆 |
| 命中 +N% | 每場戰鬥重擲一顆骰 N 次（每 5% 一次） |
| 爆擊率、爆擊傷害 | 大成功的傷害倍數提高 |
| 護甲、最大 HP | 照舊（減傷、血量） |
| 駭入干擾回合、電擊 | 「駭入干擾」行動的持續回合、每回合固定傷害 |
| 迷彩倍數、鬼影 | 「迷彩繞背」的倍數、可用次數 +1 |
| 背水一戰 | HP 低於一半時強攻 +1 顆 |
| 雙槍補槍 | 強攻擲出兩顆 5 以上時多打一次（六成傷害） |

每個流派新增 1～2 張只有骰池才做得出來的卡，例如：
- 狂暴大猩猩「越痛越兇」：重傷的 −1 顆改成 +1 顆。
- 雙持「第二發」：每件委託一次，把一顆 4 或 5 當成 6。
- 速駭「預先佈線」：每件委託第一個場面 +1 顆。
- 流浪者「留一手」：付代價時可以改付報酬打折（每件委託一次）。

卡牌 id 存在存檔裡，只改效果與說明，不改 id。

## 8. 平衡目標與量測（待做）

沿用 `pnpm test` 的四種機器人（各 200 局），機器人要學會新動作：

| 機器人 | 加骰 | 代價 | 致命判定 |
|---|---|---|---|
| 謹慎 | 不加 | 選傷勢以外的 | 一律撤離 |
| 冒險 | 能加就加 | 第一個 | 一律硬上 |
| 最佳化 | 骰數 ≤2 時加 | 選當下最不痛的 | 骰數 ≥4 才上 |
| 堆義體 | 同最佳化 | 同最佳化 | 同最佳化 |

目標（沿用評審 R4 的四條，數字依骰池重定）：
1. 謹慎型幾乎全活（≥95%，不再要求 100%），名聲最低。
2. 最佳化型存活 ≥85%，名聲高於謹慎型。
3. 冒險型死亡 40～60%。
4. 沒有單一打法同時最安全又最賺。

另外量：每件委託平均擲幾次、加骰幾次、付了哪些代價；走完新宿＋灣岸的節點數與估計時間（目標是現在的 1.5～2 倍）。
