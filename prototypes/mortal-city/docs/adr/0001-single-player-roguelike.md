# 0001 從文字 MMO 改成單機 roguelike

日期：2026-11-06。狀態：已接受。

## 背景

`docs/cyberpunk-text-mmo/concept.md` 原本定的是文字 MMO：一條長期生涯、街頭工作排隊並在離線時結算、週榜、全服城市事件、真人聊天。使用者改定方向為 cyberpunk 文字冒險 roguelike，搭配豐富插圖與少量動畫。

## 決定

- 遊戲主體是單機 roguelike。一段**生涯**＝一個傭兵從建立到死亡或**退休**，沒有固定長度。
- 生涯內沿著**街區地圖**的節點前進（新宿 → 灣岸 → 秋葉原 → 丸之內，之後回到新宿並提高**警戒等級**）。每個街區的終點是**劇情大案**。
- 跨生涯只帶走**解鎖**（加進抽選池的內容）與**傳奇檔案**，不繼承數值。
- 多人只保留不需要同步遊戲狀態的部分：**每日挑戰**（同一個 seed）與排行、**頻道**裡的自動貼文。真人聊天等接上登入之後再做。
- 拿掉：離線排隊結算、週榜、全服城市事件、抵押與贖回。武裝醫療隊改成一次性的**救命保單**道具。
- 戰鬥維持「開打前選戰術、自動播放」。技術維持 React 網頁版。

## 考慮過的其他做法

- 維持 MMO，roguelike 只當成一種任務形式：長期生涯和一局一局的節奏互相拉扯，三選一的流派也沒有明確的終點可以累積。
- 牌組戰鬥：等於另做一款遊戲，文字冒險的份量會被擠掉。

## 後果

- 原本已驗證的「離開期間報告」「排隊停止條件」用不到了；規則層的自動戰鬥、危險節點、三選一可以沿用。
- `concept.md`、`quest-layers.md` 裡的 MMO 敘述改以本 ADR 為準。
