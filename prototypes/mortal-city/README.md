# 魔都傭兵終端（mortal-city）手機直式原型

Cyberpunk 文字冒險 roguelike：傭兵沿著程序產生的街區地圖一路接案，名聲升級時三選一一張卡牌、掉寶時三選一一件道具，湊出自己的流派；死了就寫進傳奇檔案，換下一個傭兵。設計決定見 `docs/ROGUELIKE-FLOW.md`，術語見 `CONTEXT.md`，方向轉換的理由見 `docs/adr/0001-single-player-roguelike.md`。UI 規範沿用 `docs/cyberpunk-text-mmo/ui-system.md` v0.4。

## 要驗證的假設

1. 「走地圖選路線、湊流派、決定要不要冒險」在新宿一個街區裡就好玩。
2. 三選一（卡牌與道具）真的會讓不同生涯走出不同流派（狂暴大猩猩／雙持／速駭／流浪者）。
3. 10～30 秒的自動段配上像素橫幅是「看戲」，不是「等進度條」。
4. 論壇終端風格在 360～430px 的手機直式仍然清楚，危險選擇不會誤點。

## 執行

```bash
cd prototypes/mortal-city
pnpm install       # pnpm 11：esbuild 的安裝腳本已在 pnpm-workspace.yaml 核准
pnpm dev           # http://127.0.0.1:5173（被占用時加 --port 5188）
pnpm test          # 規則、地圖、reducer 與機器人通關測試（vitest）
pnpm build         # 型別檢查＋打包
```

- L1：`pnpm test`。
- L2 簡易回歸：`pnpm test` 通過後跑 `pnpm smoke`（`scripts/smoke.mjs`，Playwright 手機觸控模擬，約 1 分鐘）：360／390／430 寬 × 三個分頁不能橫向捲動、地圖走兩個節點（自動段、戰鬥、結案、三選一）、重新整理後存檔不變、測試案的危險選項都寫出致命機率。第一次跑要先 `pnpm exec playwright install --only-shell chromium`；截圖在 `smoke-out/`。
- L3 完整測試：使用者手動玩完一區後，再跑 `pnpm test` 與 `pnpm build`，並用瀏覽器走完一段生涯到退休或死亡。

## 目前狀態：進行中（新宿＋灣岸）

一段生涯：

```
建立傭兵（無名傭兵：手槍＋起始裝備三選一〔駭客終端／光學迷彩貼片／強化肌腱〕，4 點屬性自由分配）
  → 新宿街區地圖（11 層）：中段 01「終電包裹」、終點 02「診所不收現金」
  → 安全屋：退休，或繼續
  → 灣岸街區地圖（11 層，委託第 2～3 階、精英難度 5）：中段 03「不存在的保戶」、終點 06「午夜轉運線」
  → 安全屋：退休（秋葉原還沒開放，「繼續」停用）
死亡或退休 → 寫進傳奇檔案 → 建立新的傭兵（新地圖）
```

街區設定在 `src/content/districts.ts`（每區的劇情案、委託難度、事件池、安全屋開場白），每區用自己的 seed 產生地圖；傭兵、卡牌、道具、傷勢、通緝都帶進下一區。

- **地圖**（`src/rules/map.ts`；畫面在 `Run.tsx` 的 `MapView`）：地圖下方「下一步可以去」列出每個能前往的節點：委託寫方向、難度、報酬、「一定要打」或安靜得手機率（委託內容由節點 seed 決定，進去就是那件）；其他節點一句說明。全息投影風的 2.5D 地圖，投影桌面往後倒 22°，起點在最下面、劇情大案在最上方；網格、依 seed 產生的街區輪廓與地名、掃描光、HUD 角框與圖例；走過的路是紅色實線，能走的路是流動的資料光，能去的節點有光柱與波紋，所在位置標「你在這裡」；進地圖時自動捲到能前往的節點。依生涯 seed 程序產生。第 1 層只有委託與事件；第 6 層只有 01；第 10 層只有診所或休息；第 11 層是 02；精英委託每區 2 個、不早於第 5 層；至少一個黑市。
- **節點**：
  - **委託**：新宿前半段難度 1、後半段難度 2；灣岸是第 2、3 階（9 個模板）。進節點時就依 seed 決定成不成功；武力委託一定要打（畫面不顯示成功率，只寫「打贏才算完成」），駭入、潛行顯示「安靜得手 X%」，失手被發現也要打。完成（不論有沒有開打）就有機率掉寶。
  - **精英委託**：新宿難度 4、灣岸難度 5（各 3 個模板；難度 5對手更硬、屬性選項門檻 +1），一定要打一場硬仗，打贏一定掉寶（稀有表三選一），接著是可能永久死亡的危險節點（撤離／硬幹／屬性選項）。
  - **事件**（`src/content/events.ts`）：新宿 10 則、灣岸 6 則（灣岸也會出現 4 則不綁地點的新宿事件），每則 2～3 個選項，有的要錢、有的要屬性、有的看機率；每則至少有一個不花錢、不要求屬性的選項。同一段生涯不會重複（跨街區也一樣；整區的事件池都遇過才重頭來）。
  - **黑市**：贓貨攤風格（手寫價牌、PROBABLY STOLEN 印章、每件一句來路）。三件七五折的貨、救命保單 ¢450、收贓（售價 40%，升級過的義體照等級加倍）。
  - **神機醫**：縫傷口（每 1% ¢6、壓力 −10）；常備義體 5 種（七五折）＋訂製義體（其他義體每次依 seed 挑 3 種，原價，`clinicOrders`），買了直接裝上，屬性不夠也能買、先放背包；升級身上的義體（Lv.1→3，效果每級 +0.5 倍、負荷 +10，費用＝原價 × 目前等級，`upgradeImplant`）。畫面寫出裝上或升級後的神經餘裕與錯亂機率。
  - **休息**：二選一，傷勢 −30% 或通緝 −2，都降壓力 10。
  - **劇情委託／劇情大案**：論壇文章＋回覆串 → 三種以上做法 → 自動段 → 可能打一場 → 危險節點（一定有不會死的選項）→ 結案。01 的結果改變 02 的內文與回覆。
- **成長**：經驗 → 等級 → 屬性點；名聲（委託每級難度 10、精英 40、事件、劇情）→ 卡牌三選一；掉寶 → 道具三選一。還有待挑的三選一時不能前往下一個節點，戰鬥與危險節點進行中先不跳出來，節點結束後才挑。
- **卡牌**（`src/rules/perks.ts`）：27 張（狂暴大猩猩 6、雙持 6、速駭 7、流浪者 7、通用 1）加 2 張保底卡（黑錢、針劑）。同一張可以再拿來升級；流派權重隨張數成長（每張 +0.5 倍，4 張以上 ×3，`styleWeight`）、稀有卡 ×0.4；主流派（張數最多、至少 2 張）每組三選一保底至少一張，同時至少一張別的卡，留轉型的路。效果全是固定修正，不另外擲骰：攻擊、HP、命中、爆擊、護甲、駭入干擾回合、回授電擊、迷彩第一擊、鬼影（多一回合打不到你）、背水一戰（HP 低於一半攻擊加成）、補槍（雙持：命中後依機率補一槍、六成傷害，用同一顆命中骰）、包紮（流浪者：打贏後回 HP）、路線成功率與報酬、戰利品機率。流派的委託加成算在對應路線：狂暴大猩猩與雙持→武力、速駭→駭入、流浪者→潛行。
- **道具**（`src/content/items.ts`）：30 件，每件標流派（狂暴大猩猩 8、雙持 7、速駭 7、流浪者 8）。一般表 13 件、稀有表 15 件（起始裝備不進表），每個流派在兩表都至少 3 件；三選一抽三種不重複的。能開「光學迷彩繞背」的只有迷彩類義體（光學迷彩貼片、聲紋消除器、幽影纖維、沙塵迷彩斗篷）。
- **道具圖示**：每件道具一張 48 px 像素圖（`public/sprites/item_*.png`，對照表 `src/content/item_icons.json`，用 `uv run --with pillow python art_src/build_items.py` 從 `art_src/sprites_raw/raw/items_*.png` 重切），框線用流派色；卡牌沒有圖示，卡框用流派色（狂暴大猩猩紅橘、雙持金黃、速駭青、流浪者沙橘），稀有卡框線加粗。
- **掉落率**：一般委託完成（不論武力、駭入、潛行，有沒有開打）每級難度 10%（`pnpm test` 有一條測試確認三條路線同難度的掉寶率差距 ≤ 2 倍）、精英委託打贏一定掉（稀有表）、事件給的一定掉、劇情結案指定道具 ×1.5；名聲每級 `12＋4×等級`。機器人各 200 局（`pnpm test` 輸出的 `[bot]` 兩行）：謹慎型全部活著，每局卡牌 7.6、道具 2.8、名聲總量 214；冒險型死 61 局，活下來的每局卡牌 12.9、道具 4.5、名聲總量 508（含死亡的全部 200 局平均卡牌 10.3）；最佳化型（屬性堆沉著 8、技術 7，挑最安全又算完成的選項）死 19 局、91 局留下舊傷，活下來的每局卡牌 12.3、名聲總量 463。機器人的起始裝備依 id 輪流挑；道具數不含起始裝備。
- **戰鬥**：開打前選戰術（正面交火／駭入智慧槍／光學迷彩繞背，依裝備開放），結果由 seed 一次算完，畫面每回合約 0.6 秒、可 2 倍速。每回合依事件播特效：被打中震動、流血閃紅與傷害數字（手機短震），打中與爆擊的閃光，駭入干擾與電擊的電流雜訊，迷彩的紫色扭曲，低血量時面板泛紅。HP 低於 20% 自動撤退，打鬥本身不會死。通緝每顆星讓對手 HP 與攻擊 +8%。
- **等待**：自動段 10～30 秒，像素橫幅播主角奔跑的街景，文字依「總時長 ÷ 行數」逐行出現（每行一筆系統紀錄：序號、左側色線，最新一行最亮），進度條依時間連續推進（斜紋流動、前端發光）；同一種節點看過一次之後可以 2 倍速。劇情委託的回覆一則一則進來（約 1.5 秒，先顯示「正在輸入…」，點一下顯示下一則），全部到齊才選做法。新訊息出現時畫面自動捲到它。
- **結案**：委託、精英委託、劇情委託結束後，右上角先滑出 toast（任務完成／部分完成／生還／委託失敗，手機短震），約 1.4 秒後（或點一下）打開「委託結案」：印章砸下、閃光與火花（失敗沒有）、報酬一列一列出現、信用點數字往上跳 → 繼續，之後才挑三選一、才能離開節點。結算也是一列一個欄位（結果、報酬、戰鬥、傷勢、通緝、壓力、經驗、名聲、戰利品）。
- **風險**：傷勢（重傷 ≥70% 時開打 HP 很低）、神經負荷（容量－義體－壓力，影響危險節點的出事機率）、通緝、救命保單（受致命傷時救一次、用掉）。
- **義體與神經錯亂**（2026-11-09）：義體不限數量，代價是神經餘裕。餘裕低於 40，每件任務（委託、精英委託、劇情委託）在自動段結束時擲一次神經錯亂（`PSYCHO`、`rollPsycho`，依 seed）：警戒（20～39）10%、臨界（1～19）30%、失控（≤0）70%，失控後每低 1 點再 +1%（最高 95%）；錯亂時依階段分成任務中斷（沒有報酬）、重傷（傷勢至少 70%＋舊傷，任務繼續）、死亡（有救命保單就被救、任務中斷），越低越偏向中斷與死亡（中斷:重傷:死亡＝警戒 6:3:1、臨界 5:2:3、失控 4:1:5）。狀態列、任務節點、地圖「下一步」都顯示錯亂機率。重武器、高階義體與終端有屬性門檻（15 件，體能／反應／智力／沉著 5 或 6，`items.ts` 的 `needs`），不夠就不能裝，可以先放背包。
- **危險節點的取捨**（2026-11-09）：冒險選項出事時 70% 是死亡、30% 是**重傷生還**（`DEATH_SHARE`）：活著、報酬與名聲照拿，但傷勢至少 70% 並留下一道**舊傷**——依那次的路線扣 1 點屬性（武力→體能、駭入→智力、潛行→反應，最低 1；角色頁標「舊傷 −N」，要用屬性點補回來）。被救命保單救回時，武裝醫療隊拆走身上所有義體抵費用（神經負荷跟著歸零）；身上沒有義體才改留一道舊傷。靠器材或屬性的選項（劇情案的器材／屬性選項、精英的屬性選項）報酬打七五折、名聲減半、神經壓力 +10。精英委託的冒險選項也扣該方向的裝備與卡牌加成。危險選項的「基準＋做法修正－裝備與卡牌加成」整段乘 1.5（`RISK_SCALE`，下限 2%）：風險變高，帶對方向的裝備省下的機率也跟著變 1.5 倍；不靠器材、屬性的冒險選項撐過去（含重傷生還），名聲再 ×1.5（`RISKY_FAME_MULT`）。起始裝備只有手槍加三選一，所以一開始只有一條路線有器材。畫面上每個冒險選項寫「死亡 X%・重傷 Y%」（`dangerOdds`，判定也用它）。
- **存檔**：生涯一欄（每個動作都存，結果由 seed 決定、重新整理不會重擲）、跨生涯一欄（傳奇檔案、看過的節點類型）。死亡或退休後只能建立新傭兵。
- **城市氛圍**：狀態列下方的新聞跑馬燈（`src/content/news.ts`：固定的城市雜訊＋依通緝、劇情案結果、名聲、救命保單、上一位傭兵的傳奇產生的新聞）；換分頁與進出節點時約 0.2 秒的故障轉場；自動段最新一行用打字機打出來。
- **音效**（`src/components/sfx.ts`）：全部用 WebAudio 即時合成，沒有音檔。按鈕點擊聲、進節點的連線音、戰鬥每回合（打中、爆擊、被打、電流、迷彩、勝負）、結案 toast 與結算和弦、低音量的雨聲環境音。第一次點擊後才發聲（瀏覽器規定），標題列右側喇叭可以關（記在這台裝置）。
- **節點背景**：新宿與灣岸各有一套（委託、精英委託、事件、黑市、神機醫、休息各一張 S2 風格的 384×160 背景；灣岸檔名是 `node_wangan_*.png`）。Codex 生成，派工與報告在 `art_src/NODE_BRIEF.md`／`NODE_REPORT.md`、`NODE_WANGAN_BRIEF.md`／`NODE_WANGAN_REPORT.md`；`art_src/build_nodes.py` 從 `art_src/sprites_raw/raw/node_*.png` 縮成 `public/sprites/node_*.png`），主角站在中間偏左、戶外疊上雨（新宿的診所與休息、灣岸的診所是室內）；自動段時換成屋頂奔跑。劇情委託 01／02／03／06 也各有一張場景背景（`public/sprites/story_<案件>.png`，派工與報告 `art_src/STORY_BG_BRIEF.md`／`STORY_BG_REPORT.md`），讀回覆、選做法、危險節點時顯示；地下的 01、02 不疊雨。
- **紀錄**：傳奇檔案、行動紀錄、測試工具（系統錯誤模擬、跑一次測試案「終電後的手提箱」、像素元件圖鑑、清除全部存檔）。
- **通訊**：近全高抽屜，夜鴉的廣播與假玩家訊息（未連線）。

還沒做：秋葉原、丸之內、警戒等級循環、起始背景與解鎖、好感與中間人私訊、每日挑戰與排行、頻道。

未驗證：「退休還是再冒一區」這個抉擇的真人手感；平衡只用機器人量過，沒有真人試玩。

## 結構

|---|---|

| `src/content/events.ts` | 事件 |
| `src/content/items.ts` | 道具型錄、掉寶表、黑市貨架 |
| `src/screens/Run.tsx` | 像素橫幅、街區地圖、安全屋、生涯結束 |

## 發現

- 名聲曲線用機器人實測（兩區、各 200 局）：每次都選不會死的平均 7.7 張卡、敢冒險的 8.8 張。每級需求 `12＋4×等級`。

- 參考圖的「紅色＝選中」與遊戲的「紅色＝危險」會衝突，所以致命一律用紅色＋⚠＋「致命 X%・可能永久死亡」文字。退休、清除全部存檔、在黑市賣東西都要按兩次（第一次按鈕改成確認文字，3 秒內再按才執行）；挑卡、挑道具、加屬性後畫面下方會出現通知，寫出哪些數值變了；有屬性點時底部「角色」分頁有紅色數字。
- 背景分頁的 `setTimeout` 會被 Chrome 降頻：用瀏覽器自動化測試時，不要在一段腳本裡 await 計時器，一步一次呼叫。
- 開發時改存檔結構要換存檔鍵（目前生涯 `mortal-city:run:v1`、跨生涯 `mortal-city:meta:v1`）。現在沒有每秒寫入的時鐘，只在狀態改變時存檔，所以可以在頁面裡改 localStorage 後重新整理來注入測試存檔。
- 自動段與戰鬥播放的計時器：callback 放 ref，不放 effect 依賴，否則父元件重新渲染就會重設計時器（自動段卡住）。
