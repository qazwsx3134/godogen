# 魔都傭兵終端（mortal-city）手機直式原型

設計文件在 `docs/cyberpunk-text-mmo/`：雙層任務見 `quest-layers.md`，UI 規範見 `ui-system.md` v0.4（主要參考 `ui/reference.JPG`）。架構文件裡的舊代號 `tokyo-text-mmo` 指的就是這個專案（城市改名為魔都之前取的）。

## 要驗證的假設

1. 論壇終端風格（參考圖）可以轉成手機直式，而且長文閱讀、危險選擇在 360～430px 仍然清楚。
2. 雙層任務接得起來：劇情委託（一次性、危險節點等玩家、可能永久死亡）＋可重複的街頭工作（排 4 件、離線結算、停止條件、週榜同類遞減、城市事件）。
3. 「離開期間報告」「每行紀錄帶當下狀態」「停止條件寫明原因」能讓自動執行被理解（借鏡 ro-idle）。

## 執行

```bash
cd prototypes/mortal-city
npm install
npm run dev        # http://127.0.0.1:5173
npm test           # L1：規則單元測試（vitest）
npm run build      # 型別檢查＋打包
```

L2 簡易回歸：`npm test` 通過後，在瀏覽器以 360／390／430px 寬開啟，五個分頁都確認 `scrollWidth <= clientWidth`，並走一次「接劇情案 → 危險節點 → 結果」與「排 4 件 → 模擬離線 30 分鐘 → 離開期間報告」。Chrome 視窗縮放不一定改變頁面寬度，可在頁面內嵌一個指定寬度的同網域 iframe 量測。

## 目前狀態：進行中（S2 16-bit／主角 A 已選定；10 張城市與道具 sprite 已完成規格整理，8 格跑步循環原圖已生成；城市橫幅接入仍待驗收）

可以玩到：

- **委託**：劇情委託看板（P01 兩案，測試案在最下方）、街頭工作列表（三方向、難度、熟練度）、工作詳情、排隊（4 件、進度條、倒數）、測試工具（1×／10×／60× 時間、模擬離線 30 分鐘）。
- **P01「終電之後」前兩案（試讀稿）**：01「終電包裹」（老K）→ 02「診所不收現金」（白蛇）。每案：論壇文章＋四則回覆（各中間人不同口吻、夜鴉廣播、MPD 公告）→ 三種做法（方向、路上傷勢、風險修正）→ 自動段 → 危險節點（一定有不會死的選項）→ 結案（夜鴉插播）。02 要 01 結案後才開，撤離也算；01 的結果讓 02 多一段不同內文。一個角色每案一次，新角色清空重來。路線試算見下方「P01 路線試算」。
- **素質判定**（戰術對上對手）：對手有「防火牆」與「感知」。你的駭入強度（智力＋駭入熟練度每 5 級 +1＋干擾裝備每件 +2，新角色 3）低於對方防火牆，「駭入」就駭不進去；你的隱匿（沉著＋潛行熟練度每 5 級 +1，新角色 3）低於對方感知，「光學迷彩繞背」會被看穿。兩者都在戰術卡上鎖住並寫明差多少；「正面交火」永遠可用。排隊時預設戰術被擋住就自動改正面交火。數值：街頭對手依難度 1／2／4 為 2／4／7；MPD 臨檢巡警 3／3、診療所保全 4／3、神坂保全 5／5、神坂回收小組 6／6、倉庫守衛 7／7（防火牆／感知）。
- **自動戰鬥**：武力路線（01 正面走過臨檢、02 踹開後門）與第 4 階武力工作「突襲企業倉庫」會先打一場。開打前選戰術，依裝備與屬性開放：正面交火（攻擊 ×1.25；武器抵押中變赤手空拳）、駭入（要駭客終端；前 3 回合對方命中 −35%，駭入熟練度每 5 級多 1 回合；神經壓力 +5）、光學迷彩繞背（要光學迷彩義體；第一擊兩倍＋潛行熟練度×5%，對方第一回合打不到你）。你的數值：HP＝100－傷勢、攻擊＝8＋等級×2＋武力熟練度＋武器 6、命中＝70%＋武力熟練度×1%。結果由 seed 一次算完（`resolveFight`），畫面逐回合播放、可跳過。打鬥本身不會死：HP 低於 20 自動撤退、委託失敗；打贏帶著傷進危險節點（傷勢會提高致命機率）。
- **行動決定結果**：危險節點除了通用的撤離／冒險，還有只屬於你所走做法的選項。走武力：可以選「把保全也打倒」（再打一場，打贏就生還、報酬最高；打輸才擲致命判定）；走駭入：月台廣播假裝 MPD 包圍／把回收清單換成空白病歷（要駭客終端，致命 6～8%）；走潛行：迷彩從背後帶人走／貼牆等下載（要光學迷彩義體，8～10%）。01 走武力打倒 MPD 巡警會通緝 +1，02 也會多一則 MPD 通報；走駭入是霧的回覆、走潛行是夜鴉的插播。
- **排隊中的打鬥**：武力工作每件都要打（打贏＝成功），駭入／潛行工作失手＝被發現也要打（打贏就帶著東西脫身）。用「排隊」裡設定的預設戰術自動打，被鎖住時改正面交火；每場在紀錄與離開期間報告留一行（對手、戰術、輸贏、掉血）。對手依難度與方向產生（`streetEnemy`）。
- **傷勢與治療**：輕傷／中傷（40%）／重傷（70%）。重傷不能接任何工作（排隊、劇情、高階），排隊打到重傷一定停；進行中的委託可以做完。狀態列顯示「重傷」與「治療」按鈕。治療三種：在公寓休養（免費，沒排隊、沒委託時自動恢復，每分鐘 −1%、重傷時每 2 分鐘 −1%，每 30 分鐘通緝 −1★，離線也算）、白蛇的地下診所（每 1% ¢6、壓力 −10、不問來歷）、魔都綜合醫院（每 1% ¢10、壓力 −30，通緝 3★ 以上不收）。角色頁顯示戰鬥數值。
- **屬性**（角色的打造；熟練度仍是做工作練出來的，兩者並存）：技術、體能、反應、智力、沉著，起始各 3、上限 20；建角有 4 點自由分配，每升一級 +1，角色頁用「＋」分配、不能退回。效果一律是（屬性－3）×係數，所以起始值等於加入屬性前的數值（舊試算與測試不變，已用固定 seed 比對確認）：

  | 屬性 | 每點效果（本作數值） | 地圖互動（危險節點選項） |
  |---|---|---|
  | 技術 | 護甲 +3（每次被打中減傷 護甲÷(護甲+40)）、神經容量 +3 | 02「拆開門禁面板」（技術 ≥ 6） |
  | 體能 | 最大 HP +8（傷勢是 HP 的百分比，撤退線是最大 HP 的 20%） | 01 做法「扒上電車車頂」（≥ 6）、高階武力「扯開貨櫃側門」（≥ 7） |
  | 反應 | 命中 +2%、爆擊率 +4%（爆擊 ×1.5） | 無 |
  | 智力 | 駭入的干擾每 2 點 +1 回合、駭客神經壓力每 2 點 −1 | 02 做法「連上存取點」（≥ 6）、高階駭入「假資料流」（≥ 7） |
  | 沉著 | 爆擊傷害 +10%、迷彩第一擊 +0.1 倍 | 01「盯著保全冷冷威脅」（沉著 ≥ 6） |

  屬性選項每條路線都看得到，不夠就鎖住並寫出差幾點；選了不會死、算完成委託。危險節點最多 4 個選項（通用兩個＋路線一個＋屬性一個）。
- **黑市（PROBABLY STOLEN）**：角色 → 裝備有兩個攤位，每件貨都標「PROBABLY STOLEN」與來歷（例如「上週還在 MPD 的證物室」）。白蛇的義體診所照原價、直接裝上；老K的後巷貨架賣智慧手槍、重型霰彈槍、軍規駭客終端（原本只會掉落），要老K信任 3、價錢 ×1.25，買了放進背包。
- **義體、裝備與戰利品**（`src/content/items.ts`）：義體可以裝好幾件，總負荷不能超過「神經容量 − 50」（技術每點 +3、每級 +4，所以技術高才裝得下第二件）。白蛇的義體診所（角色 → 裝備 → 白蛇的義體診所）賣皮下護甲（護甲 +15，負荷 30）、強化肌腱（HP +16）、反射加速器（命中、爆擊 +6%）、神經協處理器（駭入干擾 +1 回合）、光學迷彩貼片，買了直接裝上，卡片寫明裝上後剩多少空間。武器與駭客終端會掉落，也能在老K的後巷貨架買（智慧手槍、重型霰彈槍、軍規駭客終端），從背包裝上會把舊的換回背包。掉落：排隊打贏一場每級難度 4%、劇情或高階工作打贏一場 25%、高階工作完成 25%、劇情結案依案件（01 智慧手槍 35%、02 神經協處理器 50%）；每次掉落用自己的 seed，不影響戰鬥結果。背包的東西可以賣（售價 40%），付救援帳單時先抵押背包再抵押身上的。任務進行中不能換裝。角色頁分「狀態／裝備／屬性」三個分頁。
- **不同任務、不同方法**：01 多一個體能做法「扒上進站電車的車頂」（體能 ≥ 6，危險節點有專屬的「從通風井爬回車頂」）；02 多一個智力做法「連上街角的存取點」（智力 ≥ 6，專屬「讓灑水系統同時啟動」）；02 依 01 的做法多一則回覆（車頂路線是夜鴉的插播）。第 4 階高階工作的危險節點多一個屬性選項（武力：體能 ≥ 7 扯開貨櫃側門；駭入：智力 ≥ 7 假資料流引開黑冰；潛行：沉著 ≥ 7 換上保全制服），風險比硬幹低。屬性不夠的做法與選項看得到但鎖住，reducer 也會擋。
- **戰力與名聲**（`powerOf`、`enemyPower`、`powerVerdict`）：戰力＝3×√（每回合期望傷害×有效 HP），新角色 100；對手用同一把尺（臨檢巡警 42、診療所保全 56、第 1／2／4 階街頭對手 29／44／78）。工作詳情、劇情做法與遭遇戰旁邊顯示「建議戰力 N・評語」（≥1.6 倍輕鬆、≥1.15 有把握、≥0.85 勢均力敵、其餘危險），評語用目前 HP（帶傷會變差），角色頁的戰力用滿血。戰力只給人看，判定公式不變。名聲另算、不進戰力：街頭工作做成＋難度、劇情結案 +3（冒險生還 +10）、獨特委託＋難度×3；排行頁有生涯名聲榜。
- **天賦**（`TALENTS`）：技能點跟屬性點分開，每升一級 +1（新角色 0）。武力／駭入／潛行三支各三格，由上往下學、不能退回：穩定射擊（命中 +5%）→ 壓制火力（攻擊 +3）→ 硬骨頭（HP +15）；腳本庫（駭入成功率 +3%）→ 冷卻迴路（駭客壓力 −1）→ 反制程式（干擾 +1 回合）；輕步（潛行成功率 +3%）→ 影襲（迷彩第一擊 +0.3 倍）→ 退路（劇情潛行做法致命 −3%）。
- **私人通訊與信任**（`src/content/contacts.ts`）：通訊抽屜分「公共頻道／私人訊息」，私人訊息是老K、霧、白蛇各一條對話串。訊息一則一則浮現（對方「正在輸入…」，時間看字數 0.6～1.6 秒；你的回覆立刻出現），看過的存在存檔、回來接著播不重播，可按「全部顯示」，系統設定「減少動態效果」時一次顯示。中間人會私下發委託：說完後才出現兩個回覆（接下／推掉），選了他會再回一句；接下就加入排隊。一般委託可重複（每人三件，依信任開放，輪流發，報酬只比看板同階略高）；獨特委託一次性（老K「歸還的手臂」信任 8＋名聲 12、霧「刪掉一個人」8＋25、白蛇「冷藏箱」5＋15），條件到了優先發，做成送一件裝備並回私訊。接了或推了都要等 10 分鐘（遊戲時間）才發下一件；佇列滿、重傷時接不了，委託會留著。私訊的委託只能從回覆接，看板的排隊不收。信任：替他做成一件工作 +1、劇情結案 +1（冒險生還 +3）、白蛇另看診所治療（花 ¢100 以上才算）與買義體（各 +1）；可重設的測試案不給信任與名聲。每條對話串最多留 40 則。通訊入口的紅點＝有新訊息或待回覆委託的中間人數。新角色清空所有對話串。
- **劇情委託的論壇串**：回覆一則一則浮現（同上的打字動畫、全部顯示、看過不重播），播完才出現「接下委託」。P01 兩案各有一個「追問」（01 問老K「為什麼找我？」、02 問白蛇「為什麼不收現金？」，試讀稿 2026-11-05 新增），問了對方會回答；只是對話，不改報酬與風險。
- **劇情測試案**「終電後的手提箱」（看板最下方，可重設）：論壇文章＋中間人回覆串 → 選做法 → 自動安全段 → 危險節點（沒有倒數、致命選項標 ⚠ 與文字）→ 結果（撤離、生還、被救、系統補償搶救、永久死亡）。
- **角色**：等級、傷勢、三欄裝備（武器／駭客終端／義體，各給對應方向 +5%）、抵押中的裝備與贖回、神經負荷（容量 100＋4／級、門檻 40／20／1）、熟練度、醫療保單、診所治療。
- **高階街頭工作**（第 4 階，三個方向各一件）：只能線上手動接，不能排隊；接下時排隊暫停（正在做的那件做完）。自動段 → 危險節點（依方向套用文案模板）→ 撤離（不會死、沒報酬）或硬幹（可能永久死亡；生還給報酬、熟練度、週榜積分）。狀態列在其他分頁也會提示「高階工作等待你的選擇」。
- **救援帳單**：付不起時自動抵押裝備（價值高的先押，抵押價＝售價 60%）；現金加抵押不夠就不出勤、角色死亡；贖回價＝抵押價。
- **休息畫面**：休息時用「沙發＋主角」一起畫的整張圖（`sofa_rest_a`：女主角靠著椅背睡著；`sofa_rest_b`：男主角雙手枕頭躺著），比例由同一張圖決定；死亡時是空沙發。女主角睡著才冒「z」。
- **主角外觀**：角色頁「外觀 女／男」切換女主角 A 與男主角 B（`Character.look`，只影響圖、存在存檔）。城市畫面的躺姿、跑步循環依外觀換成 `hero_b_*`，底邊對齊同一個位置。跑步 8 格每秒 5 格（1.6 秒一圈）。
- **城市**：最上方是 384×160 像素座標的橫向場景；休息顯示公寓，任務中顯示東京街景，死亡時使用空房背景（沒有下雨特效）；標籤顯示目前工作與倒數。`src/components/CityStrip.tsx` 依 `src/content/scene_layout.json`、`src/content/sprites.json` 組裝 sprite，`SpriteScene.tsx` 以 CSS 顯示捲動、浮動、熱氣與「z」等效果（休息時主角不做呼吸動畫）；舊程式手繪元件保留在 `src/pixel/`。「紀錄 → 測試工具 → 像素元件圖鑑」仍可逐一查看舊元件。封鎖線事件（潛行工作推進民生補給）、區域動態（假資料）。
- **排行**：每週委託榜（同類遞減：前 20 件滿分、21～40 件 50%、之後 20%；其他玩家是假資料）。
- **紀錄**：行動紀錄、生涯結尾與建立新角色、歷代生涯、系統錯誤模擬開關、清除存檔。
- **通訊**：近全高抽屜，「公共頻道」是 DJ 夜鴉的系統廣播與玩家訊息（未連線），「私人訊息」見上方私人通訊。
- **離開期間報告**：模擬離線，或真的關掉網頁 3 分鐘以上再回來時出現。

還沒做：P01 03～06 案、伺服器（Workers／D1）、真實聊天、登入。

## P01 路線試算

致命機率＝選項基準＋做法修正－該方向裝備（起始 5%）－熟練度×1%（下限 2%），判定時再加傷勢÷400 與神經負荷罰則（`resolveDanger`）。下表是新角色（傷勢 0、熟練度 0、神經穩定）的值；致命後有保單會被救（帳單 ¢1500，可抵押裝備），沒保單就永久死亡。經驗只在撤離或冒險生還時給（01：30、02：40）。

| 案 | 做法 | 路上傷勢 | 冒險的致命機率 | 撤離 | 冒險生還 |
|---|---|---:|---:|---|---|
| 01 終電包裹 | 正面走過臨檢（⚔ 臨檢巡警 HP 50） | 戰鬥決定 | 17%＋傷勢÷400 | ¢0 | ¢600、通緝 +1 |
| 01 | 改掉車站的掃描器 | +6% | 13%＋1.5%＝14.5% | ¢0 | ¢600、通緝 +1 |
| 01 | 走維修通道 | +8% | 11%＋2%＝13% | ¢0 | ¢600、通緝 +1 |
| 02 診所不收現金 | 踹開後門（⚔ 診療所保全 HP 70） | 戰鬥決定 | 22%＋傷勢÷400 | ¢400、傷勢歸零 | ¢900、通緝 +1、傷勢歸零 |
| 02 | 接上離線病歷庫 | +5% | 19%＋1.25%＝20.25% | ¢400、傷勢歸零 | ¢900、通緝 +1、傷勢歸零 |
| 02 | 混進夜班清潔隊 | +4% | 14%＋1%＝15% | ¢400、傷勢歸零 | ¢900、通緝 +1、傷勢歸零 |

依做法出現的危險選項（新角色、基準值再加做法修正與傷勢）：01 武力「把保全也打倒」（⚔ 神坂保全 HP 60，打輸才擲 29%＋傷勢，生還 ¢900、通緝 +1）、駭入「月台廣播」（6%→2% 下限＋傷勢，¢600、不加通緝）、潛行「迷彩帶走」（8%→2% 下限＋傷勢，¢600）；02 武力「先打倒回收小組」（⚔ HP 80，打輸才擲 35%＋傷勢，¢1200、通緝 +1、治療）、駭入「換掉清單」（8%→5%＋傷勢，¢900）、潛行「貼牆等下載」（10%→2%＋傷勢，¢900）。下限 2%。01 武力路線打贏巡警另外通緝 +1。

02 的傷勢從 01 帶過來。（下面的勝率是加素質判定前的模擬：現在 02 的診療所保全防火牆 4，新角色要先把智力加到 4 才能用駭入。）戰鬥模擬（新角色 Lv.1、各 400 場）：01 的巡警三種戰術勝率都約 100%，平均掉血正面 13／駭客 9／迷彩 6；02 的保全勝率 97～100%，掉血 22／20／17；傷勢 60% 時進 02，勝率降到 52%／60%／71%。打輸＝撤退結案（無報酬，02 仍會解鎖）。兩案全撤離仍有 ¢400 與傷口治療，不會沒錢軟鎖；兩案都冒險生還最多 ¢1500、通緝 2★。

## 發現

- 參考圖的「紅色＝選中」與遊戲的「紅色＝危險」會衝突，所以致命一律用紅色＋⚠＋「可能永久死亡」文字。
- 背景分頁的 `setTimeout` 會被 Chrome 降頻：用瀏覽器自動化測試時，不要在一段腳本裡 await 計時器，一步一次呼叫。
- 開發時改存檔結構要換存檔鍵（目前 `mortal-city:v9`），而且外層頁面還開著時它的計時器會把舊狀態寫回去；要注入測試存檔，先離開遊戲頁（例如開一張圖片網址）再改。
- 遊戲時鐘每秒 tick 會讓父元件重新渲染；子元件的計時器若把 callback 放進 effect 依賴，會一直被重設（自動段卡住）。callback 改放 ref。
