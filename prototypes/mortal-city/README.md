# 魔都傭兵終端（mortal-city）手機直式原型

設計文件在 `docs/cyberpunk-text-mmo/`：雙層任務見 `quest-layers.md`，UI 規範見 `ui-system.md` v0.4（主要參考 `ui/reference.JPG`）。架構文件裡的舊代號 `tokyo-text-mmo` 指的就是這個專案（城市改名為魔都之前取的）。

## 要驗證的假設

1. 論壇終端風格（參考圖）可以轉成手機直式，而且長文閱讀、危險選擇在 360～430px 仍然清楚。
2. 雙層任務接得起來：劇情委託（一次性、危險節點等玩家、可能永久死亡）＋可重複的街頭工作（排 4 件、離線結算、停止條件、週榜同類遞減、城市事件）。
3. 「離開期間報告」「每行紀錄帶當下狀態」「停止條件寫明原因」能讓自動執行被理解（借鏡 ro-idle）。

## 執行

```bash
cd prototypes/mortal-city
npm install
npm run dev        # http://127.0.0.1:5173
npm test           # L1：規則單元測試（vitest）
npm run build      # 型別檢查＋打包
```

L2 簡易回歸：`npm test` 通過後，在瀏覽器以 360／390／430px 寬開啟，五個分頁都確認 `scrollWidth <= clientWidth`，並走一次「接劇情案 → 危險節點 → 結果」與「排 4 件 → 模擬離線 30 分鐘 → 離開期間報告」。Chrome 視窗縮放不一定改變頁面寬度，可在頁面內嵌一個指定寬度的同網域 iframe 量測。

## 目前狀態：進行中（風格與流程待使用者確認）

可以玩到：

- **委託**：劇情委託看板（置頂的測試案）、街頭工作列表（三方向、階級、熟練度）、工作詳情、排隊（4 件、進度條、倒數）、測試工具（1×／10×／60× 時間、模擬離線 30 分鐘）。
- **劇情測試案**「終電後的手提箱」：論壇文章＋中間人回覆串 → 選做法 → 自動安全段 → 危險節點（沒有倒數、致命選項標 ⚠ 與文字）→ 結果（撤離、生還、被救、系統補償搶救、永久死亡）。
- **角色**：等級、傷勢、三欄裝備（武器／作業設備／義體，各給對應方向 +5%）、抵押中的裝備與贖回、神經負荷（容量 100＋4／級、門檻 40／20／1）、熟練度、醫療保單、診所治療。
- **高階街頭工作**（第 4 階，三個方向各一件）：只能在線手動接，不能排隊；接下時排隊暫停（正在做的那件做完）。自動段 → 危險節點（依方向套用文案模板）→ 撤離（不會死、沒報酬）或硬幹（可能永久死亡；生還給報酬、熟練度、週榜積分）。狀態列在其他分頁也會提示「高階工作等待你的選擇」。
- **救援帳單**：付不起時自動抵押裝備（價值高的先押，抵押價＝售價 60%）；現金加抵押不夠就不出勤、角色死亡；贖回價＝抵押價。
- **城市**：最上方是橫向像素欄（參考 taskbar-hero 的行軍橫幅）：休息時角色躺在公寓沙發上（窗外雨夜、直式招牌、紅提燈、泡麵、睡覺的貓），排隊執行中／高階工作／劇情自動段時在東京風的街上跑步（三層視差、高架電車、居酒屋提燈、自動販賣機、斑馬線、MPD 無人機），死亡時是空房間加雜訊「訊號中斷」；標籤顯示目前工作與倒數。全部用程式畫像素（`src/components/CityStrip.tsx`，160×48 放大），沒有圖片；減少動態設定下只畫一格。封鎖線事件（潛行工作推進民生補給）、區域動態（假資料）。
- **排行**：每週委託榜（同類遞減：前 20 件滿分、21～40 件 50%、之後 20%；其他玩家是假資料）。
- **紀錄**：行動紀錄、生涯結尾與建立新角色、歷代生涯、系統錯誤模擬開關、清除存檔。
- **通訊**：近全高抽屜，DJ 夜鴉的系統廣播與玩家訊息（未連線）。
- **離開期間報告**：模擬離線，或真的關掉網頁 3 分鐘以上再回來時出現。

還沒做：正式 P01 劇情、伺服器（Workers／D1）、真實聊天、登入。

| `src/screens/` | 五個分頁與通訊、離開報告 |

## 素材

`art_src/BRIEF.md` 的派工單由旁邊的 Codex pane 生成（使用者選「直接生成」，2026-11-04），回報在 `art_src/REPORT.md`；原始大圖在 `art_src/raw/`。全部是原創角色，沒有原作商標或文字。PNG 每張約 400 KB，正式上線前要轉 WebP 並縮到顯示尺寸。

## 發現

- 參考圖的「紅色＝選中」與遊戲的「紅色＝危險」會衝突，所以致命一律用紅色＋⚠＋「可能永久死亡」文字。
- 背景分頁的 `setTimeout` 會被 Chrome 降頻：用瀏覽器自動化測試時，不要在一段腳本裡 await 計時器，一步一次呼叫。
- 開發時改存檔結構要換存檔鍵（`mortal-city:v2`），而且外層頁面還開著時它的計時器會把舊狀態寫回去；要注入測試存檔，先離開遊戲頁（例如開一張圖片網址）再改。
- 遊戲時鐘每秒 tick 會讓父元件重新渲染；子元件的計時器若把 callback 放進 effect 依賴，會一直被重設（自動段卡住）。callback 改放 ref。
