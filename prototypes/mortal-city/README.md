# 魔都傭兵終端（mortal-city）手機直式原型

Cyberpunk 文字冒險 roguelike：傭兵沿著程序產生的街區地圖一路接案，名聲升級時三選一一張卡牌、掉寶時三選一一件道具，湊出自己的流派；死了就寫進傳奇檔案，換下一個傭兵。設計決定見 `docs/ROGUELIKE-FLOW.md`，術語見 `CONTEXT.md`，方向轉換的理由見 `docs/adr/0001-single-player-roguelike.md`。UI 規範沿用 `docs/cyberpunk-text-mmo/ui-system.md` v0.4。

## 要驗證的假設

1. 「走地圖選路線、湊流派、決定要不要冒險」在新宿一個街區裡就好玩。
2. 三選一（卡牌與道具）真的會讓不同生涯走出不同流派（火力／入侵／潛行）。
3. 10～30 秒的自動段配上像素橫幅是「看戲」，不是「等進度條」。
4. 論壇終端風格在 360～430px 的手機直式仍然清楚，危險選擇不會誤點。

## 執行

```bash
cd prototypes/mortal-city
pnpm install       # pnpm 11：esbuild 的安裝腳本已在 pnpm-workspace.yaml 核准
pnpm dev           # http://127.0.0.1:5173（被占用時加 --port 5188）
pnpm test          # 規則、地圖、reducer 與機器人通關測試（vitest）
pnpm build         # 型別檢查＋打包
```

- L1：`pnpm test`。
- L2 簡易回歸：`pnpm test` 通過後，在瀏覽器以 360／390／430px 寬開啟，三個分頁都確認 `scrollWidth <= clientWidth`（Chrome 視窗縮放不一定改變頁面寬度，可在頁面內嵌一個指定寬度的同網域 iframe 量測），並走一次「地圖 → 委託 → 結算 → 三選一」。
- L3 完整測試：使用者手動玩完一區後，再跑 `pnpm test` 與 `pnpm build`，並用瀏覽器走完一段生涯到退休或死亡。

## 目前狀態：進行中（新宿切片）

一段生涯：

```
建立傭兵（無名傭兵，4 點屬性自由分配）
  → 新宿街區地圖（11 層，只能往下一層相鄰的節點走）
  → 第 6 層固定是劇情委託 01「終電包裹」、第 11 層是劇情大案 02「診所不收現金」
  → 安全屋：退休（灣岸還沒開放，「繼續」停用）
死亡或退休 → 寫進傳奇檔案 → 建立新的傭兵（新地圖）
```

- **地圖**（`src/rules/map.ts`）：依生涯 seed 程序產生。第 1 層只有委託與事件；第 6 層只有 01；第 10 層只有診所或休息；第 11 層是 02；精英委託每區 2 個、不早於第 5 層；至少一個黑市。
- **節點**：
  - **委託**：前半段第 1 階、後半段第 2 階（6 個模板）。進節點時就依 seed 決定成不成功；火力委託一定要打，入侵、潛行失手被發現也要打。打贏有機率掉寶。
  - **精英委託**：第 4 階模板（3 個），一定要打一場硬仗，打贏一定掉寶（稀有表三選一），接著是可能永久死亡的危險節點（撤離／硬幹／屬性選項）。
  - **事件**（`src/content/events.ts`）：10 則，每則 2～3 個選項，有的要錢、有的要屬性、有的看機率；每則至少有一個不花錢、不要求屬性的選項。同一段生涯不會重複。
  - **黑市**：贓貨攤風格（手寫價牌、PROBABLY STOLEN 印章、每件一句來路）。三件半價貨、救命保單 ¢450、收贓（售價 40%）。
  - **診所**：縫傷口（每 1% ¢6、壓力 −10）、半價義體（買了直接裝上）。
  - **休息**：二選一，傷勢 −30% 或通緝 −2，都降壓力 10。
  - **劇情委託／劇情大案**：論壇文章＋回覆串 → 三種以上做法 → 自動段 → 可能打一場 → 危險節點（一定有不會死的選項）→ 結案。01 的結果改變 02 的內文與回覆。
- **成長**：經驗 → 等級 → 屬性點；名聲（委託每階 10、精英 40、事件、劇情）→ 卡牌三選一；掉寶 → 道具三選一。還有待挑的三選一時不能前往下一個節點，戰鬥與危險節點進行中先不跳出來，節點結束後才挑。
- **卡牌**（`src/rules/perks.ts`）：16 張（火力 6、入侵 5、潛行 3、通用 2）加 2 張保底卡（黑錢、針劑）。同一張可以再拿來升級；已經拿過的方向權重 ×2、稀有卡 ×0.4。效果全是固定修正，不另外擲骰：攻擊、HP、命中、暴擊、護甲、駭客干擾回合、回授電擊、迷彩第一擊、鬼影（多一回合打不到你）、背水一戰（HP 低於一半攻擊加成）、方向成功率與報酬、戰利品機率。
- **道具**（`src/content/items.ts`）：18 件。一般表 6 件、稀有表 10 件，每個流派都有；三選一抽三種不重複的。
- **戰鬥**：開打前選戰術（正面交火／駭進智慧槍／光學迷彩繞背，依裝備開放），結果由 seed 一次算完，畫面每回合約 0.6 秒、可 2 倍速。每回合依事件播特效：被打中震動、流血閃紅與傷害數字（手機短震），打中與暴擊的閃光，駭客干擾與電擊的電流雜訊，迷彩的紫色扭曲，低血量時面板泛紅。HP 低於 20% 自動撤退，打鬥本身不會死。通緝每顆星讓對手 HP 與攻擊 +8%。
- **等待**：自動段 10～30 秒，像素橫幅播主角奔跑的街景，文字依「總時長 ÷ 行數」逐行出現（每行一筆系統紀錄：序號、左側色線，最新一行最亮），進度條依時間連續推進（斜紋流動、前端發光）；同一種節點看過一次之後可以 2 倍速。劇情委託的回覆一則一則進來（約 1.5 秒，先顯示「正在輸入…」，點一下顯示下一則），全部到齊才選做法。新訊息出現時畫面自動捲到它。
- **結案**：委託、精英委託、劇情委託結束後，右上角先滑出 toast（任務完成／部分完成／生還／委託失敗，手機短震），約 1.4 秒後（或點一下）打開「委託結案」：印章砸下、閃光與火花（失敗沒有）、報酬一列一列出現、信用點數字往上跳 → 繼續，之後才挑三選一、才能離開節點。結算也是一列一個欄位（結果、報酬、戰鬥、傷勢、通緝、壓力、經驗、名聲、戰利品）。
- **風險**：傷勢（重傷 ≥70% 時開打 HP 很低）、神經負荷（容量－義體－壓力，影響危險節點的致命機率）、通緝、救命保單（受致命傷時救一次、用掉）。
- **存檔**：生涯一欄（每個動作都存，結果由 seed 決定、重新整理不會重擲）、跨生涯一欄（傳奇檔案、看過的節點類型）。死亡或退休後只能建立新傭兵。
- **紀錄**：傳奇檔案、行動紀錄、測試工具（系統錯誤模擬、跑一次測試案「終電後的手提箱」、像素元件圖鑑、清除全部存檔）。
- **通訊**：近全高抽屜，夜鴉的廣播與假玩家訊息（未連線）。

還沒做：灣岸（03、06 試讀稿已寫在 `src/content/cases_wangan.ts`，還沒接進遊戲）與其他街區、警戒等級循環、起始背景與解鎖、好感與中間人私訊、每日挑戰與排行、頻道、6 種節點類型的專屬插圖（現在節點畫面共用公寓／街景兩張 sprite 場景；Codex 額度恢復後再生成）。

未驗證：「退休還是再冒一區」這個抉擇（灣岸還沒開放）；平衡只用機器人量過，沒有真人試玩。

## P01 路線試算（01＝新宿中段劇情委託、02＝新宿劇情大案）

致命機率＝選項基準＋做法修正－該方向的裝備與卡牌加成（起始裝備 5%；下限 2%），判定時再加傷勢÷400 與神經負荷罰則（`resolveDanger`）。下表是新傭兵（傷勢 0、沒有卡牌、神經穩定、通緝 0）的值；致命後有救命保單就被救（用掉一張、傷勢 70%），沒有就永久死亡。經驗：01 30、02 40；名聲：冒險生還是經驗的 2 倍，其他結案是一半。通緝每顆星讓對手 HP 與攻擊 +8%，下表的戰鬥是 0 星。

| 案 | 做法 | 路上傷勢 | 冒險的致命機率 | 撤離 | 冒險生還 |
|---|---|---:|---:|---|---|
| 01 終電包裹 | 正面走過臨檢（⚔ 臨檢巡警 HP 50） | 戰鬥決定 | 17%＋傷勢÷400 | ¢0 | ¢600、通緝 +1 |
| 01 | 改掉車站的掃描器 | +6% | 13%＋1.5%＝14.5% | ¢0 | ¢600、通緝 +1 |
| 01 | 走維修通道 | +8% | 11%＋2%＝13% | ¢0 | ¢600、通緝 +1 |
| 02 診所不收現金 | 踹開後門（⚔ 診療所保全 HP 70） | 戰鬥決定 | 22%＋傷勢÷400 | ¢400、傷勢歸零 | ¢900、通緝 +1、傷勢歸零 |
| 02 | 接上離線病歷庫 | +5% | 19%＋1.25%＝20.25% | ¢400、傷勢歸零 | ¢900、通緝 +1、傷勢歸零 |
| 02 | 混進夜班清潔隊 | +4% | 14%＋1%＝15% | ¢400、傷勢歸零 | ¢900、通緝 +1、傷勢歸零 |

依做法出現的危險選項（新角色、基準值再加做法修正與傷勢）：01 火力「把保全也打倒」（⚔ 神坂保全 HP 60，打輸才擲 29%＋傷勢，生還 ¢900、通緝 +1）、入侵「月台廣播」（6%→2% 下限＋傷勢，¢600、不加通緝）、潛行「迷彩帶走」（8%→2% 下限＋傷勢，¢600）；02 火力「先打倒回收小組」（⚔ HP 80，打輸才擲 35%＋傷勢，¢1200、通緝 +1、治療）、入侵「換掉清單」（8%→5%＋傷勢，¢900）、潛行「貼牆等下載」（10%→2%＋傷勢，¢900）。下限 2%。01 火力路線打贏巡警另外通緝 +1。

02 的傷勢從 01 帶過來。戰鬥模擬（新角色 Lv.1、各 400 場）：01 的巡警三種戰術勝率都約 100%，平均掉血正面 13／駭客 9／迷彩 6；02 的保全勝率 97～100%，掉血 22／20／17；傷勢 60% 時進 02，勝率降到 52%／60%／71%。打輸＝撤退結案（無報酬，02 仍會解鎖）。兩案全撤離仍有 ¢400 與傷口治療，不會沒錢軟鎖；兩案都冒險生還最多 ¢1500、通緝 2★。

## 素材

`art_src/BRIEF.md` 的派工單由旁邊的 Codex pane 生成（使用者選「直接生成」，2026-11-04），回報在 `art_src/REPORT.md`；原始大圖在 `art_src/raw/`。全部是原創角色，沒有原作商標或文字。PNG 每張約 400 KB，正式上線前要轉 WebP 並縮到顯示尺寸。

## 發現

- 名聲曲線用機器人實測：每次都選不會死的一區約 70 名聲（2 張卡），敢冒險而活下來的約 160（5 張卡）。每級需求 `20＋5×等級`。

- 參考圖的「紅色＝選中」與遊戲的「紅色＝危險」會衝突，所以致命一律用紅色＋⚠＋「可能永久死亡」文字。
- 背景分頁的 `setTimeout` 會被 Chrome 降頻：用瀏覽器自動化測試時，不要在一段腳本裡 await 計時器，一步一次呼叫。
- 開發時改存檔結構要換存檔鍵（目前生涯 `mortal-city:run:v1`、跨生涯 `mortal-city:meta:v1`）。現在沒有每秒寫入的時鐘，只在狀態改變時存檔，所以可以在頁面裡改 localStorage 後重新整理來注入測試存檔。
- 自動段與戰鬥播放的計時器：callback 放 ref，不放 effect 依賴，否則父元件重新渲染就會重設計時器（自動段卡住）。
