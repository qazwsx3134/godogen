# 系統驗證與里程碑證據計畫

2026-10-26；狀態：規劃草案。每系統的 `AC-Sxx-nn` 見[系統索引](../design/gdd/systems-index.md)。本頁規定如何證明 roadmap 成果，未執行的測試一律標未驗證。

## 驗證層次

| 類型 | 主要系統 | 要驗什麼 | 不足以證明什麼 |
|---|---|---|---|
| 純 domain 測試 | S01/S02/S07/S08/S09/S12/S14/S17/S18 | 公式、狀態機、重送、邊界與失敗回滾 | 真機輸入／渲染與可讀性 |
| scene 整合 | S04/S05/S06/S10/S13/S20/S21/S22 | 真正 instantiate scene、node／signal／資源引用 | 手機熱降頻與多指手勢 |
| 輸入與 UI 行為 | S03/S20/S26 | modal、事件消費、多指、safe area、文字 | 所有實機系統鍵盤／手勢 |
| 固定情境錄影 | S08/S09/S10/S23/S24 | 命中幀、聲畫、走位／選取與遮擋 | 數值／資產耐久與去重 |
| 手機真機 | S03/S04/S20/S22/S25/S27 | 小屏可讀、誤觸、背景、記憶體、熱降頻 | 未測平台／最低機型 |
| 多 client／server 測試 | S28/S29/S30，及線上 gameplay | 權威、收斂、權限、重送／斷線／重啟 | 未壓測的 MMO 容量 |
| 平衡與內容工具 | S11/S14/S15/S17/S18/S40 | 掉落／曲線／成本、引用、任務可達與缺字 | 玩家是否喜歡與是否理解 |

不為低風險文案更動寫鏡像測試；測試優先覆蓋狀態、資產、生命週期與可能回歸的跨系統關係。UI／scene 測試找實際場景節點，不重建一份假 UI。

## AC 追溯與檔案計畫

本次 40 工作包各有 3 條初始 AC，共 **120 條**。它們是驗收目標，詳細規格補齊後可拆成更多 case，不能從文件存在推成已通過。

建議每個實作階段建立 `production/qa/systems/<slug>.md`，欄位：

| 欄位 | 內容 |
|---|---|
| Requirement | AC-Sxx-nn 與正式 GDD／TDD 規則 ID |
| Preconditions | build／content version、seed、存檔、角色、地圖、硬體 |
| Steps | 可重現操作或自動化入口 |
| Expected | 狀態、畫面、事件、資源增減的具體結果 |
| Actual | 實際觀測值與錯誤／限制 |
| Evidence | log／截圖／錄影／報告路徑與 hash |
| Verdict | PASS／FAIL／NOT TESTED，及執行日期 |

正式測試檔規劃：`tests/domain/`、`tests/integration/`、`tests/ui/`、`tests/network/`；真機與玩測報告放 `production/qa/devices/`、`production/qa/playtests/`。這些是預定路徑，本次未建立空測試冒充覆蓋率。

## 里程碑最小證據

| 里程碑 | 必要證據 | 主要失敗條件 |
|---|---|---|
| M0 | 導航灰盒、UI consume、固定相機、內容驗證、最小交易／保存、真機基準 | 需轉鏡頭找路、穿透誤觸、scene 被重建、保存損壞無恢復 |
| M1 | 10 分鐘可玩循環、普攻／技能取消、一次傷害／拾取、EXP、保存 | 連招輸入需求、死亡後舊 timer 傷害、滿包吞物 |
| M2 | 3 任務、城鎮↔草原、換裝／商店／銀行、手機完整流程；多人試驗報告 | 卡任務、重複領獎、屬性重加、切區殘留 |
| M3 | 餵食／進化／精煉、成本模擬、背景／終止恢復、20～30 分鐘真機 | 重抽／重扣、離線規則不明、持續降頻未處理 |
| M4 | 雙 client／權威／AOI／重連、交易競態、server restart、負載量測 | 同物品多份、半邊交易、客戶端可偽造最終結果 |
| M5 | 每已啟動分支專屬報告 | 用未做的分支拖慢核心，或未驗就標完成 |
| M6 | 本版所有 AC 對照、可重建 candidate、支援矩陣與已知限制 | 無證據的通過宣稱、未支援平台當成已支援 |

## 真機量測 protocol

固定 build／content version、機型／OS、解析度／renderer、品質檔、地圖與負載。先冷啟動，再跑一段固定戰鬥／回城／開窗／換裝／切圖路線；短測記基準，M3 再連續跑 20～30 分鐘。

記錄平均與 P50/P95/P99 frame time、可取得的 RAM／GPU 記憶體、載入尖峰、卡頓、聲音、操作誤觸與背景返回。溫度／耗電不可取得時明確寫缺項，不補估計數。比較前後版本用同場景與負載；未選機型不定固定 MB 上限。

背景測試至少包括：觸控按住中切背景、施法中切背景、存檔中強制終止、開聊天鍵盤、從另一 app 返回、低記憶體／重開可模擬時記錄。單機與多人恢復政策分開，不以一段巨大 delta 補跑所有戰鬥 tick。

## 玩測觀察

M1 問「玩家能否知道自己選了誰、如何停下、技能為何不能用」；M2 問「是否知道回城、比較裝備、提交任務與再出城」；M3 問「是否理解寵物與精煉成本，短遊玩是否有進展」。觀察完成時間、誤觸、停滯、放棄點與自發下一步，不只問好不好玩。

先記觀察，再改設計。若要改已確認固定鏡頭／無連招邊界，需新需求；不能因測試困難就自行加回原作操作。
