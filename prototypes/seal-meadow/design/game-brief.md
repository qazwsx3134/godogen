# 蓬蓬草原：手機遊戲摘要

狀態：規劃草案；2026-10-26。來源是[手機製作基準](mobile-production-baseline.md)與[希望 Online 研究](../../../docs/research/seal-online-deep-dive-2026-10-26/README.md)。本摘要整理現有要求，不宣稱完整設計或實作已驗收。

玩家在原創 Q 版草原與城鎮間冒險，以觸控選怪、追打與自動普攻獲得材料與裝備，透過少量技能、換裝、升級與寵物養成形成可持續遊玩的練功循環。

已確認：手機執行、固定鏡頭方向與俯角、無旋轉操作、無短連招。製作基準不安排任何鍵序／節奏連招。固定鏡頭可跟隨玩家平移。

設計支柱：觸控意圖清楚、Q 版表演可讀、每次短遊玩有成長、手機持續執行穩定。保留懷舊練功氣氛，畫面與內容採原創或授權素材。

```text
出城 → 選怪／戰鬥 → 撿物／升級 → 換裝／餵寵物 → 回城整理
 ↑                                                    │
 └────────────────────────────────────────────────────┘
```

首個手機可玩版本：固定鏡頭、一塊草原、一個角色、一種可攻擊怪、觸控移動與追打、自動普攻、一個可用技能、基本經驗與掉落、最小背包、HUD、存讀檔與手機量測。數量是本次規劃提案。

完整切片再擴到 1 職業、3 種怪、2 把武器、1 套換裝、草原＋小城鎮、3 任務、2～3 技能、寵物餵食／一次進化與一條精煉規則。多人、擺攤、公會、副本與活動有獨立後期範圍，並非首版承諾。

技術基線：Godot 4.7；現有 Compatibility 與 2.5D 角色管線先驗證。主要畫面與重複物件保存為可編輯 scene；共用模組優先查 godot-kit。橫直向、原生／Web、最低手機與長期角色呈現方案仍待決定。

製作順序、文件需求與系統工作包從[製作規劃入口](planning/README.md)開始。這次交付的是文件與 roadmap，未修改遊戲程式、未生成美術、未跑真機或完成任何發佈。
