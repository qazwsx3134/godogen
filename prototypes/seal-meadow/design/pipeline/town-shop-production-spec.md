# 暖陶瓦雜貨屋：正式製作規格

2026-11-05；依使用者選定的[暖陶瓦概念圖、商店三視圖及材質參考](../art-prompts/town-style-references-2026-11-05.md)整理。這份是下一版製作目標；目前遊戲內仍是[可玩樣板](../quick-specs/town-slice-2026-11-05.md)，兩者的幾何與貼圖不可混稱完成。

## 輪廓與比例

- 保留暖陶瓦、米白灰泥、深木結構、正面木門、兩側窗、招牌、低石基，主門面向廣場。以單一主屋頂與正面小山牆形成識別；煙囪、遮雨棚及少量貨物視面數與螢幕可讀性保留。
- 起始尺寸建議：屋身寬約 **5.2 m**、深約 **3.8 m**、最高約 **4.3 m**；門約 1.0 × 1.8 m。這是建模起點，不是從 AI 圖量出的精確數字，須放回固定 42° 相機與現有角色一起修正。
- 三視圖的屋頂、棚架與附屬物需先統一成同一組寬、深、高和位置；AI 畫出的每一面不能各自作為獨立幾何。正面位於 Godot 本地 **+Z**，底部置於 `y = 0`，pivot 保持地面中央。
- 既有樣板為約 3.8 × 3.8 m，半徑 2.9 的圓形障礙只保證包住目前模型。正式版尺寸改變後，應用門階及建築在地面上的最遠頂點重新計算保守半徑，並重新測試角色可繞行、廣場及村長入口不被阻擋。若圓形障礙造成路徑過窄，先設計並測試更合適的碰撞，不靠縮小半徑掩蓋穿牆。

## 建模與面數預算

以下是製作時的**分配上限**；以倒角、modifier、三角化後的完整可見商店計算，含招牌、棚架及煙囪，但不把建築拆成子物件規避總上限。

| 部件 | 預算（tris） | 重點 |
|---|---:|---|
| 主牆與石基 | 450 | 大面保持乾淨，不逐磚建模 |
| 主屋頂 | 900 | 清楚輪廓，以材質表現多數瓦片 |
| 山牆、煙囪 | 500 | 可見邊倒角，接合處無重面 |
| 門與窗 | 550 | 視手機尺寸保留窗框與門框 |
| 木樑及招牌 | 650 | 重複件共用材質，招牌文字維持可編輯節點 |
| 雨棚及支架 | 300 | 避免薄面雙層重合 |
| 迭代餘裕 | 300 | 留給接縫修整與必要倒角 |
| **合計** | **3,650** | 低於普通模型 **4,000** 上限，實際記錄最終值 |

花盆、木桶與貨箱作獨立簡單道具時各不超過 500 tris，並另外記錄同屏總面數；不因單件合格而忽略總量。可參考本機 Kenney 素材，記錄原始套件與授權並複製依賴，不覆寫素材庫。

## 貼圖與材質

1. 先以三種[材質參考](../../art_src/concepts/town-material-study-20261105.png)定調，建立合適 UV。參考圖帶有手繪明暗、排列與展示底色，未檢查邊緣可重複性，不直接冒充可平鋪的底色圖。
2. 起始目標為一張 **512 × 512** 色彩貼圖或可共用的材質圖集；只有固定鏡頭實測看不清才評估 1,024 × 1,024。底色使用 sRGB，資料型貼圖使用線性匯入；各貼圖記錄來源、解析度及用途。
3. 瓦片、木紋以可讀的大形狀為主，避免手機尺寸的細線造成閃爍。確有需要時製作法線貼圖，優先從實際幾何烘焙或人工修正；生成的彩色材質圖不能直接當法線圖。檢查切線方向、凹凸方向、UV 接縫及光照下外觀。
4. 記錄 Godot Compatibility 的匯入格式與貼圖依賴，確認 GLB、外置圖集和 `.import` 在新工作區均可載入。現在的 Kenney 色票及 Godot 暖陶色 shader 只是暫用；完成正式材質時再移除或替換。

## 檢查與交付

```text
參考圖／統一尺寸 → 模型／倒角／UV → 底色與必要法線
         ↓                   ↓                 ↓
   角色比例與動線      面數／重面／交疊        匯入／接縫
         └───────────────────┴─────────────────┘
                             ↓
                遊戲鏡頭、移動閃爍與手機驗收
```

- 交付可編輯 `.blend`、完整 GLB、必要貼圖、授權記錄、可編輯 `.tscn`，以及實際三角面與自動網格檢查報告；保留可更改的商店位置、招牌和碰撞參數。
- 靜態檢查退化面、完全重複三角面、非流形邊與 BVH 交疊候選，人工確認接縫；這些不等同證明畫面永遠無閃爍。實際用角色圍繞門、側面和入口行走，檢查穿牆、卡住、角色被遮擋及閃爍。
- 在 1280×720 與另一個手機橫向比例檢查店面、村長、傳送點及 UI 的可讀性；記錄同屏 draw calls／三角面／幀時間，手機瀏覽器與 iPhone 另做實機驗收。
