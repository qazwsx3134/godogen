# 像素水族箱｜執行方案

以[首版規格](SPEC.md)為驗收基準。先解決觀賞距離能否辨識特徵，再做養成與玩家回訪。以下為單人原型工作量粗估，尚未以實際製作速度校正。

| 階段／粗估 | 工作與交付物 | 通過條件 |
|---|---|---|
| M0 魚的畫面，2–3 工作天 | 建立可編輯滿版主缸、透視相機、前後景、點魚面板和縮放。用一套鬥魚模型、兩款尾鰭、兩款材質組合做四尾同缸。錄一段游動、轉身與展鰭 | 在 720p、1080p 的正常觀賞距離，測試者不開魚卡可分出長尾與銀紋。回看轉身確認尾緣連續，月牙不被水光蓋過。若辨識困難，先加大尾形差與月牙面積，再評估渲染解析度 |
| M1 買卵到成年，2–3 天，接 M0 | 建立個體資料、商店、孵化盤、魚卡、投餌、成熟條件與基本存檔。可從新檔養出兩尾成魚 | 逐步走完買卵至成年；滿缸買卵不扣款，一粒餌只算一餐，重開保留個體和成長 |
| M2 放置育種，2–3 天，接 M1 | 實作同種成魚自動配對、性狀規則、冷卻、親緣、圖鑑與送養 | 離線產卵與孵化按事件時間推進，重開時保留同一子代。親魚送養後仍可查看子代來源 |
| M3 擴缸與回訪，2–3 天，接 M2 | 接上 XP、成就、裝飾、擴缸、離線結算及低資金復原。完成手機用的可收合背包、觸控取景與布置 | 一代內能付得起擴缸；原缸的魚與造景保留。關閉後跨越孵化時間，回來看到摘要，再開一次無重複獎勵 |
| M4 手動試玩與定版，1–2 天，接 M3 | 給首次接觸的玩家一個新檔，記錄首次投餌、首次配對、子代孵化的時間與卡點 | 玩家能獨立完成一代，指出子代繼承哪項特徵，並挑出下一對親魚。先依手動驗收修正讀不清的特徵、等待空窗或金流，再跑完整回歸 |

總計約 9–14 工作天，假設手機觸控與桌面滑鼠共用遊戲規則、一套魚骨架與三件簡單裝飾。M0 完成後以實際模型、動畫製作時間重估。

## 場景與資料責任

- 主場景持有魚缸世界的 SubViewport、透視相機及獨立解析度的 Control UI。魚缸、魚、魚卵、三件裝飾、魚卡、育種頁、商店與圖鑑使用可編輯的 .tscn；根場景在編輯器中能看見代表性魚、裝飾與 UI 間距。
- 魚種 Resource 指向模型、骨架與材質，特徵對應表指定尾形、遮罩和顯示名稱。經濟與成長數值集中在一份原型設定。性狀組合直接驅動魚模型、預覽及圖鑑，四種表型共用游動行為。
- 養成邏輯接受目前遊戲時間；遺傳邏輯接受亂數來源。測試可直接推進時間或指定親源選擇。場景負責動畫、點選及顯示；扣款、產卵、經驗與存檔由同一遊戲狀態提交。
- 建置前從 godot-kit 的存檔契約挑選適合模組，以 sync.sh 同步。使用 Godot 儲存場景並以 headless 匯入。README 記錄入口、可調整的相機與泳動範圍、UI 節點及實際驗證指令。

## 驗證安排

| 層級 | 時機 | 最低證據 |
|---|---|---|
| L1 | 各規則完成 | 用可控時間驗證孵化及成年交界；列舉兩個特徵的所有親源選擇核對機率；驗證 XP 門檻與容量邊界 |
| L2 | UI、金流及存檔串接 | 從主場景買卵到第一胎，覆蓋滿缸、同種配對、無效投餌、道具回售、單指拖曳、讀檔與時鐘倒退；同一操作只扣款或發獎一次。修改 scene 間距後啟動仍保留，離開遊戲後來源 scene 無個體狀態寫回 |
| L3 | 玩家手動驗收後 | 完整回歸加上指定桌面環境的滿缸試玩；記錄機器、解析度與幀時間，初始目標 1080p、8 尾、60 FPS。交付可玩桌面版、原始場景、四表型對照與驗證紀錄 |

## 首版之後

第一輪擴充先選一個輪廓與游姿明顯不同的真實物種，驗證新增魚種所需模型、動畫和設定，再加幻想品系。玩家交易排最後獨立立項，屆時定義帳號、伺服器的魚隻所有權、雙方交割和中斷復原，並決定單機魚是否可進交易市場。

M0 外觀預覽已加入紅蓮燈（Cardinal tetra）、三款七彩神仙及雌雄オイカワ供辨識與游姿比較。鬥魚開局之後已接入紅蓮燈養成，孵出首胎解鎖商品。七彩神仙與オイカワ目前可在展示缸觀察。可參考模型庫的細長輪廓、紅藍橫帶以及尾鰭擺動，再以缸內觀賞尺寸重畫像素色塊。淡水套件有紅蓮燈、七彩神仙和オイカワ，提供照片貼圖與 three.js 程序幾何。要在 Godot 中保留其造型或動作，可選擇移植對應部分或依參考重建。海水套件則提供 GLB 網格，游泳動作由原套件的程式與 Shader 驅動。作者公開授權涵蓋模型、貼圖及動作程式（CC0 1.0）。[模型庫](https://cda-social.github.io/aquarium/models-gallery.html) · [淡水魚套件與 README](https://cda-social.github.io/aquarium/kit/freshwater-fish-kit.zip)
