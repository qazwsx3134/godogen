# 景深、美術風格與船艙佈置

2026-10-25；分析與實作：Sol。接續使用者指出的移動景深、美術風格與佈置需求。

## 景深感：讓移動揭露距離

使用者補充原作移動時具有景深感；既有實機截圖也能辨識天空、遠景、船、人物、水面與近岸生態的層次。目前沒有逐幀量測原作每層的位移率，也沒有確認是否使用景深模糊或哪一種渲染節點。因此，下列比例是 Godot 原型的設計值。

| 層次 | 原型內容 | 鏡頭移動時的畫面位移倍率 | 視覺處理 |
|---|---|---|---|
| 極遠景 | 天空、環狀行星、雲 | 0 | 大形體、低頻細節、固定構圖 |
| 遠景 | 遠島 | 0.20 | 低對比、偏空氣色 |
| 中景 | 遠岸異星林帶 | 0.46 | 輪廓簡化、霧藍綠 |
| 主體層 | 碼頭、人物、近岸樹與住家船 | 1.00 | 互動焦點、較清晰輪廓與材質 |
| 前景 | 近處水草 | 1.30 | 較深輪廓、局部遮擋、快速掠過 |

```text
固定天空／行星
      ↓
遠島 0.20 → 中景林帶 0.46 → 人物與碼頭 1.00 → 近景草 1.30
  留白          色差              清晰             遮擋
```

景深感不只靠速度：物體縮小、遠景降對比、色彩向空氣色靠攏，以及前景對後景的遮擋共同建立距離。此版以這些方式維持像素輪廓。若所有層同樣銳利、同樣飽和，即使移動倍率不同，畫面也容易像數張貼紙。

Godot 場景是 [depth_layers.tscn](scenes/depth_layers.tscn)。`MidShore` 與 `NearPlants` 的編輯器位置是各自原點，腳本只加上鏡頭相對位移；根節點可調整 `mid_speed` 與 `foreground_speed`。不需在執行時重新生成美術節點。`foliage.gdshader` 用量化的頂點位移讓樹冠與近景草輕晃；這是本作實作方式，未推定原作使用相同 shader。

## 美術風格：色彩、比例與生活細節要一起成立

從已取得的原作港口、商店與夜間船邊畫面，可觀察到像素輪廓、異星植被、大面積海洋與天空、木質生活物件，以及暖窗與冷色水域的對照。分析重點如下。

- **角色尺度**：小人物配大環境，讓看景有份量；操作提示仍要清晰，避免人物小到難找。
- **形狀語彙**：樹冠、行星與水下生態提供陌生感，船屋、木板與家具提供熟悉感。每個物件都奇形怪狀，反而容易失去可閱讀的生活場景。
- **像素密度**：輪廓階梯、材質高光與細節顆粒應保持一致。此版是程式繪製的 SVG 像素風資產，仍有尺度混合與細節較疏的限制，尚未達到原作的手繪像素完成度。
- **冷暖分工**：藍綠與紫色海灣承載環境，米黃燈光、暖木家具作視覺停靠點。燈光應影響附近色感，不能只有一個高亮黃點。
- **等待時的動態**：水面、反射、樹冠與光點讓靜止也值得看。幅度要低，避免所有物件同時強烈晃動。
- **可佈置物件的可辨識性**：立燈、盆栽、躺椅與層架用相同木色與海綠色高光；物件輪廓應在不看名稱時也能區分用途。

本輪新增八張原創 SVG：船艙、四種家具、燈光罩、中景林帶、近景草。沒有將原作截圖剪入遊戲，也沒有生成 AI 圖像。

## 佈置：把收穫變成可見的個人空間

原作 Steam 說明提到船內裝飾；目前未進入原作完整的佈置流程，無法確認其購買、擺放限制、旋轉、物件吸附與存檔方式。下面是參考這項吸引力製作的原型流程，不列作原作已驗證規則。

按 H 或「船艙佈置」可進入小船。四種家具樣品免費使用，先讓玩家試構圖；沒有接到商店與家具購買經濟。

```text
選家具 → 半透明預覽 → 點空格放置 → 自動保存版面
                         ↓
                移動／翻轉／收回
                         ↓
                   離開後再次開啟
```

| 功能 | 此版行為 |
|---|---|
| 家具選擇 | 暖光立燈、異星盆栽、木製躺椅、收藏層架 |
| 放置預覽 | 半透明物件、格位提示；占用格會變紅 |
| 擺放限制 | 64px 格線、15×4 範圍、最多 20 件；每件占一格 |
| 移動 | 先點現有家具，再點空格；右鍵取消待移動選擇 |
| 翻轉 | 放置前按 R 左右翻轉；既有物件可收回再翻轉放置 |
| 收回 | 選收回後點物件；樣品可免費再放 |
| 顯示順序 | 依地板位置決定前後遮擋；立燈帶暖色光罩 |
| 存檔 | 家具種類、位置與翻轉資料寫入既有玩家存檔；舊存檔無欄位時用預設配置 |
| 暖燈升級 | 保留原有 2 素材的船外暖燈功能，移至船艙工具列 |

家具的腳底格位不重疊，但高物件仍可能在視覺上遮擋後排，這是側視佈置的自然結果。此版尚無自由角度旋轉、牆面裝飾、不同占格尺寸、拖曳、撤銷／重做或船艙擴建。船艙是獨立的佈置畫面，未做角色在艙內走動。
