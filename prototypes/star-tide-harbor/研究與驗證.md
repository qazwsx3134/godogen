# 《獵戶座之藍》研究與「星潮小港」驗證

日期：2026-10-25。目的：研究使用者喜歡的橫向、異星海洋與悠閒小品氛圍，並製作能立即試玩的 Godot 參考原型。

本輪補充：釣魚核心已依實機截圖與使用者說明改版。詳細證據、體驗分析與 Godot 對照見 [釣魚體驗分析](釣魚體驗分析.md)。分析由 Sol 負責，Luna max 負責實機原始觀察與補拍。

移動視差、美術與家具佈置亦已補上[分析與實作對照](景深美術與佈置.md)。原型已有五層景深感與可保存的四種家具佈置，原作佈置操作仍未完整實測。

## 來源與證據範圍

官方來源為 [Steam 商店頁](https://store.steampowered.com/app/4264000/Orion_Blue/?l=tchinese)。開發／發行 EXLIX，本次查閱仍未正式發售，頁面標示預計 2026-11-29，另有 Demo。日期可能受地區與更新影響。

使用者授權後，直接啟動這台電腦已下載的 **Orion Blue Demo**，以當時空白第三欄建立 `Tide`。首次說明明示試玩範圍為遊戲內 10 天。本輪是啟動、創角、港口、居民、商店、裝備與出海釣點的第一輪實機觀察，沒有驗證完整 10 天內容或正式版。

部分流程同時有使用者操作協助，工具遇到實體輸入時先重新觀察再操作；因此不將所有進度歸因於代理單獨完成。

證據 `evidence/orion-*` 為本機研究截圖。依 Godogen 既有研究資料的做法，這些畫面留在本機、排除 Git／LFS。原型渲染截圖也保留本機，可由 `tools/capture.gd` 重新產生。

## 為什麼它的風格成立

1. **畫面比例**：人物只佔小區域，天空、水域與環境有足夠留白；橫向視點讓人能長時間停留看景。
2. **冷暖對比**：藍綠海洋與異星天空是底色，窗戶、燈火與木材提供可停靠的暖色焦點。夜景不是單純把畫面壓暗。
3. **密度分工**：遠方大形體簡潔，近岸水草、木板、招牌與花朵較密；大形體建立世界，小細節建立生活感。
4. **熟悉與陌生並存**：旅居小船、商店與居民是熟悉的生活，巨大行星、異形樹冠與發光生態提供奇幻感。
5. **動態不是只有角色**：雲、水、倒影、飄浮光點與環境動植物讓等待本身有觀賞價值。
6. **介面像物件**：米色面板、棕色邊框、像素字與圖示維持物件感；對話、背包與商店沿用相近的紙板／木框語彙。

以上為畫面分析，不是原作 shader 或引擎的逆向結果。未取得原始碼或 profiler，不能宣稱其倒影、光照、粒子由哪種技術實作。

## UI Layout 與節奏取捨

```text
音樂播放器                             情境操作提示
                                        當前任務
              天空／遠景／海灣
              角色、居民或船隻
底部：快捷背包列                         背包入口

對話時：底部寬對話框＋右側人物立繪
商店時：中央商品格＋商品詳情＋數量與購買
```

它把常駐 UI 壓在四周，盡量保留中央景色。需要管理時再展開大的背包或商店。這很適合少量操作、長時間看景的遊戲。相對的，新手要先完成創角、對話、商店與三件裝備配置，才開始釣魚；若目標是「點開就放鬆」，可以用已備妥釣具的第一幕縮短進場時間。

裝備操作在邏輯上清楚，但拾取與放下是兩次輸入；未觀察到自動裝備捷徑，不能聲稱沒有。圖示頁籤需要懸停或學習，中文長文也要確認不同解析度的可讀性。

## 小品玩法的循環

```text
換釣點／準備釣具 → 等待、觀景、釣魚
         ↑                  ↓
       生活升級 ← 資源用途／圖鑑／居民
```

分析重點不是是否能「無限刷魚」，而是每次帶回的魚是否帶來不同用途。收集、材料、關係與家居若爭用同一尾魚，就能提供溫和的選擇。放置模式應降低操作頻率，手動操作則提供更直接的參與感；實際效率差、失敗懲罰、魚餌消耗與稀有度公式，本次尚未量測。

## Godot 原型的對應範圍

| 原作吸引力 | 星潮小港第一版 |
|---|---|
| 橫向環境與生活感 | 2400px 碼頭、攝影機跟隨、滑鼠／鍵盤散步 |
| 異星水域 | 原創環狀行星、五層視差、薄暮配色、風動植被與水面 shader |
| 釣魚核心 | 選點拋竿→水下收放線誘魚→張力管理→偶發連點角力→捕獲；過緊／過鬆可失敗重試 |
| 放置 | 原型輔助示範可自動完成流程；未還原原作的放置效率與規則 |
| 收集與材料 | 六魚種、近岸／遠岸魚池、重複魚分解 |
| 居民與家居 | 一位居民、一次送禮、四種家具的船艙佈置與船外暖燈 |

釣魚互動結構依使用者補充重做；速度、吸引範圍、張力與角力門檻是原型自行設定，尚未量測原作。資源成本、魚池、居民台詞與角色均為原創。原型與原作的美術細節量、動畫、內容深度仍有明顯差距，這版適合先驗收互動結構與節奏方向。

## 原型驗證與限制

Godot 4.7 已完成匯入、啟動與核心邏輯測試，結果見 [smoke-results.json](evidence/smoke-results.json)。有實際 OpenGL 渲染截圖，並非只提供設計稿。主場景包含可編輯 saved scene 與重複卡片子 scene，正常執行不會自動重建場景。

尚待更完整驗證：長時間釣魚手感、多尺寸視窗、不同電腦效能、原作完整釣魚結算及佈置操作、居民日程與戀愛、日夜影響魚池、保存與讀回的異常情境。

第一版沒有移植原作素材，沒有把官方描述當作實機驗證，也沒有用短程程式測試宣稱玩家一定覺得好玩。接下來最有效的驗收是：讓使用者玩 3–5 分鐘，再決定要優先深化美術、釣魚操作或生活互動。
