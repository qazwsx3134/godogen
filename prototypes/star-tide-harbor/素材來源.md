# 素材與授權記錄

- `assets/*.svg`：本次以 `tools/make_art.py`、`make_cabin_art.py` 與一次性 `upgrade_fishing.py` 編寫的原創 SVG 像素風資產，沒有取用 Orion Blue 遊戲圖像。
- `assets/water.gdshader`：本次編寫的 CanvasItem 水面效果，不代表原作採相同渲染技術。
- `assets/foliage.gdshader`：本次編寫的量化頂點風動，維持像素輪廓。
- 音樂與提示音：使用 Godogen `godot-kit/synth.gd` 程序合成；沒有擷取或重用原作音訊。
- `assets/ui_font.ttf`：既有 Godogen 原型的 Noto Sans TC 字型副本；依 SIL Open Font License 使用，附 [Noto-LICENSE.txt](assets/Noto-LICENSE.txt)。
- `addons/proto_kit/scene_builder.gd`、`atomic_file.gd`、`synth.gd`：從同一 Godogen repo 的 `prototypes/godot-kit/addons/proto_kit` 複製，保持原文，未修改副本。因工作區位於 repo 外，先同步本原型實際需要的三個模組；整合回 repo 後可用 kit 的同步流程更新。
- `evidence/orion-*`：以使用者授權操作的 Steam Demo 截圖，只供研究比對，不是可重用遊戲素材。證據目錄有 `.gdignore`，不匯入遊戲資源。

沒有使用 AI 圖像生成，也沒有安裝外部 Godot 外掛。
