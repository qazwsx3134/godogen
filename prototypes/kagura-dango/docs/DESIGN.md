# 丸子大胃王：神樂生日快樂（設計）

銀魂同人、非商業的節奏遊戲，神樂生日（11/3）紀念。故事取自原作第 66 篇的丸子大胃王比賽：銀時和新八食量有限，後來全員改成用各種方法幫神樂吃丸子。

形式參考「節奏天國」這類遊戲：每關是一個短小、只用一個按鍵的節奏小遊戲，靠聲音提示抓拍子，結束時給評價。三關與終局都依丸子比賽的情節自行設計，不重現任何既有作品的小遊戲。

## 平台與操作

- 手機橫式網頁（itch.io），設計解析度 640×360，`expand` 適配長螢幕。
- 第 1 回合點左／中／右三分之一的畫面（電腦 ←↓→ 或 A S D）；第 2、3 回合點畫面任何位置（也可以用空白鍵、Z、J）。之後若加入「按住→放開」的關卡再擴充。
- 第一次進入建議先做延遲校準（藍牙耳機延遲很大）。

## 一場比賽（草稿，玩法待試玩確認）

順序寫在 `data/match.json`：

```
裁判開場（萬事屋隊 vs 對手隊）
  → 第1回合 三人齊吃    112 BPM，強度 1，30 串
  → 銀時、新八吃撐，作戰變更：全部餵神樂
  → 第2回合 銀時拋丸子  124 BPM，強度 2，28 串
  → 最終回合 全力餵食   136 BPM，強度 3，42 串
  → 裁判宣布勝負 → 神樂生日快樂 → 比賽結果
```

| 回合 | 玩法 |
|---|---|
| 1 三人齊吃 | 出餐口丟出一串，口味決定給誰吃，提示音的高低也不同：紅豆（低音）→左邊的銀時，醬油（中音）→中間的新八，三色（高音）→右邊的神樂。兩拍後落下，點那個人那一側的畫面（電腦：←↓→ 或 A S D）。點錯人算「餵錯人」，視為漏掉 |
| 2 銀時拋丸子 | 銀時拋「咚」兩拍落、快拋（高音）一拍落、半拍連拋、最後大串；點畫面任何位置 |
| 3 全力餵食 | 同第 2 回合，但有三連拋、連續快拋、兩個大串，密度最高 |

- **難度逐回合提高**：靠 BPM、密度與花樣，判定窗不縮小。
- **演出逐回合加強**（`stage.gd`，依譜面的 `intensity`）：
  - 觀眾從 16 人增加到 32 人，跟著拍子跳得越來越高。
  - 燈籠閃得越來越亮，布幕從紅變成橘紅。
  - 強度 2 以上，完美時會震屏；強度 3 加上集中線，大串時會大震。
  - 音樂一回合比一回合多層次：第 1 回合是鼓和貝斯加輕旋律，第 2 回合加主旋律，第 3 回合加十六分音符的 hi-hat、拍手和高八度旋律。
  - 演出只在背景，不擋丸子的軌跡和嘴巴；對手隊和觀眾都不發聲，玩家只需要聽提示音。
- **神樂越吃越胖**：吃下的串數跨回合累積（`MatchState`），身體寬度從 1 倍漸漸變成 1.9 倍。嘴的位置不變，所以落點仍然對得上。銀時和新八在第 1 回合各吃 8～9 串就撐到極限，會臉紅冒汗。
- **對手隊**：在後方桌子照節奏吃，三回合共 67 串，盤子越疊越高，記分板即時比較雙方的串數。萬事屋吃得比對手多就贏，滿分是 100 串，至少要吃 68 串。
- **裁判**：開場介紹比賽，每回合開始時喊「開始！」、結束時喊「停！」，最後宣布勝負。網頁版開頭音樂還沒響的那約 1 秒，畫面顯示「預備……」。
- 裁判和對手隊目前是通用的佔位角色；原作裡的具體人物等作者指定。

## 美術

像素漫畫風：大顆像素、粗外框、誇張動作，手機小螢幕上一眼看懂。角色約 96 px 高、背景 400×180，畫面上放大 2 倍。提示詞與檔名表在 `art_src/PROMPTS.md`。

## 判定與評分

判定窗（相對正拍的秒數，手機寬鬆版）：

| 等級 | 範圍 | 分數 |
|---|---|---|
| 完美 | ±0.035 s | 100 |
| 不錯 | ±0.075 s | 85 |
| 勉強 | ±0.120 s | 50 |
| 漏掉 | 超過或沒按 | 0 |

- 一下點擊會配給「窗口內最早的、還沒判定的提示」，而不是時間最近的那個：136 BPM 的半拍連拋，兩個窗口會重疊，第一串點晚了也不會搶走第二串。
- 關卡分數是所有提示的平均分；沒有對到提示的多餘點擊不扣分，只播空咬動畫。比賽總分是三回合的平均。
- 評價：80 分以上「大胃王」、60～79「吃飽了」、未滿 60「再來一盤」。結算時由角色講一句評語。
- 每首曲子固定 BPM，不做變速。

## 時間與校準

- 遊戲時間＝音樂播放位置（`get_playback_position` 加上混音延遲修正）。如果網頁版的播放位置不穩，改用「開始播放的時刻＋ticks」，以實測結果決定。判定時再減去使用者校準的偏移。
- 校準畫面：100 BPM 牛鈴，玩家跟著點 8 次以上，取平均偏差當作建議偏移。
- 測試用可注入的時鐘，跑在 `--fixed-fps` 的遊戲時間上，不依賴牆上時鐘。

## 音樂與音效

- 曲子由 `tools/bake_music.py` 離線合成成 WAV。銀時拋串之類的提示音直接混進音軌，網頁版不會有逐幀播放的抖動；玩家點擊的咬下聲即時播放。
- 譜面在 `data/songs/<id>.json`：`bpm`、`offset`（第 0 拍在音檔中的秒數）、`end_beat`、`cues`（拍數＋類型）。烘焙與遊戲讀同一份檔案。之後換正式曲目時，換音檔、改 `bpm`／`offset` 即可。

## 參考與取材界線

- [RhythmSheriff](https://github.com/golen87/RhythmSheriff)（沒有授權檔，只參考做法）：「拍數→提示」的譜面、每首曲子只記 offset／BPM、結算時依評價給角色評語。
- [PolyrhythmMania](https://github.com/chrislo27/PolyrhythmMania)（GPLv3，不複製程式碼）：分等級的判定窗、節拍器校準取平均偏差、0～100 分換三段評價。
- 兩者的玩法與素材都不使用。
