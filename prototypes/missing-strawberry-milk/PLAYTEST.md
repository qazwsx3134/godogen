# 《消失的草莓牛奶》測試與試玩

更新：2026-09-16。此文件分別記錄現有文字雛形的功能基線、待執行的真人試玩，以及 2D 第一人稱改編版的驗收。

## 1. 這一輪要回答什麼

沿用 [銀魂概念文件](../../docs/gintama-like/chat-3.md) 的問題：玩家願不願意讀完、是否理解人物關係、吐槽是否好笑、是否想試另一個選項。再加上第一人稱改編需要知道的問題：玩家目前以為自己扮演誰。

**當前版本**：文字對話、三位詢問對象、三句吐槽、兩秒選擇窗、逾時與兩種收尾。圖片／音效欄位尚未實際播放；條件呼應、點擊物件、推理解謎與存檔列在下一版的 [roadmap](../../docs/interactive-fiction/ROADMAP.md)。

## 3. 第一次真人試玩：現有文字版

**狀態：待執行，尚無受測者結果。** 先安排 5 人，記錄每人對銀魂的熟悉程度；盡量包含熟悉與不熟悉角色的人。每人預留約 15–20 分鐘，包括自由試玩與訪談；實際故事遊玩時長由觀察記錄。

### 主持流程

1. 給受測者相同版本，僅告知「請照自己的想法玩，可以說出正在想什麼」。首次遊玩先讓畫面與文本自行說明角色、目標與吐槽。
2. 觀察點擊、停頓、重讀、笑／微笑、跳字、亂選與逾時；記錄對應的台詞或段落名稱。遇到無法推進的技術問題才介入，記錄介入原因。
3. 到收尾後先詢問理解，再詢問感受。避免先揭露正確吐槽或另一個結局。
4. 問完後提供重新開始的機會，記錄是否主動想試別的選擇。

### 訪談題目

- 你覺得自己扮演誰？一開始想做到什麼？
- 為什麼先問那個人？三個詢問選項在你看來有什麼差別？
- 哪一段讓你覺得好笑、奇怪，或看不懂？
- 你選那句吐槽的原因是什麼？如果逾時，當時是在閱讀、思考還是操作？
- 你看完所有吐槽選項了嗎？倒數增加緊張感，還是讓你來不及理解？
- 你覺得自己的選擇改變了什麼？你希望哪個角色記得你剛才的行動？
- 還想再試一種選擇，或繼續看這群人遇到下一件事嗎？為什麼？

### 每人紀錄表

複製以下欄位，每位受測者填一份。記錄觀察或原話，未觀察到的項目填「未觀察」。

| 欄位 | 填寫內容 |
| --- | --- |
| 受測者代號／日期／版本 | 待填 |
| 銀魂熟悉程度／裝置 | 待填 |
| 首次完成時間／是否需要協助 | 待填 |
| 詢問對象／吐槽選擇／收尾 | 待填 |
| 自認的玩家身分與目標 | 待填 |
| 有效笑點／不理解處，含段落 | 待填 |
| 吐槽是否看完／逾時原因 | 待填 |
| 察覺的選擇後果 | 待填 |
| 是否主動重玩／想繼續，附原因 | 待填 |
| 朋友的改稿建議／需要的素材 | 待填 |

### 如何決定下一輪

以下是小樣本的方向門檻，用來指定下一個修改，不作市場推論。

- **操作**：至少 4/5 人自行到收尾。若因介面或流程卡住，先修操作。
- **故事理解**：至少 4/5 人能說出牛奶不見、調查與黑影的關係；若人物身分不清楚，P1 的首要工作就是主觀視角與開場交代。
- **喜劇／興趣**：至少 3/5 人能指出一個笑點或角色反差，至少 3/5 人有重玩或看下一段的意願。若不足，優先與朋友改稿。
- **吐槽時限**：記錄因未讀完而逾時的人數。若 2 人以上反映閱讀不足，下一輪製作無時限對照版本；重新觀察理解與壓力，保留每次版本的紀錄。
- **選擇後果**：目前的詢問 Flag 尚未被後文讀取。把玩家期待的角色回應收進 P2，分開記錄既有結尾差異與未實作的詢問呼應。

無時限版本目前尚未實作；重玩相同文本會產生熟悉效應，試玩比較時記錄順序，不把第二次更快作答直接歸因於設計改善。

## 4. 下一版的驗收：待功能完成後執行

| 改編能力 | 要走的操作 | 預期結果 |
| --- | --- | --- |
| 銀時主觀視角 | 看開場、與新八交談，再說明自己是誰 | 能從文本與畫面理解玩家身分 |
| 點擊物件 | 逐一查看物件、關閉特寫、重新查看 | 回到正確場景；同一線索不重複取得 |
| 條件呼應 | 分別先問新八／神樂／房東，再到黑影或收尾 | 出現對應角色的後續回應 |
| 線索與推理 | 以不同順序取得線索；答錯、看提示、重試 | 有可理解的依據；探索順序不造成卡死 |
| 兩種收尾 | 分別走到成功與失敗結果 | 回應玩家行動，保留喜劇收束 |
| 存讀進度 | 在線索後與分支後存檔，關閉再繼續 | 段落、線索與角色回應一致 |
| 作者交接 | 朋友改一句話、換一張圖，兩人共同預覽 | 能記錄實際協助步驟，作為 P4 工具需求 |

## 5. 問題回收

每次試玩只選最影響體驗的 1–3 個問題進下一輪。每個問題記錄「受測者／版本、段落、觀察、預期、修改、重測結果」。功能修正重跑對應的狀態與瀏覽器案例；文本修改由朋友與新試玩者確認基調。
