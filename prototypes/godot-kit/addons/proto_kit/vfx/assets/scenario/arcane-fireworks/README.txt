Arcane Fireworks
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: fireworks celebration

Frames: 32 at 96x96 px, 15 fps, plays once.
Sheet: arcane-fireworks.png, 32 columns x 1 rows, no padding.

Files
  arcane-fireworks.png            sprite sheet
  frames/              one PNG per frame
  arcane-fireworks.gif / @4x.gif preview GIFs
  arcane-fireworks.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  arcane-fireworks.tres         Godot 4 SpriteFrames. Put it next to arcane-fireworks.png at res:// (or edit the path).
  arcane-fireworks.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 96x96.

You can use these frames in commercial and non-commercial projects.
