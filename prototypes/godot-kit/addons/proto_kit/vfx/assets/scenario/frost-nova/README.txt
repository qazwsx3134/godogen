Frost Nova
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: frost nova

Frames: 16 at 64x64 px, 15 fps, plays once.
Sheet: frost-nova.png, 16 columns x 1 rows, no padding.

Files
  frost-nova.png            sprite sheet
  frames/              one PNG per frame
  frost-nova.gif / @4x.gif preview GIFs
  frost-nova.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  frost-nova.tres         Godot 4 SpriteFrames. Put it next to frost-nova.png at res:// (or edit the path).
  frost-nova.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 64x64.

You can use these frames in commercial and non-commercial projects.
