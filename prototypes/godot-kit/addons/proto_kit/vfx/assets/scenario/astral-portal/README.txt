Astral Portal
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: dimensional portal

Frames: 16 at 64x64 px, 12 fps, seamless loop.
Sheet: astral-portal.png, 16 columns x 1 rows, no padding.

Files
  astral-portal.png            sprite sheet
  frames/              one PNG per frame
  astral-portal.gif / @4x.gif preview GIFs
  astral-portal.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  astral-portal.tres         Godot 4 SpriteFrames. Put it next to astral-portal.png at res:// (or edit the path).
  astral-portal.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 64x64.

You can use these frames in commercial and non-commercial projects.
