Blaze Tornado
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: fire tornado

Frames: 16 at 64x96 px, 12 fps, seamless loop.
Sheet: blaze-tornado.png, 16 columns x 1 rows, no padding.

Files
  blaze-tornado.png            sprite sheet
  frames/              one PNG per frame
  blaze-tornado.gif / @4x.gif preview GIFs
  blaze-tornado.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  blaze-tornado.tres         Godot 4 SpriteFrames. Put it next to blaze-tornado.png at res:// (or edit the path).
  blaze-tornado.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 64x96.

You can use these frames in commercial and non-commercial projects.
