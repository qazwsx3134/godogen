Ion Orb
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: plasma orb

Frames: 12 at 48x48 px, 12 fps, seamless loop.
Sheet: ion-orb.png, 12 columns x 1 rows, no padding.

Files
  ion-orb.png            sprite sheet
  frames/              one PNG per frame
  ion-orb.gif / @4x.gif preview GIFs
  ion-orb.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  ion-orb.tres         Godot 4 SpriteFrames. Put it next to ion-orb.png at res:// (or edit the path).
  ion-orb.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 48x48.

You can use these frames in commercial and non-commercial projects.
