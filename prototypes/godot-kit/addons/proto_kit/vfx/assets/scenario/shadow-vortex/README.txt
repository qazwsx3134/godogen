Shadow Vortex
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: purple black hole vortex

Frames: 16 at 64x64 px, 12 fps, seamless loop.
Sheet: shadow-vortex.png, 16 columns x 1 rows, no padding.

Files
  shadow-vortex.png            sprite sheet
  frames/              one PNG per frame
  shadow-vortex.gif / @4x.gif preview GIFs
  shadow-vortex.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  shadow-vortex.tres         Godot 4 SpriteFrames. Put it next to shadow-vortex.png at res:// (or edit the path).
  shadow-vortex.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 64x64.

You can use these frames in commercial and non-commercial projects.
