Frozen Spikes
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: ice spikes erupting

Frames: 18 at 96x64 px, 15 fps, plays once.
Sheet: frozen-spikes.png, 18 columns x 1 rows, no padding.

Files
  frozen-spikes.png            sprite sheet
  frames/              one PNG per frame
  frozen-spikes.gif / @4x.gif preview GIFs
  frozen-spikes.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  frozen-spikes.tres         Godot 4 SpriteFrames. Put it next to frozen-spikes.png at res:// (or edit the path).
  frozen-spikes.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 96x64.

You can use these frames in commercial and non-commercial projects.
