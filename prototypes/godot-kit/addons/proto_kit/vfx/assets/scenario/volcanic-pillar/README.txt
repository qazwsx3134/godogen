Volcanic Pillar
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: lava eruption pillar

Frames: 20 at 48x96 px, 15 fps, plays once.
Sheet: volcanic-pillar.png, 20 columns x 1 rows, no padding.

Files
  volcanic-pillar.png            sprite sheet
  frames/              one PNG per frame
  volcanic-pillar.gif / @4x.gif preview GIFs
  volcanic-pillar.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  volcanic-pillar.tres         Godot 4 SpriteFrames. Put it next to volcanic-pillar.png at res:// (or edit the path).
  volcanic-pillar.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 48x96.

You can use these frames in commercial and non-commercial projects.
