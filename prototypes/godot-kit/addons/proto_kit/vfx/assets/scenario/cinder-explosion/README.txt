Cinder Explosion
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: big fire explosion

Frames: 18 at 96x96 px, 15 fps, plays once.
Sheet: cinder-explosion.png, 18 columns x 1 rows, no padding.

Files
  cinder-explosion.png            sprite sheet
  frames/              one PNG per frame
  cinder-explosion.gif / @4x.gif preview GIFs
  cinder-explosion.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  cinder-explosion.tres         Godot 4 SpriteFrames. Put it next to cinder-explosion.png at res:// (or edit the path).
  cinder-explosion.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 96x96.

You can use these frames in commercial and non-commercial projects.
