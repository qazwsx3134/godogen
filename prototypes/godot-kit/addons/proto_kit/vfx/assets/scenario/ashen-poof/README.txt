Ashen Poof
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: smoke poof

Frames: 14 at 48x48 px, 15 fps, plays once.
Sheet: ashen-poof.png, 14 columns x 1 rows, no padding.

Files
  ashen-poof.png            sprite sheet
  frames/              one PNG per frame
  ashen-poof.gif / @4x.gif preview GIFs
  ashen-poof.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  ashen-poof.tres         Godot 4 SpriteFrames. Put it next to ashen-poof.png at res:// (or edit the path).
  ashen-poof.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 48x48.

You can use these frames in commercial and non-commercial projects.
