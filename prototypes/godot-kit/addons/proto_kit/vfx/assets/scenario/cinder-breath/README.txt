Cinder Breath
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: dragon fire breath

Frames: 16 at 96x48 px, 15 fps, seamless loop.
Sheet: cinder-breath.png, 16 columns x 1 rows, no padding.

Files
  cinder-breath.png            sprite sheet
  frames/              one PNG per frame
  cinder-breath.gif / @4x.gif preview GIFs
  cinder-breath.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  cinder-breath.tres         Godot 4 SpriteFrames. Put it next to cinder-breath.png at res:// (or edit the path).
  cinder-breath.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 96x48.

You can use these frames in commercial and non-commercial projects.
