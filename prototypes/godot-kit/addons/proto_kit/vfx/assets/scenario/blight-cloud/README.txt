Blight Cloud
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: poison gas cloud

Frames: 16 at 64x64 px, 12 fps, seamless loop.
Sheet: blight-cloud.png, 16 columns x 1 rows, no padding.

Files
  blight-cloud.png            sprite sheet
  frames/              one PNG per frame
  blight-cloud.gif / @4x.gif preview GIFs
  blight-cloud.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  blight-cloud.tres         Godot 4 SpriteFrames. Put it next to blight-cloud.png at res:// (or edit the path).
  blight-cloud.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 64x64.

You can use these frames in commercial and non-commercial projects.
