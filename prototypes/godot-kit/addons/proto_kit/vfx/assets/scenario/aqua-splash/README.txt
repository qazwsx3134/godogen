Aqua Splash
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: water splash

Frames: 16 at 64x64 px, 15 fps, plays once.
Sheet: aqua-splash.png, 16 columns x 1 rows, no padding.

Files
  aqua-splash.png            sprite sheet
  frames/              one PNG per frame
  aqua-splash.gif / @4x.gif preview GIFs
  aqua-splash.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  aqua-splash.tres         Godot 4 SpriteFrames. Put it next to aqua-splash.png at res:// (or edit the path).
  aqua-splash.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 64x64.

You can use these frames in commercial and non-commercial projects.
