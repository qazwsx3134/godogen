Razor Slash
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: crescent sword slash

Frames: 12 at 64x64 px, 18 fps, plays once.
Sheet: razor-slash.png, 12 columns x 1 rows, no padding.

Files
  razor-slash.png            sprite sheet
  frames/              one PNG per frame
  razor-slash.gif / @4x.gif preview GIFs
  razor-slash.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  razor-slash.tres         Godot 4 SpriteFrames. Put it next to razor-slash.png at res:// (or edit the path).
  razor-slash.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 64x64.
