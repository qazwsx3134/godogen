Sacred Sparkle
Made with Pixel VFX Forge: https://www.scenario.com/explorations/pixel-vfx-forge/
Prompt: sparkle twinkle

Frames: 12 at 32x32 px, 12 fps, seamless loop.
Sheet: sacred-sparkle.png, 12 columns x 1 rows, no padding.

Files
  sacred-sparkle.png            sprite sheet
  frames/              one PNG per frame
  sacred-sparkle.gif / @4x.gif preview GIFs
  sacred-sparkle.json         atlas (TexturePacker JSON array: Phaser, PixiJS, Aseprite tags)
  sacred-sparkle.tres         Godot 4 SpriteFrames. Put it next to sacred-sparkle.png at res:// (or edit the path).
  sacred-sparkle.recipe.json  the recipe. Load it back in Pixel VFX Forge, or edit it with your agent.

Unity: import the sheet, Sprite Mode Multiple, Filter Mode Point, Compression None,
then Sprite Editor > Slice > Grid By Cell Size 32x32.

You can use these frames in commercial and non-commercial projects.
