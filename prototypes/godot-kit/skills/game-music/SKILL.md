# 遊戲配樂（程式合成）

來源：mortal-city 2026-11-14 的〈Neon Riot〉。第一版（140 BPM、方波琶音、加法合成）被退回「太輕快、太有程式碼的感覺」，第二版改成下面的做法後通過。

本資料夾：`gamekit.py`（樂器與混音庫）、`example_score.py`（〈Neon Riot〉完整樂譜，重搖滾＋合成器，80 秒）。

## 流程

```
 問清楚      風格、輕重、用在哪個場景、要多長（沒說就 60–90 秒循環）
   ↓
 定調性      BPM、調、和聲循環、段落表（每段幾小節、誰進誰出）
   ↓
 複製        gamekit.py 與 example_score.py → 專案的 scripts/（後者改名 make_bgm.py）
   ↓
 寫樂譜      只寫「第幾個十六分音符彈什麼」；每種樂器一條 bus
   ↓
 配平        level(bus, LUFS)：用數字定各 bus 的相對響度
   ↓
 master()    尾音摺回開頭 → 壓縮＋飽和 → -16 LUFS／-1.5 dBFS → 檢查接縫 → 寫 OGG
   ↓
 交給人聽    回報數值，並明說自己聽不到
```

```
uv run --with numpy --with scipy --with soundfile python scripts/make_bgm.py
```

約 20 秒跑完。專案裡的 `gamekit.py` 是副本：要加樂器或修混音，改這個資料夾的來源檔再複製過去。

## 輕重怎麼調

使用者說「太輕快」時，改的是這幾項，不是音量：

| | 輕快 | 沉重 |
|---|---|---|
| 速度與律動 | 130 BPM 以上、四拍大鼓 | 90–105 BPM、半拍（小鼓只落第 3 拍） |
| 和聲 | 大和弦多的四和弦循環 | 原地 riff；小調加弗里吉亞二級、三全音 |
| 音域 | 高八度琶音、鐘聲 | 降弦低音、低八度音序器、低頻重擊 |
| 節奏密度 | 連續十六分的高音 | 低音悶音 chug，高處留空 |

## 讓它像樂團，不像音序器

1. **弦用物理模型。** `string()` 是 Karplus-Strong：每次撥弦的激發噪音不同，同一個音連彈十次沒有兩次一樣；悶音、撥弦位置、撥片硬度都是參數。加法合成的鋸齒波做不出這個。
2. **人彈的聲部加抖動，機器的聲部不加。** `put(..., human=0.004~0.008)` 給時間與力度變化。鼓、吉他、貝斯加；音序器低音、pad 留在網格上，對比才聽得出誰是「人」。
3. **吉他左右各彈一次。** 同一句用不同的隨機激發彈兩遍，一左一右，不是複製一軌再延遲。
4. **失真做在 bus 上。** 整個和弦一起進 `amp()`，弦與弦之間才有互調；逐音失真聽起來像風琴。
5. **力度改音色，不只改音量。** 鼓的 `v` 同時控制擊頭亮度與響弦長度；ghost note 用小的 `v`。
6. **鼓有房間。** 鼓 bus 先過短殘響再壓縮，鼓組才像在同一個空間。
7. **編曲留呼吸。** 過門、鈸落在段落開頭、漸強後留白一拍、每兩小節的小變化。一模一樣的小節重複八次是「程式感」最大的來源。
8. **循環起點放最重的段落。** 漸強摔回開頭才有落點；開頭安靜的話，每次循環都像洩氣。

## 配平參考值（各 bus 的 LUFS）

| bus | 重搖滾 |
|---|---|
| 鼓 | -18 |
| 失真吉他 | -19 |
| 主奏 | -22 |
| 貝斯、乾淨吉他 | -23 |
| 低頻重擊等效果 | -26 |
| 音序器低音 | -29 |
| pad | -31 |

使用者說某個聲部太大或太小，改這張表的數字，不要回頭改每個音符的增益。換風格時在這裡加一欄。

## 踩過的坑

- **不能 `import` 會在頂層整首跑一遍的腳本。** 樂器與混音放 `gamekit.py`，樂譜各自一個檔。
- **`soundfile` 一次寫整段 OGG 會 segfault**：`master()` 已經分 1 秒寫。
- **接縫**：殘響與延音要先算在比循環長的緩衝裡再摺回開頭；壓縮器在接了兩遍的訊號上跑、取後半，狀態才連續。`master()` 會 assert。
- **WSL 沒有 ffmpeg**：量響度用 `gamekit.lufs()`，讀回檢查用 `soundfile.read()`。
- **驗收**：數字只能證明長度、響度、峰值、接縫、音準（`string()` 實測偏差 7 音分內）。好不好聽一律寫「未經人耳驗證」。

## 做不到的事

純合成的人聲、弓弦獨奏、真實鼓組的鈸，離錄音還有明顯距離。需要那個等級時改用取樣（SoundFont）或 `scenario-audio` skill（花使用者的點數，先問）；`master()` 一樣可以拿來做循環與響度。
