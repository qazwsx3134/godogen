# AI 生圖素材 → 遊戲可用的 PNG

流程由使用者自己用生圖工具產生圖，我們寫 prompt 與處理工具（沒有走付費的 Scenario skill）：

```
art_src/PROMPTS.md（prompt＋檔名表）→ 使用者生成 → 存成 art_src/<檔名>.png
        → godot --headless --path . --script res://tools/process_art.gd
        → assets/<檔名>.png（已經是遊戲內尺寸）→ Sprite2D／TextureRect
```

`art_src/` 放 `.gdignore`（原始大圖不會被 Godot 匯入或匯出）。

## 圖的規則（寫進 PROMPTS.md 最上面）

- **背景一律純洋紅 `#FF00FF`**。不要要求「透明背景」（生成器常把棋盤格畫進圖裡）；不要用綠色（角色、甘蔗、葉子都是綠的）。工具遇到本來就有 alpha 的 PNG 會直接保留。
- 角色一律**朝右**，遊戲裡用 `scale.x` 翻面。不畫地面影子（scene 自己有）。圖上不要有文字、UI、格線。
- 場地背景**只畫空的地板**；箱子、沙包這類會擋東西的障礙物另外生成成單獨的圖，不然會誤導玩家。
- **每一張都附參考圖**（概念圖的截圖、前一張定裝圖）：參考圖比文字更能鎖住畫風。有「Large」縮圖之前的原圖就附原圖；背景要用工具能給的最大尺寸，否則 720×1280 放大到 1080×1920 會糊。
- 組合圖（kit，例如 4×3 的物件表、4×4 的圖示表）：指定欄列數、每格一個、格與格之間留大片空白。**檢查順序**：工具照格子位置命名，順序錯了圖示就對到別的能力。
- **不要附真人照片當參考**：生成出來的角色會變成那個真人的長相。髮型用文字描述（「俐落的油頭，前面往上往後梳，旁分，兩側推短」）。
- 要用同一個角色做動畫：先定裝（第 1 張），之後每張都附上一張當參考；6 格動畫圖格子會不一致時，改用圖生影片再抽格。

## `tools/process_art.gd` 做什麼

- **去背**：用四個角落的平均色當背景色，距離低於 0.15 全透明、高於 0.45 全不透明，中間是半透明；邊緣像素先扣掉背景色的貢獻（premultiplied）再縮放，**去洋紅溢色**（讓外框不留紫邊）。
- **切格**：每格取「有東西的範圍」，但丟掉貼在格邊、與主體之間有縫的細條（生成的格子從來不是剛好等分，會切進鄰格的邊緣；曾讓 4 個圖示下方多一條細線）。
- **縮到遊戲內尺寸**（表在檔頭 `SIZES`），執行時不縮放。概念圖是 720 寬、遊戲世界是 1080 寬，所以概念圖的像素 ×1.5 就是遊戲尺寸。
- **背景**：cover-fit 到 1080×1920。
- **動畫條**（`ANIMS`）：每個相連的像素塊歸到**它重心所在的格子**，所以甘蔗伸進鄰格仍屬於原本那一格；每格用同一個裁切框、縮到第一格的指定高度，輸出一條橫條，`Sprite2D` 設 `hframes`。腳底基準線不會一致時，在程式裡用每格的 `frame_drop` 補（曾經有 3 格腳底比格底高 9／9／5 px，直接播會上下跳）。
- `-- --self-test` 檢查去背、邊緣、溢色、切格、動畫條、cover-fit。

## 匯入設定（`.import` 檔，要 commit）

- 大背景：`compress/mode=1`（Lossy）、`compress/lossy_quality=0.9`。小 sprite 維持無損（有損會讓 alpha 邊緣出現色邊）。
- 字型：`ui/fonts/NotoSansTC.ttf` 是子集（見 `tools/subset_font.py`），原始可變字重字型放 `art_src/fonts/`。
- WAV 預設會被匯入成 QOA（約 1/5），但**原始檔還在專案裡**；要縮小專案本身就轉 Ogg。

## 開始畫面主視覺的 prompt 要點

上 1/4 留白給標題、主角在中下 1/3、敵群從兩側包過來、下 1/5 較暗給按鈕；**圖裡不要有任何文字**（標題「安」、副標題、按鈕、credit 都用遊戲字型畫）；附負面提示詞；存成 `art_src/title_bg.png`，遊戲偵測到 `assets/title_bg.png` 就自動換上。
