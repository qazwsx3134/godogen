# 全員推王：往商業版的里程碑

2026-10-23 暫停；每個里程碑的現況與上架前的缺口整理在 [PROGRESS.md](PROGRESS.md)。

目標是一款原創奇幻、手機直式、免費下載、IAP（招募券、免廣告）加獎勵廣告的 HD-2D 推王遊戲（商業模式見 README「已定案」）。每個里程碑都要先通過自己的驗收，才進下一個；順序依「失敗代價最大的假設先驗」排。

```
 M1 HD-2D 推王畫面 ──→ M2 英雄美術 ──→ M3 打擊感 ──→ M4 養成循環(v2)
   (本輪，待試玩)        (紙娃娃 48px)    (王動作/特效/音效)   (戰報/養成/存檔)
                                                                │
 M7 上架 ←── M6 內容量產 ←── M5 手機實測與效能 ←────────────────┘
```

## 這一輪（M1）刻意沒做的

- 研究裡的 RO 式自由旋轉探索、建築遮擋、八方向 sprite：固定戰場用不到，行軍畫面（M6）再評估。
- 英雄新美術：英雄要做動畫格，走 M2 的紙娃娃路線，不用一張張生圖。
- 網頁版：Compatibility 渲染器沒有景深，之後要的話另做降級畫質。
