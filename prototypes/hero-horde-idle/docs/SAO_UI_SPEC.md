# 全員推王 UI 規範（刀劍神域風）

參考：作者放在 repo 根目錄 `docs/sao/` 的三張遊戲截圖（隊伍血條、敵人血條、打倒通知），以及 `docs/ui-reference/sao/` 的動畫截圖。只借**版面語言**：斜切血條、細框深色玻璃、菱形標記、白色選單與金色選取、樓層與樓層王。不使用原作的字型、圖示、圖檔、名稱與標誌；作者提供的 SAO-UI repo 只參考配色與尺寸（無授權或仿原作素材，不能放進遊戲）。

元件都在 `scenes/ui_kit/`，樣式在 `ui/sao_*.tres`（`tools/sao_style.gd` 產生），全部攤在 `scenes/ui_kit/ui_kit_gallery.tscn` 一頁可看。

## 兩層

```
 ┌───────────────────────────────┐
 │ HUD 層：蓋在戰鬥畫面上         │  深色半透明玻璃＋1 px 淺色細框
 │  血條、倒數、通知、隊伍卡       │  字白色＋深色描邊
 ├───────────────────────────────┤
 │ 選單層：主畫面的頁面與對話框    │  不透明白色視窗＋灰色細框＋陰影
 │  視窗、卡片、按鈕、圓形導覽     │  字灰墨色，選中與主要動作用金色
 └───────────────────────────────┘
```

一個畫面只用一層的外觀：戰鬥（行軍戰場、推王）上的東西走 HUD 層；面板、對話框走選單層。

## 形狀與線

- **斜切**：所有血條與倒數條的填色用 `StyleBoxFlat.skew = (0.5, 0)`，右端向右上斜；上緣 3 px 亮邊。
- **細框**：HUD 1 px、選單 2 px；圓角 HUD 1～2、選單 6～8、導覽圓 60（正圓）。
- **菱形**：正方形框轉 45°（`rotation = PI/4`、`pivot_offset = size/2`），用在通知標記與隊伍卡頭像。
- **端蓋**：樓層王血條左右各一根 8 px 淺色直條，像括號把血條夾住。
- **角標**：通知條四角各一個 12×2 加 2×12 的 L 形淺色小標。
- **陰影**：只有選單視窗有（10 px、alpha 0.3）；HUD 不加陰影。

## 字

- Noto Sans CJK TC（Bold 做名字與按鈕，Medium 做內文）；不使用原作字型。
- HUD：白字＋6 px 深色描邊；樓層王名字 30、頭上不放字、通知 26。
- 選單：頁標題 36～40、區塊標題 28、內文 22～26、按鈕 24～30。

## 元件（選單層，樣式資源）

| 角色 | 資源 | 規則 |
|---|---|---|
| 視窗 | `sao_window` ＋ `sao_titlebar` | 每頁的面板；標題列高 80，頁標題放在上面 |
| 區塊 | `sao_section` | 視窗裡的分區不用框，只在上方畫一條刻線 |
| 卡片 | `sao_card` ＋ `RarityBar` | 白底；稀有度看左側色條；選中換 `sao_selected`（金框 4 px） |
| 按鈕 | `sao_button`／`sao_primary` | 一個畫面只有一顆金色主要按鈕；focus 一律空樣式（不蓋住內容） |
| 圓形導覽 | `sao_disc` ＋ `sao_ring`／`sao_ring_active` | 深色條上的圓；所在頁外環與字變金 |
| 頂欄 | `sao_bar` ＋ `sao_chip` | 深色半透明條；金幣與招募券是白色膠囊 |

## 規則

1. 血量一律用斜切血條，不用數字百分比當主資訊；樓層王的「剩幾條」寫在右上 `×N`。
2. 時間一律用長條，不用倒數數字。
3. 推王上方只放：暫停、樓層王名字＋血條、倒數長條。其他資訊（樓層、階段、輸出）不常駐。
4. 行軍戰場不放隊長名牌；每個角色頭上一條自己的血條。
5. 稀有度不用背景色或框色表示，用左側色條與字色；金框保留給「選中」。
6. 新增元件先在 `scenes/ui_kit/` 做成 scene、放進 gallery，再拿去用；顏色與線寬只改 `ui/sao_*.tres`。
