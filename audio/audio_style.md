# 音軌方法· 速通片的代碼合成配樂（拆解方法＋原創範例）

這一頁是從一次拆解裡沉澱的方法：參考片是X 用戶Tak（@cherry_mx_reds）的15 秒《Art History Speedrun》，它的配樂本身就是代碼合成的。這裡只保留**怎麼拆、怎麼寫、怎麼混**，不保留原曲的逐音轉錄。

配套腳本：`scripts/audio/synth_藝術史速通.py`。樂譜是一段**原始範例**（D 小調，和聲Dm–B♭–F–C），段落結構和畫面的`scripts/engine/eras.js` 一致，樂器庫和混音鏈可以直接復用，換成你自己的樂譜即可。

--- 

## 0. 一句話結論

速通類短片的配樂可以是**一張嚴格的BPM 網格上的程序化編曲**：17 個時代按“八分音符個數”排布（6,4,4,4,4,4,3,3,3,3,2,2,2,1,1,1,9），越往後每段越短，靠“段落變短”製造速度，速度越短”。每段換一套該時代的代表樂器，一個三音動機隨和弦移調貫穿全片。音樂在格子上停住後，接一串卡通音效（叮、滑哨墜落、碎裂、貓叫、收尾撥弦）完成結尾笑點。

## 4. 混音做法（腳本後半段，原樣可用）

1. 0.5s 小空間混響，12ms 預延遲，濕聲9% 
2. 逐段低頻暖底：按段的和弦根音（`BED_ROOT`）舖“三角波＋下八度
，逐段 2–6kHz 動態EQ（`MID_ORIG`）
4. 逐段補>6kHz 的空氣噪音（`HF_ORIG`）
5. 逐段K 加權響度對齊`target`，迭代4 次，10ms 平滑增益防拉鍊整體聲
6.
可選：15.88kHz 陡峭通端
有參考片時，`target / MID_ORIG / HF_ORIG / LOW_FLOOR_ORIG` 填參考片逐段量出來的值（用第1 節的方法）；沒有參考片時，範例裡的「統一相對值」就夠用。
起音軟化的經驗：撥弦模型2ms 硬起音聽起來太「點」，改成10ms 線性起音、高次諧波起音更晚（每升一次諧波×1.6，上限35ms）、起音噪音減半並加7kHz 低通，整體會連貫很多。
例的產出：48k 立體聲，15.06s，-14.0 LUFS，真峰-1.5 dBTP。

uv run --with numpy --with scipy --with soundfile python scripts/audio/synth_藝術史速通.py

## 5. 可復用規律：給任何動畫做程式合成配樂
下面這些可以直接照抄。
1. **先定一張BPM 網格，所有東西都對齊到它上面**。 128 BPM（八分音符0.234s）適合「速通、蒙太奇」這類節奏；剪輯點、音樂起音、音效落點全部取`t0 + n·E`。好處是畫面怎麼剪，音樂都不會顯得混亂。參考片的時間殘差只有±4ms，而這種「機器般的準」本身就是風格的一部分。
2. **用「每段八分音符數遞減」做加速，不要提速**。本片是6 → 4×5 → 3×4 → 2×3 → 1×3，到最後一段再放長（9）讓觀眾喘口氣、給笑點留位置。速度不變，聽感卻越來越急；而且每段都落在網格上，和畫面切點天然同步。做法：先列出畫面每段的時長，四捨五入到八分音符，再整體微調，讓遞減變得規律。
3. **一個三音動機，換樂器、隨和弦移調重複**。選一個短小、節奏鮮明的細胞（範例樂譜是♪♪♩「級進上行、再下跳」），每個場景用該時代或風格的代表樂器演奏一遍，音高跟著當段和弦走。和聲骨架用一個四和弦循環（例子是Dm–B♭–F–C）就夠；想做「出格感」的段落（異國、前衛）只換調式或加三全音，節奏和網格不動。開場可以用動機的倒影或擴大版（範例洞穴段是下行的附點四分）先立住。
4. **段間不做交叉淡化**。新段在網格上硬起音，上一段的音符保留自己的自然尾音（撥弦30–300ms，持續音約150ms 的release），可以讓一個低音持續音跨段延續來「縫」兩段。這樣每次換場都有清楚的「咔」，又不會斷。不需要每段都加轉場咻聲（參考片一個都沒有）。
5. **結尾音效按「停—懸—砸—反應—收」設計**：
   - 停：音樂在網格上停住，用約150ms 的快速衰減，不要硬切
   - 懸：一個小「叮」當引子，接下哨（純正弦指數掃頻，約0.35s、2 個雜訊八度多）
   - 折音座多角變化（純正弦指數衰減完
   - 反應：角色發聲，例如線性折線音高的“喵”，放在砸之後約0.5s，整段最響
   - 收：一兩下輕“啵”配簽名，最後一個落在主音或屬音上的低音撥弦
   全部按事件時間點從畫面接觸表（每0.1s 一幀）對齊。
6. **響度對齊方法**：
   1. 先量參考片的整體值（ffmpeg ebur128：積分LUFS、LRA、真峰）
   2. 再按段量K 加權響度，以及2–6kHz、>6kHz、40–220Hz 地板相對段響度的差值
   3. 合成後依次做：低頻段溫度逐段響度迭代對齊（3–4 次，10ms 平滑增益，防止拉鍊聲）








   4. 如果參考是AAC，再加16kHz 低通
   5. 最後整體對齊LUFS，並做前視峰值限幅
   全程用「相對段響度」的差值，不用絕對值，這樣換素材、換整體響度都不用重標。
7. **synth.py 改成通用模板的方式**（結構不動，只換四塊資料）：
   - `T0, E`：網格零點與八分音符時長（BPM → `E = 60 / BPM / 2`) 
   - `edges / target / MID_ORIG / HF_ORIG_ BED_ROOT`：段落邊界和逐段參考值；沒有參考片時，`target` 統一填一個值即可（比如-14），其餘三項填入「不補」
   - `era(n0, items)` 的樂譜塊：每段一行列表，元素是`(相對八分位置, 樂器函數, 增益, 聲像)。樂器函數庫（`pluck` 撥弦族、`additive` 持續音族、`kick / clap / hat / taiko` 鼓族、`chip / supersaw` 合成器族）可以直接復用，新風格一般只要調`pluck` 的諧波表和衰減 參數
   - 字塊音效：事件時間 / / / /L /L /L 數字/ end_thump`，參數（頻率、時長）從參考片測得，或按第5 條的模板自行定
   後半段混音鏈（暖底→ EQ → 空氣→ 響度迭代→ 低通→ 限幅）原樣保留。
8. **分析流程的順序**：
   1. 起音通量擬合網格，先拿到BPM 和t0 
   2. 在16 分音符網格上逐格做FFT 新音檢測，再用basic-pitch 複音轉錄交叉驗證
   3. 用窄帶諧波比和包絡判斷
   4. 用高頻、低頻能量變序打擊樂
   5.實測它在樂器判斷上可靠，在拍速（說120，實測128）、動機音數、「轉場咻」、音效時間上都錯了
