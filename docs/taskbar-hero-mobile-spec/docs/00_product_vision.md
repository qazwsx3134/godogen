# 00 — Product Vision

## Product Goal

做一款受到 Task Bar Hero 核心體驗啟發的手機單機 Idle RPG，但針對手機重新設計。

不是把 Windows Taskbar 搬到手機，而是把其核心概念：

> 「遊戲一直在旁邊自己進行，玩家偶爾介入最佳化」

轉換成手機體驗：

> 「App 開著時小隊永遠在冒險；App 關閉時由 Offline Simulator 計算進度；玩家每次打開都能快速收穫、調整 Build、繼續推進。」

---

## Target Experience

### 玩家打開 App 30 秒

- 看 Offline Report
- 收 Loot
- 看有沒有稀有裝備
- 一鍵 Equip 或 Salvage
- 關掉 App

### 玩家玩 3–5 分鐘

- 看 Offline Report
- 換裝
- 升級技能
- 分解裝備
- 合成高階裝備
- 解 Rune
- 推 Stage

### 玩家玩 10–20 分鐘

- 調整 3 人隊伍
- 測 Boss
- 調 Formation
- 調技能與裝備
- 挑戰高難度內容

---

## Core Fantasy

玩家不是「控制一名角色」。

玩家比較像：

- 小隊管理者
- Build Designer
- Loot Curator
- Progression Optimizer

角色會自己戰鬥。

玩家的價值在於：

- 選隊伍
- 配裝
- 選技能
- 分配資源
- 決定成長方向

---

## Design Principle

遊戲的樂趣不是：

> 操作技術

而是：

> 觀察 → 獲得 → 比較 → 決策 → 成長 → 再觀察

---

## Product Positioning

類型：

- Idle RPG
- Auto Battler
- Incremental RPG
- Loot RPG
- Party Builder

不是：

- ARPG
- Survivor-like
- Turn-based RPG
- MMORPG
