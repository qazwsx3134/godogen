# 03 — Systems Overview

## Core Systems

### 1. Party

- 最多 3 Hero
- Formation slot（MVP 固定位置）
- Hero level
- Hero mastery（MVP 後）
- Skill loadout
- Equipment

### 2. Combat

- Auto target
- Auto movement
- Basic attack
- Active skill
- Passive
- Buff / Debuff
- Death / revive between waves

### 3. Stage

- Act
- Stage
- Wave
- Enemy composition
- Boss
- Rewards
- Recommended power

### 4. Loot

- Chest
- Equipment
- Material
- Currency
- Rarity
- Affix

### 5. Equipment

- Weapon
- Armor
- Helmet
- Gloves
- Boots
- Accessory

MVP 共 6 slots。

### 6. Inventory

- Item list
- Sort
- Filter
- Lock
- Equip
- Salvage
- Auto salvage rule

### 7. Cube

MVP：

- Merge
- Salvage
- Craft

Later：

- Engraving
- Socket
- Reroll

### 8. Rune

Account-wide meta progression。

提供：

- Combat bonuses
- Loot bonuses
- Offline bonuses
- QoL unlocks

### 9. Offline

- Timestamp
- Efficiency
- Reward cap
- Report generation

### 10. Save

- Local JSON / binary
- Versioned schema
- Auto save
