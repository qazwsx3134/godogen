# Deep Rock Galactic 採礦體驗研究

2026-11-26 · One More Rock V0.2 參考

**優先把每一鎬挖開的位置做準，再讓數鎬累積成能看懂的坑、缺口或通路。** 掉落、搬運和清空料斗才接在這個可見的地形變化後面。對 One More Rock 來說，值得先做的是岩壁的局部變形與鎬尖接觸的一致性。已有的石屑、音效、震動和坍落足以一起測這件事。

## 觀察與來源

- **挖掘可以改寫動線。** Ghost Ship Games 的開發日誌說明，他們希望玩家靠挖除地形與移動工具前進。洞室以手工模板組成，部分通道入口會被壓實的泥土封住，洞壁的形狀與雜物因生態區而異。官方商店的地形短片約 1–4 秒可見同一個岩洞入口反覆噴出碎屑，開口逐步擴張，隨後角色走到洞口。這段能看清楚保留下來的輪廓和被挖掉的位置。 [Ghost Ship 洞穴生成日誌](https://store.steampowered.com/news/posts/?appids=548430&enddate=1726743173&feed=steam_community_announcements#:~:text=Below%20Decks%20at%20Ghost%20Ship) · [官方地形短片](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/548430/extras/b1e09da4971f482ba004dadc1dfc918f.mp4)
- **開口、碎屑和後方空間是同一個動作的結果。** 本機安裝附帶的 `CharacterSelectionVignet_Driller_01_540.mp4`，前約 0–6 秒能看見第一人稱鑽頭推進岩壁、近處掠過石屑，接著視野進入新開出的空間。這是鑽頭示範。從這兩段可以推論，碎屑最重要的作用是讓玩家讀到哪裡剛被挖掉，以及下一鏡還剩多少岩壁。
- **資源可以有不同的揭露和搬運節奏。** 官方更新明列地上礦塊有自己的拾取動畫與音效。Heavy Extraction 則讓玩家辨認岩面上的琥珀色跡象，挖出一整塊 Resinite 再特殊搬運。另一個官方例子是挖開薄土才能取得 Ossium。這些例子支持用同一套可挖地形串起普通收取、少見發現與較大批的搬運。 [拾取更新](https://store.steampowered.com/news/posts/?appids=548430&enddate=1580481696#:~:text=resource%20chunk%20pickup) · [第六季 Heavy Extraction](https://www.deeprockgalactic.com/season-06) · [Ossium 更新](https://store.steampowered.com/news/posts/?appids=548430&enddate=1771934433#:~:text=thin%20layer%20of%20dirt)

## 對照 V0.2

目前已經可以左鍵揮鎬、長按連挖，岩山與路邊岩石都可挖。鎬尖有接觸姿勢，命中有石屑、塵霧、聲音與觸覺回饋。挖空底部會落下大塊，碎岩落地後才能撿，收取時會先上浮再落入背包或推車。 [原型說明](../../../prototypes/one-more-rock/README.md)

## 一段礦場試玩的範圍

```text
看岩面 → 揮鎬 → 鎬尖命中、岩面局部消退
                     ├→ 挖深或打通薄脊 → 改變走法
                     └→ 挖掉支撐 → 大塊坍落、落地碎開
                                          ↓
                             碎岩落地 → 上浮 → 背包或推車
                                                   ↓
                                          卸貨堆積 → 加工清空
```

先用同一個場地比較更新前後的三個操作。貼牆固定角度連挖五下，看缺口是否逐鎬可讀。以桌機滑鼠與手機橫向操作各長按掃過岩壁邊緣，錄下鎬尖、實際切面和幀時間。最後挖底部、接上推車、運回工坊，對照塌落時點、地上餘量及入庫數。這三段優先用來決定是否值得把局部網格更新推廣到整座礦山。 [One More Rock 實作方案](IMPLEMENTATION.md)
