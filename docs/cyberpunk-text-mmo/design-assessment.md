# Lead Game／Systems Design設計評估

日期：2026-10-29。基於目前concept、game-design、risk-systems與content-plan所做的主session評估；沒有派遣其他代理，沒有實玩證據。以下是提案，不覆寫已確認需求，也不代表新增系統已獲驗收。

## 1. 判斷

題材、風格與高風險身份已清楚；尚未證明的是「玩家能用判斷取得更想要的結果」。目前接案、配裝、自動執行與結算都有設計位置，但策略互動、人物依戀與多人互相影響還不夠具體。若直接擴至24案，可能先放大文本成本，仍無法回答為什麼想再玩一案。

最值得保住的體驗目標：靠準備與判斷活下來；城市與人物記得自己的做法；有機會以不同方式成為傳奇。永久死亡是這段生涯的風險，不是每隔幾案強迫重練的內容循環。

## 2. Lead Game Designer：玩家想做什麼

### 任務的選擇要有兩種值得要的結果

選項不能只是同一報酬下，三個成功率或能力門檻不同。情報、金錢、人物、暴露、神經壓力與後續案源之間要有取捨，才會產生自己的打法。

例：從企業診所帶走一名證人。強行突入速度快、能保住完整資料，但容易暴露；入侵可關閉保全，卻需承擔義體負荷，且某些遠端紀錄可能無法保留；用人脈安排轉診可以降低交火，但要付出欠情或情報。哪個更好取決於角色狀態、手上情報與想保住的人。

以上結果是案件原型，不是正式世界事實。不能為了平衡硬把所有方案都懲罰一遍；某個方案在特定條件下較好，是先前準備帶來的回報。需要避免的是整個章節永遠同一方案占優。

### 玩家需要在乎的人與自己的問題

目前首六案主要各自帶出一個系統，仍欠一條讓玩家想追問的情感線。建議先固定兩名會再次出現的人物、一個共同祕密，以及玩家為何願意接下一案。人物不是只負責開任務和講規則，而要有需要玩家幫忙、也會反過來影響玩家的行動。

每件案子至少改變一段關係、一個情報理解或一個未來機會。這些改變要在之後真的出現：曾救過的人提供門路，曾背棄的人不再相信你。初期幾個重要旗標足夠，不需先加十個勢力聲望條。

### 自動段負責執行，不吞掉有趣決策

保留一般委託自動跑、重要劇情／重大危險手動選的既定方向。主要策略放在出發前的情報與方案，必要的中途抉擇只保留少數真正改變結果的節點。不把所有小動作都改手動回合戰。

自動段顯示可讀的狀態變化與理由；不以2～8分鐘的空倒數當作核心體驗。首個原型可縮短安全段，先看玩家是否想調整下一案的策略，再決定正式耗時。

### 失敗也要有故事推進

大多數普通失敗先表現為失去資料、增加暴露、救援負債、人物受損或案源改變。依案件設計新的有成本後續，避免只有成功領獎與死亡刪角兩種結果。

失敗後的新案不重置原案，也不自動退款／給滿額報酬。目的在於保留新的決策與可繼續的生涯，而不是無限補助。

## 3. Lead Systems Designer：系統如何互相作用

建議用目前已有的少量變數互相影響，不再增加大量獨立資源條。

```text
情報／人物關係 → 可用方案與可信的風險預測
                         ↓
武器／設備／義體 → 執行能力、方案標籤與負荷
                         ↓
案件決策 → 傷勢／神經壓力／警方暴露／人物後果
             │                  │
             ↓                  ↓
        治療／救援         路線／追緝／撤離
             └────────┬─────────┘
                      ↓
          報酬／名聲／經驗／新案源與城市貢獻
```

### 義體與等級應增加可行策略

保留升級提高抗性的需求。義體可有少量能力標籤或主動用途，如遮蔽監控、短時過載、緊急穩定；先挑兩三種能在不同案件派上用場的效果，而非每件只加不同幅度的數值。

過載的代價可進入既有神經壓力，讓玩家思考現在是否值得動用能力。等級提高後，原本危險的組合更容易運作；更高負荷與新案件仍需準備。不能把高等角色設計成完全沒有死亡／失控風險，也不能讓升級後所有敵人同步變強到感受不到進步。

### 警方應改變行動空間

通緝提高後，任務路線、可接觸的人物與安全撤離選項應有可讀改變。降低通緝要透過案件裡可行的行動，如避開監控、取回辨識資料或以較高代價撤離。避免只是星星增加、傷害乘數提高或關頁等清星。

五級框架保留；第一個原型先驗證低星與高星的行動差異，不需先寫滿五套大規模遭遇。一般犯罪、證據、名聲與神機錯亂保持不同狀態，不能全部合成一條惡名。

### Trauma Team是準備選擇，不是必繳通行費

保障讓某些冒險值得考慮，救出後仍有傷勢、任務代價與帳單；有保單不能抹掉死亡。沒有保障也要存在合理可玩的保守路線，否則保費只是必繳成本，所有未投保角色都等於未完成教學。

有限案源必須支撐醫療費用；診所、人脈、撤離方案可成為不同的保命準備。先用一種保單與少量案件驗證取捨，再決定是否需要保單等級。不能先加入訂閱式離線扣費。

### 永久死亡要以整段生涯校準

死亡前不只提示「可能死」，還要讓玩家理解風險來源、有哪些準備與替代方案。因忽略警告／主動冒險而死，與在日常重複抽取小機率中累積死亡，是不同體驗。

簡化獨立事件下的累積死亡率：

`D = 1 - (1 - p)^n`

| 變數 | 型別／範圍 | 意義 |
|---|---|---|
| p | 小數，0～1 | 每次事件的死亡率，僅示意假設 |
| n | 整數，0以上 | 事件次數 |
| D | 小數，0～1 | 至少死亡一次的機率 |

輸出0～1；n為0或p為0時為0，p為1且n大於0時為1。p＝0.01、n＝50時D約0.395，即39.5%。真實任務不必獨立、也不採固定p；此例只說明單次1%不等於整段生涯低風險，不是本作死亡率提案。

建議把死亡集中到有充分鋪陳的重大風險，普通失敗先用不同後果承接；實際可見資訊與數值須試玩。已確認的危險節點等待、離線不代選維持不變。

### 有限任務需要有限經濟與章節終點

同角色不重複案件已確認，不能用刷案填補金錢／經驗缺口。每條可達路線都需盤點必要裝備、醫療、名聲門檻與後續案源；如果玩家已結完案件卻買不起必要物品，屬進程設計問題，不能讓玩家只能故意死掉重開。

章末有明確生涯階段成果。更新新案件才能擴充內容；不要把死亡當成強迫玩家重讀相同故事的日常留存。新角色可略過已讀敘述但仍做自己的選擇與結算，不藉略過繼承獎勵。起始配裝可選不同方向作為低成本重玩差異，此項是新提案，不是已定職業系統。

## 4. MMO仍缺的核心：別人的存在怎麼影響我

聊天提供交流管道，排行榜提供比較，三條貢獻進度提供合作目標；這些目前仍不足以證明玩家需要互相交流。

建議第一個城市事件驗證一個具體影響：有些人做情報案件後，城市揭露新的可見路線；有人完成醫療／補給案件後，後續任務得到新的合法援助選項。這些作用限於明確的共享事件狀態，不替其他人決定私人劇情或殺死其NPC。

普通玩家即使獨自遊玩也有替代方案。不要把新手進度硬鎖在稀少職業或某人必須在線；角色進行中的案件以啟動快照為準，不能因他人完成事件而令等待中的生死選擇失效。

通訊可以討論公開的城市狀態、路線與各自見聞；不預設玩家擁有完全不同的官方真相，也不強迫聊天才能過關。第一個原型只需證明一次「另一個玩家的貢獻讓我的可用選擇改變」。

## 5. 排行與生涯身份

名聲榜保留，死亡角色留下傳奇紀錄。排行顯示玩家是誰、做過什麼，比只顯示一個大數字更有題材價值。稱號／生涯摘要可取自已完成案件，不增加戰力繼承。

週榜與一次性案源的衝突尚未解決：老角可能結完全部案件、新角可能刻意重建取得計分機會。建議先讓名聲／生涯榜成立；週榜在章節或進度分組、計分機會確定後完成，不刪除使用者要求的排行榜，也不靠重複刷案補洞。

## 6. 我會優先修正的順序

| 優先 | 缺口 | 最小修正／驗證 |
|---|---|---|
| P0 | 三種方案是否只是能力門檻 | 同一案件設計兩個合理目標，各至少兩種可行解法；用不同狀態試玩是否改變選擇 |
| P0 | 玩家為何在乎下一案 | 先固定兩個有動機的人物與一條祕密，前兩案出現可回收後果 |
| P0 | 普通失敗與永久死亡是否分層 | 同案走生還、失敗延伸、救出與明知風險仍冒險的分支 |
| P0 | 任務／醫療成本是否造成軟鎖 | 盤點一條成功路線與一條失敗後續路線的資源和可接案件 |
| P1 | 義體是否改變玩法 | 兩三種用途可跨案重用，有不同負荷／壓力代價 |
| P1 | 共享事件是否改變個人可行動作 | 兩帳號以不同案件貢獻，展示一個合法新選項 |
| P1 | 死後新角是否只是枯燥重讀 | 已讀加速＋不同起始配裝，不跳過選擇或繼承獎勵 |
| P2 | 週榜是否有合理計分機會 | 在有限案源上先模擬，再擴到真人競爭 |

不建議現在再加製作、抽卡、公會、PVP、大型地圖或更多數值條。UI與架構規劃足以支持切片，下一輪設計投入應先落在案件選擇與後果。

## 7. 下一個原型要回答的問題

不用先完成24案。先用兩份連貫案件、兩名重要人物、三套起始配裝、少量風險與一個共享援助效果，串出可試玩的20～30分鐘段落；事件耗時可縮短，不把等待當驗收。

驗證方式是讓玩家先說出目標與選擇理由，遊玩後回顧哪些後果有感。觀察是否所有配裝／人物狀態都選同一路、是否只按最安全答案、能否理解失敗、是否想知道人物下一步，以及別人的行動是否產生可指出的影響。這些是待試玩問題，不是保證測完就好玩的通過證書。

只有當玩家願意討論自己的取捨，且能記住人物與後果，再擴至六案與更大文本量。這是優先順序建議，不自動更改目前內容／里程碑承諾。
