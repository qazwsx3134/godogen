# Cyberpunk 文字 MMO RPG：設計與開發規劃

更新：2026-10-29。階段：概念深化與開發規劃，尚無遊戲實作。

## 已確認的方向

Cyberpunk 2077同一時空、以東京為原型的城市；文字任務RPG。原生網頁、手機直式優先，電腦相容。每角色委託不重複；永久死亡後可建新角重玩。一般流程自動執行，重要劇情與重大危險節點等待玩家選擇。包含警方追緝、Trauma Team、等級提升神機錯亂免疫力、聊天與系統訊息；玩家各自成長競逐排行，也合作推進城市事件。

技術方向由使用者指定React與Cloudflare，可使用shadcn/ui及Tailwind。具體架構採React SPA、Workers API、D1遊戲資料與DO聊天；元件與視覺提案見以下文件。
