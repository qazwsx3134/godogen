# 雙層任務：劇情委託＋街頭工作 v0.1

日期：2026-11-04。§1 是使用者當天確認的決定；§2 以後是依決定展開的提案，數值與名稱都還要試算。本檔優先於其他文件中與「每角色委託不重複」「有限經濟」「週榜無法計分」有關的舊敘述，受影響段落列在 §9。

## 1. 已確認（2026-11-04）

- 本作是**任務型 MMO**，任務分兩層：
  - **劇情委託**：維持每角色一次、有人物與後果、重要劇情與危險節點手動抉擇、可能永久死亡。
  - **街頭工作**：可重複接，報酬與難度隨工作階級逐級上升（增量成長）。
- **街頭工作的死亡風險**：低階不會死，只會受傷、增加壓力、提高通緝或損失信用點；**高階可能永久死亡，但只能在線手動接，不能排隊、不能離線執行**。
- **執行方式**：一次排有限件數，做完就停，要回來重新排。
- **多人連動**：街頭工作計入週榜、推進城市共同事件，並在區域頁顯示人數與動態。
- **第二批決定（同日）**：
  - 首版一次排 **4 件**，隨名聲擴充到 8 件；擴充是否花信用點仍待定。
  - **第 4 階起**可能永久死亡。
  - 接劇情委託時，排隊中的街頭工作**暫停**，劇情結束後繼續。
  - 街頭工作文本用**模板＋變數**。
  - **熟練度上限 100**；每級效果以百分比計，越重要的屬性每級提升越少（數值見 §3.1）。

## 2. 兩層怎麼接在一起

```text
            劇情委託（一次性・手動抉擇・可能永久死亡）
            中間人 → 案件 → 危險節點 → 人物與城市後果
                 ↑ 名聲、人脈、區域資格        │ 解鎖新工作類型與階級
                 │                              ↓
街頭工作（可重複・排隊 N 件・增量）
  低階：自動跑、可離線、不會死 ──→ 信用點／經驗／素材／熟練度
  高階：在線手動、一件一件、會死 ──→ 高報酬、稀有素材、名聲
                 │                              │
                 ↓                              ↓
       裝備／義體／醫療保障            週榜積分・城市事件進度・區域動態
```

劇情委託負責「我是誰、城市記得我什麼」；街頭工作負責「我每天在變強、在排行上往前」。劇情需要的能力、裝備與保障，主要靠街頭工作累積；街頭工作的新類型與高階，靠劇情的名聲與人脈解鎖。

## 3. 街頭工作規格提案

### 3.1 類型與階級

工作類型沿用三種解題方向，每種有自己的階級與熟練度：

| 方向 | 低階例子 | 高階例子 |
|---|---|---|
| 火力 | 收保護費、清除街頭幫派據點 | 突襲企業倉庫、正面攔截車隊 |
| 入侵 | 破解自販機、竊取監視畫面 | 盜取企業伺服器、癱瘓區域監控 |
| 潛行 | 送貨、跟蹤拍照 | 從保全大樓帶走人、盜取原型義體 |

- 階級暫定 1～5；第 4、5 階是「高階」，會標「⚠ 可能永久死亡」，只能手動接。第幾階開始會死，待 M0 試算後確認。
- 階級由兩個條件解鎖：角色等級，以及該區域的街頭名聲或劇情旗標。入口用 ro-idle 職業頁的寫法列出缺口：「✖ 需要街頭名聲 3（目前 1）」。
- **熟練度**（增量的核心）：每個工作類型各自累積，上限 100。越重要的屬性每級提升越少（初始試算值，M0 調整）：

  | 屬性 | 重要度 | 每級 | 100 級時 |
  |---|---|---|---|
  | 成功率 | 最高 | +0.05% | +5% |
  | 傷勢與暴露 | 高 | −0.15% | −15% |
  | 報酬 | 中 | +0.25% | +25% |
  | 耗時 | 低 | −0.4% | −40% |

  報酬與耗時一起算，100 級時每小時收益約為 1 級的 2.1 倍（1.25 ÷ 0.6），再乘上階級倍率；平衡時要一起看。25／50／75／100 級各解鎖一個同類型的變體工作。

### 3.2 排隊與執行

- 低階工作可以排 N 件（暫定首版 4 件，隨名聲擴充到 8 件），由伺服器依 `due_at` 逐件結算，離線照常推進。
- 每件耗時沿用 game-design 的 2～8 分鐘假設；排滿 8 件約 30～60 分鐘。
- 排隊時選一組**行動準則**（謹慎／平衡／冒進三組預設，可改 3～4 條：傷勢到哪就撤、暴露上限、優先保什麼）。準則只影響低階工作的自動判定。
- **停止條件**（ro-idle 的保險絲）：傷勢達門檻、神經壓力達門檻、通緝達門檻、信用點低於出發時的設定比例、補給用完。觸發時剩下的工作取消並寫明原因。
- 高階工作一次一件、玩家在線手動確認，過程中的危險節點套用 risk-systems 的生死規則（等待選擇、確認後伺服器一次結算、重整不重抽）。
- 同一角色同時只做一件事：排隊中的街頭工作、高階工作與劇情委託互斥。接劇情委託時，排隊中還沒開始的工作暫停（正在做的那一件先做完），劇情結束後自動繼續。

### 3.3 可解釋性

照 ro-idle lessons §3.1～§3.3 的做法：
- 每件工作的紀錄帶當下傷勢、暴露與壓力，自動動作寫出是哪條準則觸發的。
- 不能接、評級偏低時寫出缺口。
- 離開回來先看報告：完成幾件、收益、傷勢與通緝變化、為什麼停下、城市事件進度。

## 4. 增量曲線（形狀，數值待試算）

- 報酬隨階級線性到緩增（例如每階 ×1.6～×2），不做指數膨脹；同階內靠熟練度提升 10～30%。
- 支出同步增加：高階工作需要更貴的裝備、義體維護、醫療保障與清除通緝的成本，讓收入有去處。
- 劇情委託的報酬不能比同階街頭工作少太多；它的價值在獨特裝備、人脈、區域資格與名聲，不在信用點。
- 第一輪平衡用「排幾輪低階工作才能換一件裝備、跨一個階級」來推算，目標在 M0 定。

## 5. 經濟（取代「有限經濟」提案）

街頭工作帶來持續的收入，所以經濟改成收支平衡設計：

| 來源（faucet） | 去處（sink） |
|---|---|
| 街頭工作報酬（主要） | 裝備與義體購買、改裝、維護 |
| 劇情委託報酬（一次性） | 醫療自付額與 Trauma Team 保費 |
| 素材出售 | 清除通緝（賄賂、換身分） |
| 城市事件達標獎勵 | 排隊名額擴充？（待確認是否用信用點買） |
| 抵押品贖回 | 贖回被抵押的裝備（risk-systems §3） |

首版仍沒有玩家交易、拍賣與抽卡（game-design §6 不變），所以不會出現 ro-idle 那種市場通膨；要注意的只有單人收支。

## 6. 週榜

- 每週委託榜改為以**街頭工作積分**為主：每件完成的工作依階級給分，高階加權；劇情委託另給固定分。
- 分組：依街頭名聲階級分組，避免新角色直接和老玩家比。
- 防刷：
  - 計分以工作結算時間歸屬當週，沿用 game-design §8 的週界線規則。
  - **同類遞減（2026-11-04 確認中等強度）**：同一種工作（類型＋階級）每週前 20 件給滿分、第 21～40 件 50%、第 41 件起 20%。只影響週榜積分，不影響信用點與經驗。
  - 一帳號一個活躍角色的規則不變。
- 名聲／生涯榜照舊；死亡角色保留紀錄。另外加多個紀錄軸（ro-idle lessons #12），避免一個總榜很快飽和。

## 7. 城市共同事件

- 事件目標改成「指定的街頭工作類型累積完成數」，再加少數劇情委託的關鍵目標。例：封鎖線的「民生補給」＝全服完成 N 件潛行送貨工作。
- 進度顯示在主畫面頂部與官網；排隊中的工作要結算後才計入，畫面寫明。
- 獎勵兩層：每帳號一次的參與獎；前段貢獻者只多拿稱號。事件達標後開通的路線與援助永久保留。
- 目標調整規則：只能下修、要公告、已貢獻不作廢。

## 8. 區域人數與動態

- 每個區域頁顯示：目前在這區做工作的傭兵人數、本週完成的工作數、本週死在這區的傭兵數（只顯示高階工作與劇情委託）、正在進行的城市事件。
- 每個角色的工作各自結算，互不搶目標。看得到別人，但不互相干擾。
- 知名傭兵的高階死亡可以進系統廣播，但只公開無劇透的內容，玩家可以關閉自己的公開。
