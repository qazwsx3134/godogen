## 共同視覺語法

- 邊角有選擇地切開，線框、角標、編號與標題條形成機械感。
- 深底上的紅、青、黃等色彩負責區分資訊與狀態；不是所有區塊同時高飽和發光。
- 圖示以輪廓、實心幾何與固定符號族辨識；數字與欄位對齊，主次有差別。
- 設備依情境有不同外觀，但「可操作／目前狀態／等待／拒絕」仍有明確層級。
- 作品集頁的黃色底、標題帶與概念分頁是展示排版；本作不照搬成常態遊戲頁。

以上是本次逐圖觀察的設計歸納。原圖有概念、替代稿與遊戲截圖，本文不把所有內容都視為已出貨UI，也不把靜態圖片推論成動畫證據。
