# 極短篇：不是頭痛，是桂 v0.2

日期：2026-10-29。作者已提供故事核心與台詞，並明確指示「阿銀說 你腦袋被撞到嗎 好了 做成玩家抓時機按下吐槽」；後續指定桂必須分兩句、中間停頓，第二句理直氣壯且表情認真。核心採納範圍限於以上指示；具體秒數、操作提示及美術仍待試玩／作者檢視。

## 場景與節拍

暫用萬事屋客廳；桂在中央，伊莉莎白在右側。神樂與銀時用畫外音回應，避免五張立繪互相遮擋。桂雙手像參考圖放在頭兩側，從開頭到吐槽完成前都不放下；全程一本正經。

L01 伊莉莎白：[舉牌]「頭痛？」

L02 神樂：「狗勾？」

L03 阿銀：「你腦袋被撞到嗎」

L04 桂：[嚴肅，先糾正]「頭痛賈奈。」

[獨立停頓；不是用一條台詞一次打完。原型在翻過第一句後保留 0.55 秒，再顯示第二句。可由編輯器的 freeze 調整。]

L05 桂：[更理直氣壯，一本正經，仍保持認真表情]「咖紫拉打。」

[遊戲裡這一拍是三選一「下一句」（咖紫拉打／這是肉球隊長的耳朵／下一句是什麼來著？），見 `prototypes/debt-commission/stories/katsura_dog_ears/README.md`。草稿原本的時機挑戰（QTE 圓環）已拿掉，要不要回來由作者決定。]

L06 新八：[玩家抓準時機，左側漫畫格]「到底是怎樣啦！！那你手舉個屁啊！！！」

## 玩家結果

- 抓準：播放作者的完整吐槽與漫畫演出，短篇結束。
- 太早：系統提示「搶早了。等桂說完，再留半拍。」後重試第二句。
- 太晚／沒按：系統提示「慢了一拍。圓環重疊時，點下去吐槽。」後重試。
- 錯誤沿用既有眼鏡規則，耗盡可重試；不加新角色台詞、不把操作失敗寫進正式人物記憶。
