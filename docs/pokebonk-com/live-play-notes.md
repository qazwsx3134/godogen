# pokebonk.com 實玩筆記（Claude，2026-10-19）

`pokebonk.com`（作者 Charcher，v0.7.3 BETA）和先前研究的 `pokebonk.solais.cloud` 是**兩款不同的遊戲**。

| | pokebonk.solais.cloud | pokebonk.com |
|---|---|---|
| 角色呈現 | 3D 模型（GLB） | 2D 像素精靈圖（PMD SpriteCollab，CC BY-NC 4.0），立在 3D 場景裡 |
| 場景 | toon 材質＋描邊 | 像素風貼圖的 3D 地形：草地、石砌懸崖台地、小路 |
| 規模 | 44 隻、Mega、可多人線上 | 151 隻關都、Ultimate、聯盟；只有單人 |
| 進度 | 存在本機 | 存在伺服器（訪客綁裝置） |

條件：桌面 Chromium 1280×720，鍵盤操作，以訪客身分（經使用者同意）玩 2 局。截圖在 gitignored 的 `.claude/tasks/pokebonk-com/shots/`。

## 1. 流程

```
標題（訪客／登入／建帳號）
  → 選夥伴（妙蛙種子／小火龍／傑尼龜，各有職業與被動）
  → 主選單（Play 經典、Survival 無盡、任務、圖鑑、Lab、成就、排行榜）
  → 聯盟（選上場的寶可夢，顯示招式組與數值）
  → 選地區（Viridian Forest／Rocky Desert）＋模式＋難度
  → 一局：Zone 1/3 → 2/3 → 3/3 → 神殿
  → 結算
```

- **夥伴**：開局選的是「聯盟」第一位成員，其他成員要在局內挑戰後捕捉。
  - 傑尼龜：職業 DEFENDER，被動 Torrent Shell（+15 護甲、+20 護盾，HP 低於 40% 時傷害 +40%），起手招 Water Gun。
- **招式按等級解鎖**，沿用寶可夢的 learnset。傑尼龜的例子：
  - Water Gun：起手。
  - Bubble：Lv.2。
  - Rapid Spin：Lv.4。
  - Hydro Pump：Lv.7。
  - 共 38 招。
- **招式分形態**：Projectile、Burst、Spin、Bolt（貫穿射線）等，也分物理／特殊。
- **局內進化等級**：Lv.24、Lv.44。
- **Ultimate**：R 鍵，例如傑尼龜的 Shell Whirlpool。
- **地區**：
  - 每區有 3 個 zone，每個 zone 隨機出一隻守護者，最後是神殿。
  - 地區有屬性傾向，例如 Viridian Forest 是草／蟲／一般／飛行。
- **難度**：Normal、Hard（敵人 +70%，Stardust ×1.75）、Nightmare（敵人 +160%，Stardust ×2.5）。
- **計時賽**：通關獎牌門檻為銅牌任何勝利、銀牌 30:00、金牌 23:00、冠軍 17:30。可見一局完整通關約 17～30 分鐘。
- **計時**：每個 zone 從 10:00 倒數。

## 2. 局內

- **HUD**：
  - 左上：頭像、名稱、屬性、等級。
  - 上中：地區、Zone n/3、難度、倒數。倒數下方有「CALM」壓力條，下方顯示金幣與數量計數。
  - 右上：圓形小地圖，標出寶箱、商人、籠子、神殿等圖示。
  - 右側：KO 數和 STREAK 連殺倍數（×173）。
  - 左下：3 格道具、4 格招式（第 4 格鎖住）、Ultimate 圓鈕（顯示冷卻圈）。
- **升級三選一**（截圖 `p1-14.png`）：
  - 卡片類型：新招式、招式升級（例如 Water Gun Lv.2→3：+1 彈跳、+22% 傷害）、維他命（PP Up 加投射物、Carbos 加移速、HP Up、Calcium 加特攻、Elixir 加持續時間）。
  - 卡片標稀有度（Common、Uncommon、Movement）、NEW／UPGRADE，並寫出數值前後對比與「Affects: 某招」。
  - 選卡操作：Refresh(2)、Skip(2)、Banish(1)，數字鍵 1～3 直接選。
- **場上物件**：商人（靠近顯示 Shop）、籠子（捕捉用？）、寶箱、Poké Ball、拉霸機狀的物件、石碑或神殿、金幣、綠色經驗寶石。
- **懸崖會擋路**：第二局我被卡在懸崖凹角，被一群敵人圍住，54 秒就倒下。地形是會影響走位的。
- **結算**（截圖 `p3-end.png`）：
  - 時間、KO、總傷害、分數。
  - 拿到的 Stardust。
  - 反應（屬性連鎖？）、進化、最佳連殺、物種數。
  - 各招傷害占比。
  - 圖鑑研究進度：打倒某物種一定數量後解鎖成頭像。
- **兩局的結果**：
  - 第一局：存活 2:45、Lv.10、195 KO、19.3k 傷害。
  - 第二局：存活 0:54。
  - 兩局都死在第一個 zone，所以**守護者、神殿、進化都沒看到**。

## 3. 美術（這次最想學的部分）

| 項目 | 觀察 | 截圖 |
|---|---|---|
| 角色 | 2D 像素精靈圖，最近點取樣（不模糊），輪廓線是圖本身畫好的；腳下有柔和的橢圓影子；看起來永遠面向鏡頭 | `zoom-sprite.png`、`p4-4.png` |
| 植物與道具 | 樹、蕨類、花、蘑菇、石頭都是像素圖的公告板，數量很多，近大遠小 | `p2-combat-a.png` |
| 地形 | 草地是有像素點綴的貼圖，遠處因 mipmap 變柔；台地的側面是石磚像素貼圖，頂邊有一圈草邊；小路是另一張貼圖沿路徑鋪 | `zoom-sprite.png` |
| 遠景 | 天空漸層、遠山剪影 | `08-run-6s.png` |
| 鏡頭 | 透視；我目測俯角 35～45°，**程式實際是 FOV 70、俯角 0.45 rad（約 26°）、距離 9，可在 4.5～26 調整**（Codex，`main:4599`、`:52635`）。兩局畫面的遠近差異來自距離設定或速度 FOV 加成，不是等級 | `08-run-6s.png` 對 `p2-combat-a.png` |
| 特效 | **特效也是像素風**：Ultimate 的漩渦是大格像素的藍白色塊，水彈是圓點，命中有「It's super effective!」字樣 | `m-ult.png` |
| Ultimate 演出 | 全寬斜向橫幅，含頭像與招式名，同時鏡頭拉近 | `m-ult.png` 右上 |
| UI | 白底圓角卡片、斜紋色帶標題、粗圓體（類似 Nunito／Fredoka）、彩色膠囊按鈕、按鍵提示 | `p1-14.png`、`p3-end.png` |

**像素 2.5D 的重點**：角色、植物、特效全部用同一種像素密度、最近點取樣，3D 只負責地形與遠近。
這組合不用建模，也能有「3D 遊戲」的空間感，正好是我們要做的。

## 4. 手機

- 手機要求橫向：直向時顯示全螢幕旋轉提示，並嘗試 `screen.orientation.lock('landscape')`（失敗就忽略）。橫向短邊小於 480 時，把邏輯寬度設成 `min(1100, 長邊×480/短邊)`（Codex 報告第 7 節）。
- 這次沒用手機模擬，因為換 context 會再建一筆訪客紀錄。
