我原本就是想要做銀魂的遊戲 然後我現在要把逆轉裁判的異議跟證物還有抓到矛盾 變成銀魂的吐槽

設計吐槽玩法機制與角色互動細節。
了解，這個改法很合銀魂的精神：逆轉裁判是「找矛盾」，銀魂是「找槽點」。玩家扮演新八（全作最強吐槽役），在一群裝傻的人之中負責吐槽，劇情才能往下走。

下面是改版設計，沒提到的部分（對話畫面、懸浮按鈕、存檔）沿用上一版。

一、機制對照表
逆轉裁判	銀魂版	說明
證言	裝傻發言	角色輪流說出離譜的話，每句可能藏著槽點
追問	聽下去	讓對方繼續講，常常會越講越離譜，挖出更大的槽點
出示證物	吐槽	選一句吐槽台詞打回去
證物	吐槽素材	調查時收集的「事實」，用來當吐槽的根據
抓到矛盾	吐槽成功	全螢幕吐槽 cut-in
生命值	眼鏡耐久度	吐槽失敗會讓眼鏡裂開，碎掉就 Game Over
「異議！」	「你在說什麼啊！！」	大字吐槽泡泡
判決	吐槽評價	章節結算 S/A/B/C
二、新增玩法
1. 吐槽詞選擇
找到槽點後，從 3~4 句吐槽中選一句。選項有「正確的吐槽」、「方向對但太弱」、「完全吐錯方向」。例如銀時說「草莓牛奶是被外星人偷走的」，正確吐槽是「冰箱上明明有你的指紋！」，而不是「外星人哪會喝草莓牛奶！」（在銀魂世界外星人滿街都是，這句反而會冷場）。

2. 吐槽時機（QTE）
部分槽點有時間限制，裝傻的話講完後會出現縮圈，圈縮到剛好時點下去才能打出「完美吐槽」。太早是打斷別人，太晚就冷場了。

3. 連續裝傻
銀魂最經典的節奏：一個人裝傻、另一個人接著裝得更扯、第三個人再加碼。玩家要連續吐槽，每成功一次速度就變快，全部接住觸發「吐槽連擊」。

4. 放過不吐（隱藏要素）
有些場面「不吐槽」才是正確的。讓裝傻一路發展下去，會解鎖隱藏劇情或更離譜的展開。在選項中顯示為「……（放棄吐槽）」。

5. 吐槽力與超必殺
吐槽成功會累積吐槽力，集滿後可以發動「超必殺吐槽」，一口氣戳破整段發言的所有槽點。

6. 打破第四面牆
銀魂常拿作品本身開玩笑，遊戲也可以這樣做：角色會吐槽懸浮存檔按鈕擋到他的臉、對話框打錯字、敏感字眼被打上消音條、旁白被角色搶話等等。這類場面的槽點是 UI 本身，玩家要點畫面上的 UI 元素來吐槽。

7. 冷場懲罰
吐槽失敗時，畫面凍結，出現烏鴉叫聲和「……」，眼鏡裂一格。碎掉時的 Game Over 畫面是一副碎掉的眼鏡，旁邊寫著「新八的本體已損毀」。

五、給遊戲 AI 的 Prompt（銀魂吐槽版）
你是資深的遊戲工程師與遊戲設計師。請製作一款「手機直立式吐槽冒險視覺小說」的可遊玩 Demo，題材是銀魂的同人遊戲，核心玩法改編自逆轉裁判的詰問系統，但把「找矛盾」改成「找槽點吐槽」。

【角色】
- 玩家操控：志村新八（吐槽役）
- 主要裝傻角色：坂田銀時、神樂
- 其他登場：定春（只會汪）、登勢婆婆（擔任「家庭會議」主持人）
- 台詞需符合各角色個性：銀時懶散愛狡辯、神樂句尾加「阿魯」且很毒舌、新八認真但存在感低常被說只是眼鏡。所有台詞為原創，不直接照抄原作台詞。

【畫面規格】
- 直立 9:16，基準 1080x1920，支援 Safe Area。
- 分層：背景 → 立繪 → 特效 → 對話框 → 懸浮按鈕 → 彈出視窗。
- 對話框在底部約 28%，左上名牌，逐字顯示，右下閃爍 ▼。
- 右上兩顆懸浮按鈕：選單(≡)、存檔(S)，可拖曳吸邊，閒置 3 秒變 40% 透明，長按存檔鈕為快速存檔。

【核心玩法：吐槽系統】
1. 裝傻發言：角色輪流說出多句發言（橘色字），玩家可左右切換。
2. 每句可選「聽下去」（對方補充更多內容，可能揭露新槽點或解鎖新素材）或「吐槽！」。
3. 吐槽時跳出 3~4 個吐槽選項，限時 8 秒。有的選項需要特定「吐槽素材」才會出現。
4. 結果分四種：
   - perfect：全螢幕震動 + 集中線 + 大字泡泡「你在說什麼啊！！」 + 吐槽力大量增加
   - weak：小型泡泡，吐槽力少量增加
   - fail：冷場演出（畫面變灰停格、烏鴉叫聲、「……」），眼鏡耐久度 -1
   - hidden：選「放棄吐槽」反而解鎖隱藏劇情
5. 部分槽點是 QTE：發言結束後出現縮小的圓圈，縮到剛好時點擊為 perfect，太早或太晚為 fail。
6. 連續裝傻：多個角色接連裝傻，玩家需連續吐槽，每成功一次時限縮短，全部成功觸發「吐槽連擊」演出。
7. 眼鏡耐久度 5 格，歸零 Game Over，畫面為碎掉的眼鏡與文字「新八的本體已損毀」，從最近檢查點重來。
8. 吐槽力集滿可發動「超必殺吐槽」，一次戳破整段發言的所有槽點。
9. 第四面牆演出：部分槽點是 UI 本身（例如角色抱怨懸浮按鈕擋到臉、對話框出現錯字、敏感字被消音條蓋住），玩家要點擊該 UI 元素來吐槽。
10. 同一槽點失敗 3 次，由神樂給出提示（語氣很毒舌）。

【調查模式】
- 場景上有可點擊熱區，查過的打勾，獲得「吐槽素材」。
- 底部選單：調查／移動／對話／素材。

【其他畫面】
- 標題、選項分支、吐槽素材與人物檔案（4 欄格狀）、存讀檔（3 頁 × 6 格，含縮圖）、對話紀錄、設定、章節結算（吐槽成功數、PERFECT 數、最高連擊、冷場次數、隱藏裝傻數、評價 S/A/B/C）。

【系統】
- 劇本用 JSON，與程式分離。指令至少包含：bg、char、say、choice、flag、goto、item、investigate、boke_round（含 lines、listen、tsukkomi.options、result、require、timer、qte）、shake、flash、cutin、freeze、bgm、se。
- 旗標、素材、眼鏡耐久度、吐槽力都要存進存檔。換場景與每回合裝傻開始時自動存檔。

【Demo 劇本：第一章「萬事屋冰箱草莓牛奶失竊事件」】
- 開場：新八發現冰箱裡他買的草莓牛奶不見了。
- 調查萬事屋（取得素材：空牛奶瓶、銀時嘴角的白色痕跡、神樂的醋昆布包裝、定春的腳印）。
- 家庭會議（由登勢婆婆主持）：
  - 第一回合：銀時裝傻 4 句，其中 2 句可吐槽。
  - 第二回合：神樂裝傻 3 句，並試圖把罪推給定春。
  - 第三回合：銀時 + 神樂連續裝傻（連擊關卡）。
  - 至少一個第四面牆槽點、一個 QTE 槽點、一個隱藏「放棄吐槽」路線。
- 結局：真相大白，但最後又出現一個讓新八崩潰的反轉。
- 約 80~100 句對話，節奏要快，每 3~5 句就要有一個笑點。

【美術】
- 先用 placeholder：背景為漸層 + 地點名，立繪為剪影 + 角色名 + 表情文字。所有素材路徑集中在一個設定檔，方便之後替換。

【程式要求】
- 模組化（劇本引擎、吐槽系統、UI、存檔、音效分開），加上註解，附上新增章節與替換素材的說明。
