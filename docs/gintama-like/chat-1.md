可以。我會先把「銀魂感」拆開，而不是直接從「做一款銀魂遊戲」開始。

真正讓《銀魂》成立的，不只是角色、吐槽、江戶或武士，而是幾個很特殊的節奏：

極度日常 → 突然荒謬
很蠢的目標 → 當成世界末日處理
玩家以為在玩 A → 系統突然變成 B
角色明知道自己在遊戲裡
搞笑累積很久 → 某個瞬間突然認真
認真完 30 秒 → 再用低級笑話全部毀掉

所以如果你真的要做一款「有銀魂靈魂」的獨立遊戲，我反而不建議先做動作 RPG。

我最想推的是：

《萬事屋模擬器》型的像素日常遊戲

表面上是一款：

而且從你的開發背景來看，我反而不會先碰 Unity 3D 大型專案；這種作品很適合用 Godot + 2D Pixel Art + data-driven event system 做，讓大量成本放在事件腳本、角色對話與小型玩法，而不是地圖與美術產量。

如果下一步要繼續發散，我會往三條完全不同的方向推：

《沒事屋》：Stardew Valley × 銀魂，日常委託生活 RPG。
《江戶最糟的一天》：一天無限輪迴，每輪都因為蝴蝶效應變得更荒謬。
《吐槽之魂》：WarioWare 式超短 mini-game 集合，每 5～20 秒換一個玩法。

其中我認為 1 最有長期作品潛力，3 最適合獨立開發先做 Demo，2 則最有機會做成真正讓人記住的 indie game。
