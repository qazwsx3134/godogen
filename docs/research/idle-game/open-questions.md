## 2. 想確認原作時，追加什麼觀察最有效

| 原作未知 | 建議觀察 | 能排除的歧義 |
|---|---|---|
| 自動程度、完整卷軸 | 從開始到兩波清完的連續30～60秒，記錄有無輸入 | 是否接敵停下、清完移動、背景／鏡頭如何捲 |
| 黃色量表用途 | 同時保留名稱／tooltip、攻擊與區域進度，對比變化 | 普攻條、波次條、經驗或其他量表 |
| 掉落／取得夢靈 | 從敵人死亡到背包新增，打開日誌 | 擊殺掉落、捕捉、保證獎勵或抽取 |
| 性格與屬性 | 同物種／等級／裝備，對比兩性格與詳細tooltip | 加值作用的屬性、順序及括號意義 |
| 技能目標 | 兩隊友不同最大HP／當前HP／比例，完整錄一次施法 | 最低HP還是最低比例、是否等缺血才放 |
| 治療反應 | 全滿、少量缺血、大量缺血各一組，保留日誌 | raw／effective／overheal、同源觸發與堆疊 |
| 羈絆疊加 | 2名→3名、同物種重複、戰死一名的前後面板 | 門檻累加／取代，是否計重複與死亡 |
| 死亡與Boss | 一次全滅與一次用鑰匙進入／失敗 | 重試、扣費、返還、掉落與首通 |
| 天賦交易 | 節點購買前／後／重登及是否有重置 | 金幣成本、上陣格加成、前置與退款 |
| 融煉／進化 | 主體及材料前後完整詳情，保留確認畫面 | 消耗、品階、保留欄位、退裝與鎖定 |
| 工坊 | 自動填入、製作成功與失敗／跨階，保留slot tooltip | 五槽／中央槽用途、材料數、機率條件 |
| 離線與睡眠 | 保存金／EXP／隊伍／時間，關閉或睡眠後回來 | 是否離線、收益上限、領取與凍結快照 |
| 背包滿 | 小容量填滿後持續掛機，再看日誌／待領 | 丟棄、停止、代售或另存 |

以上是後續蒐證建議，本次沒有實際操作原作，也沒有證據就不補原作答案。

## 3. 主要風險登錄

| 風險 | 早期信號 | 處理與出口 |
|---|---|---|
| 桌面殼（Deferred） | 目前無對應製作工作 | 不列入M1～M6阻擋項；恢復S03時再評估 |
| 玩法只剩數值自動長 | 換隊無差異，永遠選最高ATK | M3固定資源build／敵型矩陣 |
| 治療／反應正回饋失控 | 特定build事件量爆炸、永動免死 | A05、事件有界、數值／觸發政策實測 |
| 重複物／工坊經濟無底 | 重複堆積、唯一消耗卻要太久 | 先畫source／sink與時間成本，M4再擴 |
| 進度損壞／重領 | 中斷後多扣、receipt與資產不同步 | 同revision快照、故障注入、去重 |
| 背景耗能與記憶體 | 開窗次數越多越慢、hide仍滿載 | S30逐階測量，M5八小時soak |
| 離線模型偏袒特定build | 補師隊在線離線收益差很大 | 同核心校準／分模型，未達門檻不開 |
| 內容規模失控 | 提早承諾378隻、完整動作與進化 | 分里程碑小內容包、量產前先驗1套 |
| UI資訊過載 | 新玩家只會關掉所有視窗 | 分層資訊、逐步解鎖、可重看教學 |

任何高風險項只完成文件還不算解除；需對應M1～M6的實測證據。
