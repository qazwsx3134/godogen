# Azeroth Survivors 分析

2026-10-26。研究對象是 <https://wow.aethus.pl/>（v0.119.0），一款魔獸世界題材的 survivors-like 同人遊戲，作者署名 Aethus。

研究方式：
- 在內建瀏覽器實際玩了一局人類戰士，地點是艾爾文森林，存活 2:08，升到 10 級後倒下。
- 看過主選單、天賦、掉落表、收藏、成就、獎勵各頁。
- 讀了網頁的網路請求、全域變數和 console 紀錄。

本文的數字都是畫面上讀到的；標「推測」的是從現象推出來的。

依這份分析寫成的 godot-kit 模組列在最後一節。

## 結論

這款遊戲值得學的是**兩層成長怎麼咬合**，以及**一套資料驅動的自動施法規則**：
- 局內用三選一抽卡拼出一套自動施法組合，每張卡帶稀有度，稀有度直接決定數值。
- 局外有三條成長線：
  - 天賦經驗變成天賦點，投到里程碑會改變法術玩法。
  - 首領掉落的裝備永久收藏。
  - 成就點數換特權，例如多一次重抽、放逐、跳過。

美術方面，它沒有自己的美術：直接讀取魔獸世界舊版客戶端的原版資料。能學的是那套 2004 年的低面數製作方法，不是素材本身。

## 1. 技術架構

```
瀏覽器
 ├─ rogue.js / addons.js / saves.js   玩法層設定、addon 安裝、存檔匯出匯入
 ├─ boot.js → wenilla.js + wenilla_bg.wasm (87 MB)
 │    Rust（crate benilla-app）重寫的 WoW 1.x 客戶端：
 │    ├─ 載入 M2 模型、BLP 貼圖、ADT 地形、WMO、DBC 資料表
 │    ├─ 執行原版 FrameXML / Lua 介面（ui_script/addons.rs）
 │    └─ 內建本機伺服器（host=azeroth.local、realm=Elwynn Forest）
 └─ /data/…   29,502 個原版客戶端檔案（索引在 /data/__index）
```

- 介面全部畫在 WebGL canvas 上，DOM 裡沒有文字，所以無法用網頁工具讀取。
- 存活玩法（刷怪、卡片、計時）推測寫在 WASM 裡的伺服器端，前端只負責顯示。
- 第一次進遊戲要下載約 500 個檔案，再執行約 100 個介面腳本（FrameXML）。分頁放在背景時會暫停，所以載入時間取決於分頁有沒有被看著，從幾十秒到十幾分鐘都可能。

**版權**：模型、貼圖、地圖、音效、介面圖都是 Blizzard 的原版素材。這次研究沒有下載或保存任何素材檔。我們的模組只取機制，素材一律原創。

## 2. 畫面與美術（能學的做法）

| 觀察 | 做法 | 套用到我們的原型 |
|---|---|---|
| 角色和怪物是低面數模型（WoW 1.x 的角色大約 1,500～3,000 三角面） | 輪廓靠模型，細節全畫在貼圖上 | seal-meadow 的 3D 流程：素體 3,000～6,000 面已經偏多，可以再減 |
| 手繪貼圖，光影直接畫進貼圖 | 幾乎不靠即時光照，換到任何光源下都好看 | 用卡通材質：Shader to RGB 加兩階 ColorRamp |
| 小尺寸貼圖拼成圖集（BLP 常見 256～512） | 少量貼圖、重複使用 | 每件裝備一張小圖集 |
| 法術特效是粒子和帶狀拖尾，用加法混色，顏色飽和（順劈斬的白弧、旋風斬的綠色迴旋、戰鬥怒吼的地面光圈） | 特效比模型更負責「打擊感」 | kit 已有 `fx_burst`、`fx_slash` 類的 shader，可以照這種配色做一套 |
| 傷害數字：一般白色、精英或暴擊黃色大字，向上飄 | 數字本身就是回饋 | seal-meadow 的 `Fx.popup` 已有，可以依稀有度和法術換色 |
| 鏡頭：第三人稱斜俯視約 45 度，視野不遠 | 敵人密度高時也看得清自己 | — |
| 介面：原版 WoW 頭像、動作列、小地圖、聊天框，再加上 survivors 的計時、擊殺數、金幣、寶箱數 | 熟悉的介面加上少數新欄位，學習成本很低 | — |

## 3. 局內玩法

### 流程

```
選職業／種族／區域 → 進場（站著不動時計時器不開始；畫面寫「移動以開始」）
  → 自動攻擊＋自動施法清怪 → 吃經驗 → 升級：三選一抽卡（時間暫停）
  → 時間軸事件（獸群狂奔、精英）→ 3/6/9/12 分鐘首領 → 16:00 最終首領
  → 倒下或勝利 → 結算：天賦經驗、統計
```

### 操作
- WASD 移動（或同時按住滑鼠左右鍵）。
- 攻擊與法術全部自動。
- 升級時：1/2/3 選卡（再點一次確認）、R 重抽、Enter 開始。

### 升級與卡片

- 每升一級都有固定成長：傷害 +3%、最大生命 +9、每秒生命回復 +0.08（訊息欄原文）。另外再三選一抽卡。
- 經驗需求：Lv1→2 要 5，Lv2→3 要 14；2 分鐘升到 10 級，前期升得很快。
- 法術欄位 6 格，卡片上寫「佔用法術欄位 2/6」。
- 卡片分兩種：
  - **新法術**：佔一格欄位，加成是傷害 %。
  - **強化已掌握的法術**：等級 +1，加成可能是傷害 %、冷卻 % 或目標數。
- 每局重抽 3 次。成就特權還能再加重抽、放逐、跳過換金幣、開局多發卡。

**稀有度**決定數值（實際看到的卡）：

| 稀有度 | 顏色 | 新法術加成 | 升級加成 |
|---|---|---|---|
| 普通 | 白 | （撕裂沒有寫） | 傷害 +18%（順劈斬 1→2）、冷卻 −5%（盾牌猛擊 3→4） |
| 優秀 | 綠 | 傷害 +18%（血性狂暴、嗜血、斬殺）；增益類為冷卻 −7%（戰鬥怒吼） | 傷害 +25%（斬殺 1→2）、冷卻 −10%（挫志怒吼 1→2） |
| 精良 | 藍 | 傷害 +25%（旋風斬） | — |
| 史詩 | 紫 | 傷害 +34%（盾牌猛擊） | — |
| 傳說 | 橘 | — | 冷卻 −23% 且目標 +2（盾牌猛擊 1→2） |

### 法術的目標規則（戰士）

| 法術 | 規則 |
|---|---|
| 順劈斬（初始） | 前方弧形，多目標 |
| 盾牌猛擊 | 7 碼內最多 2 個目標，332 傷害；暈眩 1.5 秒，對首領只有四分之一；優先打首領和精英 |
| 嗜血 | 7 碼內最近的 1 個目標，172 傷害；回復傷害的 50%；優先打首領和精英 |
| 斬殺 | 10 碼內 1 個目標，234 傷害；生命低於 30% 時加倍（468）；優先打首領和精英，其次是低於 30% 的 |
| 撕裂 | 8 碼內生命最高的 3 個目標，且還沒被撕裂的；7 秒內分 7 次共 185 傷害 |
| 旋風斬 | 8 碼內全部敵人 |
| 血性狂暴 | 每次命中累積 2 點怒氣（每秒上限 10）；滿 100 時對 9 碼內全部造成 283；10 秒一次；離開戰鬥會流失怒氣 |
| 戰鬥怒吼 | 所有傷害 +40%，持續 11 秒；有敵人進入 30 碼內才施放 |
| 挫志怒吼 | 14 碼內全部敵人，被命中的敵人傷害降低 35% |
| 致死打擊 | 7 碼內最近的 1 個目標，優先打首領和精英 |

可以看出規則是用少數幾個參數組合出來的：射程、目標規則（最近、生命最高、全部）、目標數、優先標籤、斬殺線、持續傷害、暈眩（首領減免）、吸血、增益與觸發距離。`auto_caster.gd` 就是照這組參數寫的。

### 敵人與時間

- 前 30 秒是狗頭人群，1 分鐘左右換成野狼，之後出現精英（右下角有精英提示）。
- 時間軸事件：開場橫幅「迪菲亞起義：在猛攻中存活下來！」，約 1:00 出現「獸群狂奔而過！」。
- 首領時間表（掉落表頁）：艾爾文森林 3:00 霍格、6:00 毒牙之母、9:00 拉克佐、12:00 斯邁特先生、16:00 最終首領艾德溫·范克里夫。
- 結算統計分開計算精英、守護者、首領，可見除了首領還有「守護者」這一類敵人（這局沒遇到）。

### 金幣與寶箱

（2026-10-26 使用者補充）

- **金幣**：局內貨幣，擊殺時獲得。人類的種族被動是金幣 +20%；特權「跳過」不選卡時也是換成金幣。
- **寶箱**：每開一次都要花金幣，開出隨機道具，而且**越開越貴**。
- HUD 右上的「寶箱 20」推測就是下一個寶箱的價格。這局帶著 122 金幣結束，卻一個都沒開；推測寶箱要在地圖上走過去才能開，不會自動扣錢。這點沒有實際驗證。
- 這是常見的 survivors 設計：金幣不會溢出變成沒用，價格上升則限制同一局能換到的道具數量，讓金幣加成的種族和特權有實際價值。

## 4. 局外成長

```
         ┌──────── 天賦經驗（存活、擊殺、首領、勝利 × 區域難度）
 一局 ───┼──────── 首領掉落 60% → 裝備永久收藏（9 部位 × 6 階）
         ├──────── 成就進度 → 成就點數 → 獎勵（特權、夥伴、戰袍、外觀）
         └──────── 金幣累計 → 零錢類成就
```

金幣本身是局內貨幣，用在寶箱上（見上節），不會帶出局外。

- **職業**：9 個（戰士、聖騎士、獵人、潛行者、牧師、薩滿祭司、法師、術士、德魯伊），每個有初始技能、生命值和法術池。
- **種族被動**：例如人類每 30 秒傷害 +15%、持續 10 秒，經驗 +10%，金幣 +20%。外觀也在這裡選。
- **天賦**：
  - WoW 原版的三系樹，最多 51 點；每系投 5 點開一行。
  - 10、20、30 點是里程碑，會改變法術玩法。例如武器系：重傷、橫掃攻擊、致死創傷；狂怒系：暴怒、亂舞、劍刃風暴。
  - 3 組天賦方案，重置免費。
  - 經驗曲線：第 1 點需要 80。
- **區域**：12 個，從艾爾文森林到納克薩瑪斯，每個區域對應一個裝備階級。打敗最終首領才開下一區。
- **裝備**：54 欄。每區 5 個首領，各掉一件，掉率 60%。永久保留，穿上有屬性加成。收藏頁是「6 階 × 9 部位」的格子，並列出「下一批可以拿的裝備」。
- **成就**：總點數 2270，分成區域 24、職業 20、收藏 7、壯舉 21、累計 12、合作 14 類。例如進行 10 次冒險、收集 5000 金幣、擊殺 10000 個敵人、進行 100 次冒險。每個職業各自累積，點數全帳號共用。
- **獎勵特權**（用成就點數買，有等級）：三思（多一次重抽）、放逐、跳過（換金幣）、開局手牌、老兵的教誨（等級較低的職業天賦經驗 +20%）、銳眼（提高掉落機率）。
- **其他**：冒險選項（難度）、合作模式（和好友一起玩）、存檔下載與匯入。

## 5. 沒觀察到的部分

- 寶箱在地圖上怎麼出現、開出的道具有哪些種類、價格實際的漲幅（規則見「金幣與寶箱」，數字沒有量到）。
- 守護者敵人、首領戰的招式、勝利後的畫面。
- 冒險選項有哪些難度、加成多少。
- 合作模式怎麼連線。

## 6. 做成模組：對照 godot-kit

| 遊戲系統 | kit 模組 | 狀態 |
|---|---|---|
| 三選一抽卡、重抽、放逐、法術欄位、法術等級 | `card_draft.gd` | 已有 |
| 稀有度：權重、運氣、依稀有度給傷害／冷卻／目標 | `rarity.gd` | **新增** |
| 自動施法：冷卻、射程、目標規則、優先標籤、斬殺、持續傷害、暈眩（首領減免）、增益與觸發距離、吸血、等級加成、全域倍率 | `auto_caster.gd` | **新增** |
| 一局的時間軸：首領與事件、生怪速度曲線、各時段的敵人種類、精英機率、同場上限 | `run_timeline.gd` | **新增** |
| 三系天賦：每 5 點開一行、前置條件、10/20/30 里程碑、多組方案、免費重置、經驗換點數、單局經驗公式 | `talent_tiers.gd` | **新增** |
| 首領掉落與收藏：區域解鎖、掉率與運氣、已擁有不重複掉、穿戴與屬性、各階進度、下一批可拿的裝備 | `loot_ledger.gd` | **新增** |
| 局內寶箱：花金幣開、越開越貴、隨機道具 | `chest_shop.gd` | **新增** |
| 成就（累計或單局目標、解鎖獎勵） | `run_goals.gd` | 已有 |
| 成就點數換特權（有等級的商店） | `upgrade_tree.gd`（不設相鄰關係就是永久商店） | 已有 |
| 大量敵人的 2D 立牌、受擊閃白、消散 | `sprite3d*` | 已有 |
| 打擊停頓、震屏、音效 | `time_control`、`camera_shake`、`sfx_bank` | 已有 |

新模組都是純邏輯（RefCounted，不依賴節點），可以存讀檔，給定種子時結果固定。測試在 `godot-kit/tests/test_survivor_modules.gd`，共 109 項檢查。

### 組合方式

```
每一幀（沒有在選卡時）
  RunTimeline.step(delta, 活著的數量) ─→ 生怪（種類、是否精英）、事件（首領）
  AutoCaster.step(delta, 玩家位置, 敵人清單) ─→ 命中（傷害、暈眩）、回血、增益
升級時
  CardDraft.offer() ─→ 三張卡的 id
  Rarity.roll_offer(ids, rng, 銳眼) ─→ 每張卡的稀有度
  選了以後：新法術用 AutoCaster.learn(spell, Rarity.bonus(tier))
           升級用 AutoCaster.rank_up(id, Rarity.bonus(tier, "upgrade", rng))
           每級固定成長：AutoCaster.damage_mult += 0.03
首領死亡
  LootLedger.roll_drop(zone, boss, rng, 銳眼) → collect → worn_stats() 進下一局
走到寶箱旁
  ChestShop.open(金幣) → 扣錢、拿隨機道具；HUD 顯示 ChestShop.price()
結算
  TalentTiers.add_xp(TalentTiers.run_xp(本局統計, 權重, 區域倍率))
  RunGoals.note("kill", n) …
```
