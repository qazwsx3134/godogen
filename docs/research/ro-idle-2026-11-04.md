# RO放置仙境（ro-idle.app）：系統與營運研究

日期：2026-11-04。版本快照：更新紀錄最新 p6.44（2026-11-03）。研究對象：[ro-idle.app](https://ro-idle.app/)，一款以仙境傳說「懷舊小黑窗」為風格的同人放置掛機網頁遊戲（繁中、PWA、手機與電腦皆可）。

**判斷：這款遊戲真正的核心不是戰鬥，而是「規則編輯器＋可解釋的自動執行＋離線補算報告」。** 玩家花時間的地方是掛機設定：條件積木、怪物控制、補給、回城處理、事件巨集；角色依規則自動打怪，回來後看伺服器補算的離開期間報告。多人部分把互動放在「不需同時在線」的地方：隊伍分配、共享 MVP、全服擊殺目標、露天商店、好友寄送、非同步切磋重播。更新紀錄頁可見的 20 天（10/15～11/03）內有 239 筆更新，其中多數由玩家回報或建議觸發；更早的版本存在（可見範圍從 p5.9 開始），開服日期未知。

給本作的借鏡另寫在 [cyberpunk-text-mmo/ro-idle-lessons.md](../cyberpunk-text-mmo/ro-idle-lessons.md)。

## 1. 產品骨架

### 1.1 核心循環

```text
          ┌──────────── 掛機設定（規則編輯器）────────────┐
          │ 技能規則＋條件 / 怪物控制 / 補給 / 回城處理 / │
          │ 依怪換裝 / 逃生 / 事件巨集 / 配置檔           │
          └───────────────────────┬───────────────────────┘
                                  ↓ 開始掛機
選地圖 ─→ 自動尋怪 → 戰鬥 → 撿取 → 負重/補品門檻 → 回城賣/存/買 → 回地圖
   ↑                    │                                          │
   │               危險/圍攻/低HP → 逃生（瞬移/翅膀）              │
   │                    │                                          │
   │               死亡 → 扣1%經驗 → 復活 →（連續死亡保護）停止    │
   │                                                              ↓
   └── 換地圖/轉職/配點/精煉/插卡 ← 離開期間報告・統計・日誌 ←──┘
                                  ↓
          社交層：隊伍分配・全服MVP・全服活動・露天商店・寄送・排行
```

**官方**：新手指南的四步是建角、選職業與地圖、安排技能與補給、配點（自動配點預設關閉）。「離線後回來時伺服器會補算進度」。

### 1.2 內容規模（官方，官網首頁數字）

41 職業、330 技能、429 怪物、895 道具、527 裝備、226 地圖。內容來自原作資料包，「資料與此版遊戲共用內容包」：官網資料庫與遊戲讀同一份資料。

### 1.3 平台與介面（官方，未實測）

- 原生網頁＋PWA manifest（standalone、主題色 `#0a4fd6`）；官網另有夜間模式，畫面出來前就讀 localStorage 套上，避免先閃白底。
- 介面有「舊版／新版／測試版」三種，可在底部 ⚙ 切換（實測時預設為新版）。測試版（p6.35 推出時叫「新介面（測試）」）：中間是最大的「小黑窗」（戰鬥與聊天日誌），右邊是基本資料、地點與目標、隊伍、統計；底部 5 個入口（角色、背包、冒險、社交、城鎮），電腦版有 Alt 快捷鍵，視窗可拖動、縮放、同時開多個。
- 新介面的手機版：小黑窗全螢幕，上方切換戰鬥／聊天；「狀態」按鈕看地點、增益與統計；底部分頁點了從下方拉出頁面，再點一次收回。
- 主選單依用途分組（p6.30）：角色（人物、職業、生命體）、物品（背包、倉庫、商店、攤位、交易）、掛機（設定、統計、查詢）、社群（隊伍、公會）。贊助放最後。
- 音效與音樂使用原版客戶端素材，可分別開關；隊友的歌舞音效也有獨立開關。

## 2. 掛機設定：整個遊戲的核心

### 2.1 三種顯示模式，一份設定（官方）

- **簡易模式**只列常用項目，新角色按「開始掛機」就能玩。
- **進階模式**多了條件積木、怪物控制表、自動換裝、倉庫補給、撿取清單、自動切換配置檔、事件巨集、匯入匯出。
- **OpenKore 模式**內容和進階模式相同，只是依 OpenKore 設定檔分頁（config.txt、mon_control、items_control、eventMacro…），每個區塊標出 OpenKore 關鍵字，並有唯讀的 config.txt 文字檢視。給老玩家熟悉的心智模型。
- 切換模式不改任何設定；簡易模式下看不到的進階設定照樣生效，畫面會列出有哪些。

### 2.2 條件積木（官方）

同一套條件可以掛在技能、藥水、坐下回復、每種逃生、換裝規則、倉庫補給、巨集上。可用的條件：自己 HP／SP、狀態、負重、Zeny、在不在城鎮、正在做什麼；隊友的狀態、HP、人數；目標的 HP、狀態、種族、體型、是否 Boss；身邊敵人數；上一招是什麼（連段）。

- 預設是全部成立（AND）；「新增『或者』條件組」最多 6 組（OR of ANDs）。
- 輔助技能另有「輔助對象（隊友）」篩選：HP 低於、SP 低於、狀態、職業。
- 攻擊規則依清單順序取第一條符合的；專用規則放在通用規則前面。
- **每條規則下方即時顯示「目前不施放」的原因**（SP 不足、冷卻中、哪個條件不成立），全部成立時顯示「條件都成立」。
- 「接著施放」讓一條規則放完立刻接下一招，跳過它自己的條件。

### 2.3 其他規則表（官方）

| 規則表 | 做什麼 |
|---|---|
| 怪物控制 | 每隻怪選主動打／優先打／被打才還手／引怪；逃生選看到就逃／被打才逃／打完目標再逃；圍攻權重（強怪算 2 隻，0 不計）；「自己符合才主動打」 |
| 依怪物換裝 | 依怪物、屬性、種族、體型由上往下找第一條符合的；空條件的規則放最下面當預設裝 |
| 道具設定／回城處理 | 一個道具一列：用途、補給「少於幾個就補到幾個」、先從倉庫拿、不夠就回城買、回城賣、存倉、優先撿 |
| 逃生 | 危險名單、等級差、MVP 視為危險；先試瞬移技能再試翅膀；「地上有東西時先撿，最多幾秒再逃」（0～15 秒） |
| 事件巨集 | 條件＋一串步驟（放技能、用道具、換裝、等待、回城補給、換地圖、接另一條巨集最多 3 條、切配置檔、停止掛機…）；單次最長 60 秒；緊急逃生優先於巨集；「只執行一次」用於開場準備 |
| 暫停而非停止 | 「停止掛機」可勾「條件成立後自動繼續」：留在原地不找新怪，有怪來照打，每 10 秒檢查一次 |

### 2.4 防呆與保護（官方）

- **連續死亡保護**：60 分鐘內死亡 1／2／3（預設）／5／10 次就停止，或不限制。
- **7 天沒上線自動停止掛機**，日誌寫原因；帳號與物品不刪。
- **上鎖**：裝備與卡片上鎖後不能賣、交易、擺攤、丟棄、精煉、插卡，自動化流程全部跳過。
- 回城賣預設不賣：穿著的、上鎖的、精煉過、插卡、鍛造、損壞、換裝規則或巨集指定要用的。
- 自動購買不會讓 Zeny 低於這次開始掛機時的 20%；連續兩次買不到下限就停止專程回城並提示。
- 載入設定前自動備份，可一鍵還原。

### 2.5 設定分享（官方，p6.17～p6.18）

掛機設定可以分享到伺服器、按讚、檢舉（前端推論：`/api/shared-configs/:id/like|report|delete`）。列表用紅字標出危險內容：自動配點、回城賣卡片或高價道具、沒設購買預算、主動打 Boss／MVP、巨集會用掉道具。載入時列出這些項目讓玩家逐項勾選，沒勾的不套用。套用的分享被刪除或下架時會提醒。另有：匯出成檔案、只匯出／匯入部分區塊、瀏覽器內 5 個存檔位、伺服器配置檔每角色 10 組。

## 3. 可解釋性：日誌、統計、報告

- **離開期間報告**（官方）：上線時伺服器分批補算，報告顯示後才進入遊戲。報告列出每次死亡的原因、打倒的 MVP、稀有掉落（只列裝備與卡片）。
- **死亡歸因**（官方）：死亡訊息記錄被哪隻怪、哪個技能打倒、最後一下多少傷害、在哪張地圖。統計頁有「死亡紀錄」（最近 20 次），日誌被洗掉也看得到。為了撿稀有掉落而沒逃時，會寫出「為了撿〇〇，被圍攻（或遇到危險怪）時沒有逃」。
- **統計「自歸零起」**（官方）：只有按「歸零」才重新起算；起點存在瀏覽器，不跨裝置同步。
- **體感與數字的差異**（官方）：在線狀態約每 3 秒成批提交與推送，戰鬥事件各自保留模擬時間；排行依最後已結算的等級；日誌有上限，長離線摘要可能明示資料不完整。
- **技能說明顯示實際詠唱**（官方，p6.33）：依角色目前的 DEX 與裝備算出實際秒數，附基礎秒數；預覽加點時跟著變。
- **公式公開**：「玩法與公式」頁列出六圍用途、詠唱、ATK、HP／SP、屬性相剋表、體型修正表，附 DEX 詠唱試算器；並明說「依本遊戲實際程式整理，不能直接套用其他版本 RO 的公式」。
- **查得到 ≠ 已開放**（官方）：技能頁標示已實作／待實作／停用；資料列出不代表角色已符合使用條件。

## 4. 成長與經濟

### 4.1 成長（官方）

- 職業：初心者 → 一轉 → 二轉（2-1／2-2）→ 轉生（Base 99、Job 50、技能點用完、付 1,285,000 Zeny）→ 進階一轉 → 進階二轉；轉生後 HP／SP 1.25 倍、經驗約 3 倍，排行榜上轉生角色排在前面。
- 死亡扣「這一級所需 Base EXP 的 1%」，不降級、不扣 Job EXP。
- 重置：Base 69 以下免費洗點；之後首次 300 萬、每次再加 100 萬。技能重置次數隨轉職贈送。
- 形象只能設定一次（性別、髮型、髮色）；更名券、髮型券、染髮券另由轉蛋取得。形象不影響數值。

### 4.2 Zeny 流動（官方）

| 來源 | 去處（sink） |
|---|---|
| 怪物掉落賣 NPC、撿到就賣（收 10% 手續費） | 藥水、箭矢、翅膀、回城補給 |
| 露天商店賣給玩家 | 擺攤稅：單價滿 100 萬才收 3%（p6.33 由「整筆合計」改「看單價」） |
| 交易、好友寄送 | 精煉費用與損壞、修理、倉庫開倉費 |
| — | 洗點、轉生 1,285,000 Zeny、轉蛋 200,000／抽 |

Zeny 上限每角色身上與倉庫各 21 億（p5.63 由 10 億提高）。倉庫 600 格。

### 4.3 製作與精煉（官方）

鍛造、配藥、做箭矢、箭矢筒（500 支壓成 1 個，重量 25）、果汁等；p6.40 起製作不限城鎮。精煉超過安全值 2 級以上，成功或失敗都會全服公告（例：「某某的 +6 鋼鐵鎖子甲 精煉 +7 失敗，裝備損壞了……」）。

## 5. 多人與社交

| 系統 | 怎麼運作（官方） | 互動型態 |
|---|---|---|
| 隊伍 | 同帳號最多 4 隻一起掛；組隊大廳招募缺的職業與等級區間，可自動接受；最多同時申請 5 隊 | 半同步：有一人在線就整隊推進，全隊離線才停 |
| 隊伍分配 | 隨機分配只決定誰撿；該角色打完目前目標先撿 | 非同步 |
| 協助範圍 | 「協助隊友打怪」「對隊友輔助」兩個獨立開關；p6.38 可指定只幫哪些隊友 | 玩家自己決定合作深度 |
| 全服 MVP | 每張圖同時一隻，照原版重生；全服共用一條血量；傷害最高的隊伍搶到；**每次掉兩份完整掉寶**：一份給搶到的隊，另一份依傷害加權分給其他出手的人；離線角色遇不到 | 同步競爭＋參與保底 |
| 全服活動 | 一週內全服打倒 2000 萬隻波利（11/3 由 3000 萬下修），達標後 3 天掉寶 1.5 倍；進度顯示在遊戲與**官網每一頁上方**；離線擊殺上線補算後才計入 | 非同步合作 |
| 公會 | 公會列表、招募設定、入會申請（最多 3 個、7 天失效）、公會倉庫 | 非同步 |
| 露天商店 | 搜尋所有城鎮的攤位，依單價排序；攤主掛機或下線時照常營業；帳號 24 小時沒操作自動收攤 | 非同步交易 |
| 好友寄送 | 分批領、領到倉庫、退回 | 非同步 |
| 好友切磋 | 用雙方最後一次結算的裝備與「切磋技能」設定模擬 1v1，3 分鐘；對方不必在線；紀錄保留 7 天，可重播並分享到聊天 | 非同步 PvP，無獎勵 |
| 競技場 | 依等級分三場；強制模式直接開打、安全模式需對方 60 秒內接受；計分照原版 PvP 房；純娛樂 | 同步 PvP，無獎勵 |
| 南門聊天室 | 原版場景，坐在地上聊天、頭上冒對話框；一間 50 人自動分房；掛機照常；10 分鐘 zZ、30 分鐘自動離開；可縮小成右下角一條 | 社交場所 |
| 稱號 | 聊天名字前顯示稱號（p6.26） | 身份展示 |

**公開 API（2026-11-04）**：排行榜分 `overall`（前 50）、`families`（7 個職業系各一榜）、`forge`（鐵匠鍛造分數）、`pharmacy`（配藥）；快取 30 秒。總榜前 50 名**全部已是 Base 99 且轉生**。轉生在 10/27（p6.0）才開放，也就是約 8 天內，前 50 名都轉生並在約 3 倍的經驗曲線上重回 99：等級榜已經飽和，鍛造、配藥這類非戰鬥榜才有區分度。全服擊殺活動目前 6,912,982／20,000,000（活動開始約 30 小時）；回應另有 `missMult: 1.2` 欄位，推測是未達標時的較小加成（前端推論，官方文字未說明）。

## 6. 公平、反濫用與帳號安全（官方）

- 停權只針對：腳本／外掛自動操作、大量建帳號多開掛機、現金交易。偵測條件不公開，申訴在 Discord。
- 同帳號最多 5 角、同時掛 4 隻；同一網路（IP）11/5 起最多 12 隻同時掛機（含離線掛機），超過時最晚使用這個網路的帳號先被停；「不會因此停權」。伺服器只存 IP 與裝置特徵的加密雜湊。
- 刪除角色恢復 **7 天等待期**（10/20）：原本確認後立刻刪除，帳號外流時別人幾秒就能刪角。
- 同帳號角色曾被禁止同隊（10/17），後來改成允許、並曾收「掛機位租金」，10/22 取消並全額退款。
- 畫面開著但 20 分鐘沒操作，即時畫面暫停、改為離線結算；有新版本時，沒在操作的分頁自動重新整理。

## 7. 收益模式（官方，僅供參考）

## 8. 技術架構（前端推論）

| 觀察 | 意義 |
|---|---|
| `POST /api/characters/:id/commands`，body 為 `{commandId, command, expectedCommandRevision?}`；網路錯誤重試 3 次、間隔遞增 | 冪等指令＋樂觀鎖；回應直接帶新的 `view` |
| 所有操作都是 `command.type`：`start`、`stop`、`updateConfig`、`sell`、`refine`、`rebirth`、`mailSend`、`vendOpen`… 上百種 | 單一指令入口，伺服器是唯一權威 |
| `EventSource('/api/characters/:id/stream?after=…&chatAfter=…')`，事件：`snapshot`、`events`、`gap`、`chat`、`trade`、`arena`、`lounge`、`superseded`、`restart`、`idle` | SSE 單向推送；游標續傳；`gap` 表示補不回來要重抓；`superseded` 是被其他分頁接手 |
| 稀有掉落紀錄改為只存最近 30 筆、調整 DB 寫入設定（官方 10/16） | 早期瓶頸在存檔寫入量與尖峰登入 |
| 「補算離線進度」曾擋住交易、入隊、踢人、買攤位（官方 p6.33 修正） | 線上動作不該等待離線方補算完成 |

1. **離開期間報告的實際畫面**：兩次離開約 3 分鐘再進入，都只看到補算進度窗，沒有報告。前端程式的條件是「這台瀏覽器最後看到畫面的時間距今 ≥ 3 分鐘（`ec=18e4`）且有新事件」；使用者當時另開著遊戲畫面，最後看到的時間一直被更新，可能因此沒有觸發。報告內容只能依前端字串整理（§11.5）。
2. 聊天：頻道看到了（§11.1），但沒有發言，也沒有進南門聊天室、競技場。

### 11.1 主控台（「新版」介面）

- 上方一排分組頁籤：角色（人物、職業）／物品（背包、倉庫、商店、攤位、交易）／掛機（掛機設定、統計、查詢）／社群（隊伍、公會、全服 MVP、排行榜）／贊助、說明。
- 左上「戰鬥訊息」是主角；篩選：全部、戰鬥、技能、經驗值、掉寶、系統、警告。可關「自動捲動」，關掉時新訊息出現「▼ 有新訊息」。
- **每行戰鬥訊息都帶當下狀態**：`[HP 88% / SP 91%] 對 蟲蛹 造成 29 點傷害。（延遲 1288 毫秒）`。顏色：受傷紅、經驗黃、撿取綠、稀有掉落粉紅（`◆ 稀有掉落！蟲蛹 掉落了 鐵盾 [1]`）、Miss 灰、休息淺藍。
- **自動動作寫出觸發原因**：`HP 18% 低於 35%，使用 紅色藥水，HP +41。`、`HP 37%、SP 100%，坐下休息…`、`HP 90%、SP 100%，站起來繼續行動。`
- **死亡訊息**：`✖ 你死亡了：被 曼陀羅魔花 打倒（25 傷害），在 普隆德拉原野 02。` 接著 `角色死亡，已停止掛機（可在掛機設定開啟「死亡後自動恢復掛機」）`：停止的原因和解除的地方寫在同一處。
- 開始掛機時提醒：`尚有 48 點屬性點未分配，戰鬥力會明顯不足。`
- 戰鬥訊息下方有 OpenKore 風格的指令列，`help` 列出 `exp [report|monster|item|reset]`、`s`、`st`、`i [eq|u|etc]`、`eq`、`skills`、`weight`、`where`、`ml`、`ai`，每個都有中文別名（例如「經驗」「狀態」「背包」）。
- 聊天分頁：全部、一般、好友、組隊、公會、密語；「一般頻道是目前地圖的所有人」。
- 右欄：角色（形象、等級條、HP／SP、負重、Zeny、未分配點數紅字）→ 開始／停止掛機 → 地點與戰況（地圖、儲存點、全服擊殺波利進度條與剩餘時間、行動、目標與血條、目前增益）→ 統計（自歸零起）。底部狀態列：地圖、行動、連線狀態、南門聊天室、競技場、⚙、換角色。

### 11.2 掛機設定（簡易模式）

- 區塊依序：配置檔、掛機地圖、藥水與補給、道具設定、組隊行為、休息與撿取、逃生、選怪、鑑定、箭矢與魔力礦石、回城與負重、攻擊方式、掛機技能、切磋技能、自動配點、設定分享。每個區塊有 ? 說明，可全部展開／收合。
- 改動後頂部與底部都出現「有尚未套用的修改」，套用鈕固定在底部；Ctrl／⌘+S 也能套用。
- **配置檔範本**：省水練功、高效率打寶、安全掛機、指定怪物刷卡；配置存在伺服器，每角色 10 組。
- **地圖清單**依城鎮分組，顯示每張地圖的人數（總數與在線，例如原野 08「1916 人（36 在線）」），並寫明「人數不影響打怪：每個角色各自一個世界，不會被其他玩家搶怪」。選地圖後顯示一句地圖介紹（「新手冒險者的第一站，到處都是波利與瘋兔。」）、小地圖與怪物表（Lv、HP、屬性、種族、體型、行為、數量，Boss 標重生時間）。另寫明 Boss 重生「每隻角色各自計算，同隊在同一張地圖的隊員共用」。
- **逃生觸發條件**：交戰中 HP 低於、被圍攻 N 隻以上、偵測到危險怪、連續 N 秒找不到目標、交戰中 SP 低於、一次受到 N 點以上傷害、對同一隻怪連續 N 次打不中；每項各選不處理／蒼蠅翅膀／蝴蝶翅膀。

- **判斷順序明文寫出**：逃生 → 回復 → 坐下 → 輔助 → 攻擊（依清單順序）→ 普通攻擊。
- **設定分享**：熱門／最新／我分享的，可依職業與 Base Lv 篩選。每筆顯示「還在用 594・套用 1403・讚 14」；有風險的分享直接在列表標紅字警告（「會自動配點（屬性點加下去不能退回，只能找重置師）」「回城購買沒有設保留 Zeny 也沒有預算，可能把 Zeny 花光」）。熱門依「還在用」排序：近 7 天套用、超過一天還沒換掉的帳號數；分享者本人與同裝置的帳號不算。實際列表多是新手刷蟲蛹的設定。
