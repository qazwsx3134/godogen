# Echoes of Aincrad 參考研究：戰鬥呈現以外的 MMORPG 機制

日期：2026-10-24。用途：先決定《浮空劍域》的系統骨架，戰鬥畫面可稍後選擇 Hero Horde Idle、RO 式 2.5D 或文字／面板放置。本文依官方資料研究，沒有宣稱實際遊玩《Echoes of Aincrad》。

**主要結論：先設計「角色如何成長、世界如何開放、物品如何循環、隊伍與組織如何產生關係」，再決定這些結果要如何演出。** MMORPG 的世界感來自角色、資源、知識與社會關係的持續累積；不是必須一次做完公會、拍賣、住宅等所有常見功能。

## 1. 先分清三個參考層次

| 層次 | 能提供什麼 | 本次處理 |
|---|---|---|
| Echoes of Aincrad | 角色、武器養成、探索、據點整備、任務推進、AI 伙伴 | 官方確認後再作參考 |
| 真正的 MMORPG | 真人合作、社群組織、玩家交換與共享進度 | 用其他官方遊戲手冊補足機制類型 |
| 我們的新作 | 單機 AI 隊伍、永久死亡與傳承、放置化 | 獨立設計，不假裝是原作已有功能 |

《Echoes of Aincrad》官方產品頁列為單人 Action JRPG；官方攻略也說明它以任務推動區域開放，並非開放世界。不能把其故事中的 VRMMORPG 背景，當成產品真的提供大型真人線上世界。[官方產品頁](https://www.bandainamcoent.com/games/echoes-of-aincrad)、[官方攻略](https://www.bandainamcoent.com/news/echoes-of-aincrad-a-guide-to-aincrad)

使用者先前確認的單機＋AI、永久死亡＋部分傳承及 Web 桌機／手機橫向繼續有效。**HD 2.5D 目前改為候選畫面方向，不是已鎖定的開發前提。**

## 2. Echoes of Aincrad 已確認、值得借鏡的設計

### 2.1 成長分成不同軌道

官方入門指南區分角色升級取得成長點、武器使用經驗解鎖劍技、裝備本身的強化，以及由主線／發現城鎮推進的 Cardinal Rank。Rank 還會影響商店、製作選項、伙伴與部分世界難度。[官方入門指南](https://en.bandainamcoent.eu/sword-art-online/news/echoes-of-aincrad-starter-guide)

**設計分析：** 這些軌道回答不同問題：角色等級決定基礎能力，熟練度證明練過什麼，裝備成長提供配裝目標，探索階級開放世界。新作應分開保存與顯示，讓玩家不只追一個總戰力。

### 2.2 裝備有可留下的特效價值

官方說明武器可強化、合成、製作，EX-MOD 可提供不同特效並在同類武器間組合／轉移。單純取得較高階掉落，不保證立即比已整備的舊武器好。[官方系統解說](https://en.bandainamcoent.eu/sword-art-online/news/echoes-of-aincrad-gameplay-mechanics-explained)、[官方攻略](https://www.bandainamcoent.com/news/echoes-of-aincrad-a-guide-to-aincrad)

**設計分析：** 物品可以同時有基底能力、成長潛力、特效與素材用途。這會讓不直接穿上的掉落仍有價值。但若重抽、強化、轉移、融合同時推出，很容易把整理成本推得過高；新作先確立一條清楚的裝備循環。

### 2.3 探索與整備構成遠征節奏

官方資料描述安全區／傳送裝置揭示地圖資訊，探索可發現寶箱、特殊機關及捷徑；據點提供角色調整、商店與鍛造，再從任務終端選目標出發。[官方系統解說](https://en.bandainamcoent.eu/sword-art-online/news/echoes-of-aincrad-gameplay-mechanics-explained)、[官方攻略](https://www.bandainamcoent.com/news/echoes-of-aincrad-a-guide-to-aincrad)

**設計分析：** 回城可以是交付成果、接收情報、補給和換配置的有意義節點，而非只有走回商店。新作可保留這個節奏，但不必照搬所有調整都只能在城鎮進行的限制。

### 2.4 伙伴是配置與關係系統

官方有不同伙伴的支援／連攜能力與行動方針，出發前可以查看配置。這支持「同一角色配不同伙伴，形成不同隊伍」的設計。[官方系統解說](https://en.bandainamcoent.eu/sword-art-online/news/echoes-of-aincrad-gameplay-mechanics-explained)、[官方入門指南](https://en.bandainamcoent.eu/sword-art-online/news/echoes-of-aincrad-starter-guide)

本次資料不足以確認完整好感、婚姻或玩家公會系統，因此不把它們列為此作已證實功能。新作的伙伴信任／個人事件屬可另行設計的內容。

### 2.5 永久死亡是模式規則，不等於通用 MMO 規則

官方存檔指南將 Death Game Mode 作為獨立的存檔模式選擇，並指出試玩版轉入的存檔不能切換成該模式。[官方存檔指南](https://www.bandainamcoent.com/news/echoes-of-aincrad-save-data-transfer-guide)

新作採使用者選定的「角色死亡、帳號保留部分傳承」。這是我們自己的成長結構，不能宣稱是 Echoes of Aincrad 的原樣移植。

## 3. 一款有 MMORPG 感的遊戲，應檢視哪些機制

以下是**設計盤點與本作建議**，不代表每款 MMORPG 都必須具備全部功能，也不代表 Echoes of Aincrad 已有下表全部內容。

| ID | 系統 | 玩家在做什麼／得到什麼 | 需要定義的規則 |
|---|---|---|---|
| S01 | 角色身份 | 創角、命名、外觀、出身、稱號 | 角色檔與帳號檔分離、重建角色的保留範圍 |
| S02 | 角色成長 | 升級、配點、選流派 | 經驗曲線、屬性效用、重配、等級門檻 |
| S03 | 武器／技能熟練 | 練使用習慣、解鎖技能與配招 | 習得、熟練、技能格及特化互相獨立 |
| S04 | 探索與樓層 | 調查地圖、開營地、找捷徑 | 未知資訊、區域門檻、傳送、路線風險 |
| S05 | 任務與敘事 | 主線、支線、討伐、收集、個人事件 | 前置、追蹤、失敗、回報、重複及領獎 |
| S06 | 裝備與掉落 | 找適合配置的物品 | 品質、tier、特效、綁定、取得途徑 |
| S07 | 裝備加工 | 強化、拆解、製作、特效處理 | 消耗、成功率、保底、轉移限制與成長上限 |
| S08 | 背包與倉庫 | 整理、比較、鎖定、存放 | 物品實例、堆疊、任務物品、死亡掉失 |
| S09 | 生活技能 | 採集、製藥、鍛造等非戰鬥成長 | 採集點、熟練、配方、材料來源與市場用途 |
| S10 | 城鎮服務 | 商店、旅館、工坊、情報與招募 | 服務解鎖、補給、收購、任務終端 |
| S11 | 小隊與伙伴 | 分工、招募、配置、協作、建立關係 | 成員資格、角色定位、指令、成長與離隊 |
| S12 | 聊天與好友 | 找人、交流、保持聯繫 | 頻道、權限、私訊、封鎖、舉報與訊息保存 |
| S13 | 公會與組織 | 長期共同目標、歸屬、貢獻 | 職權、任務、倉庫、建設、加入退出 |
| S14 | 經濟與交易 | 買賣、訂單、定價、資源交換 | 貨幣來源／消耗、綁定、買回、交易成本 |
| S15 | 世界活動 | 區域事件、商隊、災害、攻略進度 | 觸發、參與、結束條件、影響與重置 |
| S16 | 副本與長期挑戰 | 重複攻略、材料目標、特殊挑戰 | 入場條件、獎勵、重玩理由、追趕機制 |
| S17 | 聲望與知識 | 解鎖配方、NPC 態度、情報 | 個人關係與組織認可分離、死亡後如何保留 |
| S18 | 收藏與身份表達 | 圖鑑、成就、稱號、外觀、居所 | 有用的里程碑、跨角色保留、可選支線 |
| S19 | 自動化與離線 | 選農點、補給、委託、回歸結算 | 可自動範圍、停機原因、離線上限與風險 |
| S20 | 持續資料與可用性 | 存檔、重返、回顧、理解進度 | 防重領、版本遷移、重連／恢復、新手引導 |

S12–S15 中涉及真人共同狀態的部分，需要真正的線上服務；AI 隊友與 NPC 商店可以提供單機對應玩法，但不能視為已完成真人社交或玩家市場。

## 4. 真正的 MMORPG 要額外解決什麼

官方 FFXIV 手冊提供招募隊伍、組隊條件、好友及郵件等實例；UI 手冊還列有公會、交流群、封鎖與顯示篩選。這些說明社會系統包含「找得到人、談得攏、能共同參與、遇到問題可處理」，不只是顯示玩家姓名。[組隊手冊](https://na.finalfantasyxiv.com/game_manual/pp/)、[社交介面手冊](https://na.finalfantasyxiv.com/game_manual/view/)

官方市場指南把 NPC 買賣與玩家市場分開，且具備搜尋、成交紀錄等支援；生活委託則涵蓋戰鬥、採集與製作。這是資源能在不同玩家活動間交換的機制參考。[市場指南](https://na.finalfantasyxiv.com/uiguide/item/)、[委託系統](https://na.finalfantasyxiv.com/a_realm_reborn/sp/system/contents/)

### 四個需要共同世界的核心問題

1. **合作如何形成**：職責互補、招募條件、成員資格、退出／替補與分配規則。
2. **物品如何交換**：市場、直接交易或訂單；可交易範圍、價格資訊與貨幣消耗。
3. **共同進度如何成立**：公會工程、區域事件、首通紀錄由誰參與、誰得獎、何時重置。
4. **持續身份如何維持**：好友、公會、聲望、長期承諾與可追溯的紀錄。

玩家數較少時，這些系統還要處理找不到隊伍、交易缺少對手方與新舊玩家落差。這是未來若做真人線上版時的設計工作，不納入目前單機首版。

FFXIV 的 Duty Support 也提供指定內容使用 NPC 隊伍的官方案例，說明「內容進行方式」與「真人社交」可以分開規劃；不代表 NPC 可以取代全部 MMO 社會關係。[Duty Support](https://na.finalfantasyxiv.com/game_manual/dutysupport/)

## 5. 建議新作的成長骨架

### 五條分開的成長

| 軌道 | 用途 | 對永久死亡的建議 |
|---|---|---|
| 當代角色等級／屬性 | 基礎生存與配置能力 | 重練 |
| 當代武器技能熟練 | 使用某流派的成果 | 重練；符合條件的知識可登錄手記 |
| 裝備與加工 | 將掉落轉成配置選擇 | 身上失去、倉庫保留 |
| 探索／冒險執照 | 開放區域與服務、證明探索進度 | 已登錄知識與營地保留 |
| 配方／收藏／組織認可 | 跨角色的選擇與世界記憶 | 保留；不要直接等同滿級戰力 |

「冒險執照」是本作提案，不沿用 Cardinal Rank 名稱或假定公式。建議以首次發現、主線、營地與守層者里程碑推進，**不因反覆刷相同怪就無限升階**。

不建議直接照搬所有敵人隨總階級變強：若舊區也同步膨脹，可能削弱回頭農素材與感受成長的意義。首版用明確的區域 tier 與推薦條件，特殊挑戰再另設難度。

### 一次遠征應有完整目的

```text
看到目標 → 查來源／危險 → 接任務與配置隊伍
                              ↓
                        探索／採集／狩獵
                              ↓
                    帶成果回城 → 加工／登錄／存放
                              ↓
                    解鎖新能力、服務、路線與挑戰
```

這條循環可以由 3D 場景、2.5D 或面板呈現，對非戰鬥系統的資料需求一致。

## 6. 讓農怪以外的機制真的有用途

### 任務不能全部只換怪名

主線開放世界、流派任務教配置、支線建立人物與配方、討伐提供可重複材料目標、採集委託消耗生活產出、伙伴任務表現個性。獎勵也應分成金幣、能力、配方、路線、情報與關係，不全都只發 EXP。

追蹤應說明任務物品來源、目前缺量與下一步；收集／提交是分開狀態。涉及重要選擇及消耗稀有品時，不做無提示自動回報。

### 採集、製作與經濟要接起來

```text
採集／掉落 → 普通材料 ─┬→ 藥品／食物 → 遠征消耗
                       ├→ 裝備／強化 → 配置成長
                       └→ 委託／出售 → 金幣
                                          ↓
                              補給、加工、招募與服務
```

先建採集、鍛造、製藥三條簡單路徑即可，不必一開始把釣魚、裁縫、烹飪全部做成獨立職業。首版的材料要至少有一個明確用途；既不能全部只能賣，也不能全部永遠不值得賣。

### 掉落應同時有短期與長期價值

建議順序：比較與鎖定 → 定向強化 → 拆解回收 → 配方製作 → 特效轉移。隨機重抽、套裝、插槽、複雜融合留到前面的資源循環成立後。

每項系統都要回答：消耗什麼、改善什麼、失敗損失什麼、何時不值得再投資。新作 v0 的強化失敗不毀裝是既有設計，不因參考 EOA 而自動更改。

### NPC 與公會感

單機可先做「冒險者協會」：執照、委託板、捐料工程、工坊解鎖與 NPC 攻略隊的事件。資料清楚標示 NPC 隊伍，世界事件有確定狀態，不假造真人在線數或玩家聊天。

可擴充伙伴信任、個人事件與導師手記；這些是新作提案，沒有宣稱 EOA 的官方資料已證實相同系統。

## 7. 永久死亡如何影響這些系統

| 類型 | 應保存在哪裡 | 死亡後 |
|---|---|---|
| 等級、屬性配置、個人技能熟練、當代隊伍與隨身物 | Character／Run | 結束或失去 |
| 倉庫、已登錄配方、探索圖鑑、執照、營地、傳承手記 | Profile | 保留 |
| 當代對某伙伴的信任 | Relationship／Run | 結束；事件可留回顧 |
| 組織認可與城鎮工程 | World／Profile | 已提交成果保留 |
| 正在做的任務與未領獎 | QuestInstance／Run | 不變成下一代可直接重領的資產 |
| 死亡與重要選擇 | Journal／Grave | 保留可回顧紀錄 |

因此，「聲望」「好感」「進度」不能只用一個數字；系統必須知道它屬於哪一代、誰給予、靠什麼提升及死亡時怎麼處理。

## 8. 新作的採用順序

### 第一層就需要的核心

角色與三條當代成長、區域／營地、任務、裝備比較／鎖定、補給、商店／工坊、AI 小隊、倉庫、死亡傳承、存檔及回顧。原有單層循環先驗證，不擴成所有 MMO 功能一起開發。

### 建議接著加入的世界感

冒險執照、採集／製藥／鍛造、配方來源、情報圖鑑、伙伴個人事件、協會委託與一種區域事件。這是此次分析提出的候選擴充，還不是全部承諾納入首版。

### 明確留到其他階段

真人聊天／好友、公會管理、玩家交易／拍賣及全服攻略屬線上版範圍；住宅、坐騎、寵物、婚姻、PvP 與領地戰則是可選內容。未做這些，不代表目前單機的核心循環不完整。

## 9. 與戰鬥畫面的關係

先定義「出發請求」與「遠征結果」：區域、隊伍、配置、方針、消耗、角色傷亡、EXP、熟練度、物品、任務與世界狀態變更。保存、加工、任務及經濟系統可先基於這些事件製作。

未來若選擇手動走位／格擋的動作玩法，會改變戰鬥規則與輸入，不只是換一個 renderer。因此本輪暫緩的是戰鬥呈現及具體操作模型；沒有宣稱三種玩法可零成本互換。

**建議下一步：先用簡單的遠征結算模擬器，驗證「任務 → 成長 → 物品加工 → 下一目標 → 死亡傳承」能否持續成立，再投入戰鬥畫面。**
