# Melee 近戰敵機

依 `melee.png` 製作的低面數八足機體，特徵是前方雙側長刃、背部長方形艙體、藍白裝甲與尾部脊片。

- `melee.glb`：1,458 三角面，單一蒙皮網格／材質、19 根骨頭。`walk` 和 `idle` 循環，`attack` 為約 0.67 秒的雙刃揮擊。
- `melee.blend`：包含骨架、動畫與已打包貼圖的可編輯來源。
- `render_check.png`、`render_motion.png`：匯出 GLB 的多視角及動作預覽。
- `L_Blade`／`R_Blade` 是刀刃骨頭；動作只處理視覺，不包含攻擊判定。

造型有意簡化：省略小螺栓、複雜關節和表面接縫；刀刃、艙體與腳的比例為參考圖無尺寸時的估算。重建、效能與驗證方式見[共用說明](../README.md)。
