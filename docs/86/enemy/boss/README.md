# Boss 敵機（製作中）

參考 `boss-threeview.png` 和 `../../boss.jpg` 建立 40 m 長的敵機。機頭、前槍與外圈尖刺、中央環形甲板／砲口、雙尾分節和尾端箭形裝甲是主要辨識特徵。

| 項目 | 製作基準 |
|---|---|
| 全長 | 約 40 m，含前槍與雙尾 |
| 原點／朝向 | 最低點為地面；Blender 機頭 -Y，Godot 機頭 +Z |
| 模型面數 | 初始預算約 6,000–10,000 三角面；依實際輪廓調整 |
| 貼圖 | 初版 1024 色彩圖集、512 金屬／粗糙度圖，遠距離使用 |
| 執行時 | 優先單一網格與材質；可編輯來源保留零件 |

圖中的「右側」帶有透視角度，與正／背視的投影並不完全一致；厚度、俯視輪廓及尾部升角依三張圖和原始參考推定。尚未製作動畫、碰撞或遊戲接入。
