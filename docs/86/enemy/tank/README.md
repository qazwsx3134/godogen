# Tank 坦克型敵機

依 `tank.png` 製作的低面數八足重砲機，特徵是前伸的單管長砲、寬肩裝甲和背部散熱片。

- `tank.glb`：1,324 三角面，單一蒙皮網格／材質、19 根骨頭。`walk` 和 `idle` 循環，`fire` 為約 0.4 秒的砲管後座。
- `tank.blend`：包含骨架、動畫與已打包貼圖的可編輯來源。
- `render_check.png`、`render_motion.png`：匯出 GLB 的多視角及動作預覽。
- `Turret`／`Cannon` 是砲塔與砲管骨頭；模型不包含發射點、彈體或碰撞判定。

造型有意簡化：省略細小螺栓、管線及多數面板接縫；砲管、機身與腳的比例為參考圖無尺寸時的估算。重建、效能與驗證方式見[共用說明](../README.md)。
