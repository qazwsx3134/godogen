使用者 2026-10-20 寫的五幕劇本（[prototypes/luffy-marineford/TODO.md](../../prototypes/luffy-marineford/TODO.md)）拆成可動工的清單。劇本的先後以使用者為準；和原作不同的地方照設計文件慣例標「**改編**」，沒核實的標「**待查證**」。

> 五幕對應設計文件 v1.2 的 C5～C7（馬林福特篇）。使用者 2026-10-20 的決定見文末「已決定」。

   ↓

  〔斯摩格戰：撐住〕→ 漢考克救下、給鑰匙 → toast 白鬍子參戰

〔 〕＝玩家操作的遊戲段；其餘是過場或遊戲中的事件。

## 共同規則（沿用 v1.2）

- 劇情事件**抵達路點**才觸發，不用倒數。
- 必敗只放在短過場：黃猿踢飛、金色拳頭、赤犬。遊戲段裡 HP 0 一律是失敗、重試。
- 打不贏的對手（斯摩格、卡普）不做成「打倒」，做成「撐住／打中幾下就進過場」。
- 遊戲段畫面上的同伴最多 2 名，其餘的人只在過場出現。

### 每一項都要遵守

- 新畫面、特效、過場都是產生器存檔的 `.tscn`，登記在原型 README 的場景表。
- **新 shader 與材質都加進網頁預熱清單**（`main.gd` 的 `_begin_warm_up`），否則第一次出現時會卡 60～90 ms。
- 每幕做完重量網頁 p95（250 隻＋同伴＋群戰背景）。
