# 《異獸髮廊》(Beastfolk Barber) 試玩版 — 元素與 UI 版面研究

來源：Steam 試玩版 v0.1.25r34（朋友開發），2026-10-24 在 1920×1080 全螢幕實機操作並截圖。
截圖放在 `shots/`，僅供內部參考，不要提交到公開 repo。
範圍：主選單、設定、開場旁白、對話、教學、選髮型與預覽、歷史紀錄、暫停選單。
第二輪補充：剪髮拖曳、解圍布拖曳、第二位客人（雙頭）的分頁與記憶標記。
**未涉及**：結算畫面、存檔／讀檔、手把操作、燈號面板的確切意義、記憶標記是否可手動拖放。

## 1. 遊戲核心

像素風視覺小說＋推理。玩家是髮型師助理菲迪，客人嘴上說的需求不等於真正的喜好。

```
聽需求 → 選前髮＋後髮 → 預覽(剩 3 次) → 看客人表情與反應 → 判斷喜不喜歡 → 剪
   ↑                                    │
   └──────────── 次數用完前反覆試 ──────┘
```

| 元素 | 做法 |
|---|---|
| 推理線索 | 客人的**表情立繪**（閉眼微笑＝喜歡、皺眉＝不喜歡）加上對白 |
| 資源限制 | 每位客人只能預覽 3 次，顯示成手持遙控器上的「剩餘次數」 |
| 預覽的包裝 | 「小潔的想法投影鏡」：預覽是半透明疊影，確認後才變實體 |
| 選擇空間 | 前髮 3 × 後髮 3，兩排獨立選，組合出 9 種 |
| 敘事 | 預覽結果由角色用對白說出，不用數值條，情緒由台詞和表情承載 |
| 世界觀 | 獸人客人、髮廊日常；教學用吉祥物老鼠「小潔」講，語氣輕鬆 |

### 2.2 設定面板 `shots/02-settings.png`

- 置中深咖啡底板，約 810×820 px，圓角＋像素邊。
- 上方音量區用橘色細框圍起三條滑桿（全音量／配樂／音效）；標籤靠左、滑桿靠右。
- 勾選項兩個並排（全螢幕、文字特效，後者旁邊有 `[?]` 小說明）。
- 解析度、語言用「◀ 值 ▶」左右箭頭切換，不用下拉選單。
- 底部按鈕：主選單是單顆「關閉」；遊戲中是「返回遊戲」＋「回到標題」雙按鈕（`shots/10-pause-menu.png`）。同一個面板兩種情境重用。

### 2.3 對話畫面（核心）`shots/03`、`shots/04`、`shots/11`

```
┌────────────────────────────────────────────────────────────┐
│ ☰  💬  ▶                                 (左上三顆圖示鈕)    │
│ ┌────────────┐                                              │
│ │菲迪(金色)  ◣│         角色立繪（置中，鏡中場景）            │
│ │ 對白…      │                                              │
│ └────────────┘                          ┌─說話者在右時─┐     │
│                                         │ 泡泡移到右側 │     │
│                                         └──────────────┘     │
│   鏡子框、植物、瓶罐 = 背景與前景同一張場景                   │
└────────────────────────────────────────────────────────────┘
```

- **沒有底部對話框。** 用漫畫式泡泡，位置跟著說話者變：說話者在畫面外就貼畫面邊緣、尾巴指向邊外。
- 泡泡底色近黑咖啡（約 `#1F140E`）、白字；**名字用角色專屬色**（菲迪金黃、尼拉亮藍），在泡泡內左上。
- 泡泡尺寸**隨文字長度縮放**（「好的。」是小泡泡，兩行長句是大泡泡），不是固定尺寸。
- 泡泡形狀表情緒：平常是切角方形，**喊叫／驚呼是鋸齒爆炸形**（`shots/03`，`shots/08` 後段）。
- 打字機逐字出現，字從暗到亮淡入（設定裡的「文字特效」）。
- 點擊繼續的提示是**像素十字游標**，貼在泡泡右下，不另放「▼」。
- 左上三顆工具鈕（選單／歷史紀錄／自動播放）：深咖啡方塊、約 84 px、圓角，間距 16 px，**圖示只有線稿**，無文字。
- 鏡頭語言：開場是全身遠景，後來**拉近成特寫**（`shots/04`），同一面鏡子框貫穿，背景模糊的第二人物（菲迪映在鏡中）用半透明表示。

### 2.4 教學「書」`shots/05`

- 左側整面是**羊皮紙攤開的書**（約 780×1000），右側場景仍可見。
- 每頁：上方 2–4 行粗體手寫風字，下方一張像素吉祥物插圖（老鼠「小潔」）。
- 翻頁用左右橘色三角箭頭；最後一頁換成「關閉」按鈕。
- 順序：需求 → 想法 → 客人可能不喜歡 → 想法投影鏡 → 預覽能看反應 → **限制只有 3 次**。每頁只講一件事。
- 限制那頁直接展示**會出現在 HUD 裡的遙控器**，教學圖和實際 UI 一致。

### 2.5 選髮型畫面 `shots/06`、`shots/07`

```
┌───────────── 左 50% ─────────────┬──────────── 右 50% ───────────┐
│  客人特寫（半透明想法髮型疊在頭上）│ ┌─ 想法泡泡(咖啡) ─┐            │
│                                  │ │菲迪的內心獨白…  │            │
│                                  │ └─────────────────┘            │
│                                  │ ┌─ 暗橄欖綠面板 ───┐            │
│                                  │ │(圓章)前髮 ▢ ▢ ▢ │            │
│                                  │ │ ─────────────── │            │
│                                  │ │(圓章)後髮 ▢ ▢ ▢ │            │
│                                  │ └─────────────────┘            │
│                                  │  📟剩餘3   [ 預覽 ]            │
└──────────────────────────────────┴────────────────────────────────┘
```

- **左右各半**：左邊維持場景＋角色，右邊整塊換成暗橄欖綠面板，是這個遊戲裡唯一的「選單式」畫面。
- 右面板由上到下：想法泡泡（提示線索，咖啡色）→ 選項面板 → 預覽按鈕列。
- 選項：每排左邊是圓形章（前髮／後髮的頭像小圖＋標籤字），右邊 3 顆奶油色方磚（約 140×140，間距約 50）；磚上畫迷你獸人頭像，**頭髮輪廓就是圖示**，沒有文字。
- 狀態：未選＝奶油色；選中＝**橄欖綠反白**；整個面板在兩排都選前，預覽鈕不出現。
- 選取立刻在左邊客人頭上以半透明疊影顯示，不用按確認。
- **預覽鈕與次數**：兩排都選好才出現，位於面板外右下；旁邊的手持遙控器顯示剩餘次數，次數用完前後都不換位置。
- 預覽時（`shots/08`）：右面板整個收起、回到全幅鏡子，結果用對白與表情揭曉，之後面板再回來。

### 2.6 歷史紀錄 `shots/09`

- **做成聊天軟體**：客人在左（圓形頭像＋藍色名字＋奶油氣泡），玩家／菲迪在右對齊，無頭像。
- 大面板約 1170×820 置中，深咖啡底；右側是自訂捲軸（奶油軌道＋橘色滑塊）；右上角橘底白 X 關閉。
- 背景保留遊戲畫面但壓暗，**還看得到剩餘次數**，所以不遮住關鍵 HUD。
- 氣泡寬度隨文字，最大寬度約面板 60%。

### 2.7 暫停選單 `shots/10`

- 就是設定面板，底部多「返回遊戲」「回到標題」，沒有存檔、讀檔、圖鑑入口（試玩版）。

### 2.8 剪髮與解圍布：拖曳小遊戲 `shots/12`、`shots/14`

- 預覽用完後（見 2.5 的客人台詞「我想要用完」），**直接進入剪髮**，我沒有看到「確定剪」按鈕；是否有手動確認未驗證。
- 剪髮、解圍布各是**一個單動作拖曳**：畫面上出現操作提示卡，標題「沿箭頭拖曳」，卡片內是**循環播放的動畫示範**（剪刀開合、雙手拉蝴蝶結），箭頭尾端有橘色圓點。
- 提示卡位置會換：剪髮時在左側（約 500×500），解圍布時在右下，**避開要操作的部位**。
- 我兩次拖曳都成功，但起點不同（一次在頭髮上、一次在提示卡的橘點上），**判定區域未釐清**。
- 小遊戲期間左上「歷史紀錄」鈕**變灰不可用**，選單與自動播放仍亮。
- 演出：拖完後鏡頭平移，客人移到畫面一側，泡泡改放另一側；之後解圍布、客人眼睛發亮。

### 2.9 雙頭客人：分頁＋記憶標記 `shots/15`、`shots/16`

```
┌ 頂部教學字(聚光燈時) ────────────────────── 1  2  3 ┐
│                                    ┌─想法泡泡──────┐ │
│  客人特寫(兩顆頭)                  └───────────────┘ │
│                                    ┌盧卡┐┌瓦羅┐        │
│                                    │前髮 ▢ ▢ ▢ │ ← 面板色跟分頁 │
│                                    │後髮 ▢ ▢ ▢ │        │
│                                    📟剩餘 [預覽]        │
└──────────────────────────────────────────────────────┘
```

- **每顆頭一個分頁**：盧卡（米色面板）、瓦羅（藍色面板）。**分頁色＝該角色的名字色**，面板底色跟著換，視覺上不會搞錯目前在改誰。
- 每個分頁各有一組前髮／後髮（各 3 選項），選項磚上的頭像換成對應那顆頭的樣子。
- **記憶標記**：頂端右上有「1 2 3」三個數字；磚塊左上角會出現同樣的數字，記錄**第幾次預覽選過這個選項**。這是為了解決「兩顆頭要記住每次預覽了什麼」，由想法泡泡直接點明（「一次要處理兩顆頭，得好好記住每次預覽了什麼才行」）。
- **聚光燈教學**：第二位客人第一次出現新功能時，整個畫面壓暗，只亮起要講的區塊，加一個箭頭指向它；頂部用白字說明，右側 ▶ 翻下一步。
- 教學期間示範了自動預覽，並**自動替我標好 1**，然後交還控制。
- 瓦羅的磚塊：頭像是黑短髮龍人，選中仍是橄欖綠反白；盧卡的磚塊是金髮龍頭像。

### 2.10 更多泡泡形狀與名字色 `shots/15`、`shots/17`

| 形狀 | 用途 |
|---|---|
| 切角方形（預設） | 一般對白 |
| 鋸齒爆炸形，尾巴像閃電 | 喊叫、驚呼 |
| **波浪邊＋小汗滴** | 尷尬、不悅、討厭（盧卡「你讓我開始討厭它了」） |

- 道具細節：瓦羅那一場桌上多了手機；鏡中背景裡始終有半透明的菲迪。

## 3. 視覺語言

| 項目 | 觀察 |
|---|---|
| 色票 | 暖橘／焦糖／奶油為主，輔以深咖啡（泡泡、面板）與橄欖綠（選取、選項面板） |
| 圖形 | 全像素；UI 邊緣是像素階梯圓角，非向量平滑圓角 |
| 字型 | 粗圓黑體，標題用手寫圓粗體；中文字體很粗，小字也清楚 |
| 圖示 | 只用線稿，無文字；功能靠教學頁和慣例認得 |
| 分區 | **用背景色塊分區**（咖啡／橄欖綠），不用框線 |
| 層次 | 場景 → 角色 → 泡泡 → 工具鈕；泡泡是最亮的對比，吸引視線 |

## 4. 值得借的設計（對「對話型」遊戲）

1. **泡泡跟著說話者走**，不是固定在底部：說話者與畫面外的區別一眼可見，也省掉側邊名牌。
2. **泡泡形狀＝情緒**：平靜／喊叫是兩個形狀，不用特效就傳達語氣。
3. **泡泡隨字長縮放**，短句不留空白。
4. **歷史紀錄做成聊天**，把「回看對話」包成角色世界裡的東西；頭像＋名字＋左右對齊，閱讀成本低。
5. **玩法 UI 隱藏到只剩必要**：預覽鈕要兩排都選好才出現；選單式畫面與敘事畫面左右分半，不切換整個場景。
6. **資源限制用實物表示**（手持遙控器），而且教學頁先展示同一個物件。
7. **教學是角色在講**（吉祥物＋書頁），每頁一件事，最後給「關閉」。
8. **同一個面板兩種情境**（設定／暫停），只換底部按鈕。
9. **「不能按」＝變灰但保留位置**（繼續遊戲、預覽），版面不跳。
10. **鏡頭拉近／拉遠**取代場景切換，同一個鏡框貫穿全程。
11. **聚光燈教學**：壓暗整個畫面、只亮要講的區塊，新功能第一次出現才教，並由遊戲替玩家示範一次再交還。
12. **同一元件的多實例用「分頁色」區分**：分頁色＝角色名字色＝面板底色，不需要額外標籤。
13. **互動提示卡是循環動畫**，位置避開操作區，標題一句話（「沿箭頭拖曳」）。
14. **小遊戲期間停用不相關按鈕**（歷史紀錄變灰），而不是整排隱藏。

## 5. 對 debt-commission 的取捨

`prototypes/debt-commission` 的介面基準是「銀魂和紙」（`AGENTS.md`），**不要換風格**，只借結構。

| 可借 | 對應 debt-commission | 建議 |
|---|---|---|
| 泡泡位置跟說話者 | `dialogue_box_gintama.tscn` 目前是固定底部框 | 先評估吐槽回合是否要「近臉泡泡」，保留底部框當預設 |
| 泡泡形狀＝情緒 | 吐槽、驚訝、爆氣 | 用和紙裁切的不同輪廓，**不要手繪新框**，沿用整張透明 PNG 的規則 |
| 歷史紀錄做成聊天 | 已有 reading／backlog？ | 先查現有 `gintama_reading_*.tscn` 有沒有；沒有再做 |
| 限制用實物表示 | 吐槽次數、扣分機會 | 用和紙風小道具（令牌、印章），不是純數字 |
| 面板左右各半 | 調查／選項回合 | 選項不遮角色臉時才用 |

**別借**：像素邊框、橄欖綠底色、鋸齒爆炸泡泡的具體造型（這些是他們的風格）。

## 6. 開放問題

- 剪髮前是否有手動「確定」？（我兩位客人都是預覽用完後自動進入剪髮）
- 結算畫面長什麼樣、怎麼計分？（進到剪髮演出為止）
- 記憶標記能不能手動拖放？我拖「2」的那次，遊戲正好進入下一段演出，沒有觀察到結果。
- 剪髮拖曳的判定區域。
- 鏡子旁的燈號面板（右側一排彩色小方塊）是剩餘次數、客人好感還是純裝飾？預覽前後亮的格數有變，但沒驗證規則。
- 手把操作與觸控版面（選項磚大小是否適合手指）。
- 存檔機制與「繼續遊戲」的行為（我開了新遊戲，這台機器上已建立試玩版存檔）。

> 方法備註：全程用 Windows-MCP 操作，點擊與截圖；只動了新遊戲流程與預覽，沒有改設定。
