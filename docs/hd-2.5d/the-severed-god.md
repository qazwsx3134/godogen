我認為它值得研究的地方，是它把多種玩家熟悉的系統整合起來，並透過「攻擊敵人的不同部位」形成自己的辨識度。

2. 最值得分析的戰鬥系統：Break & Sever







steamcommunity.com


傳統 JRPG 的策略通常是：
找到弱點 → 造成更多傷害 → 擊殺敵人。

但《The Severed Gods》在這個過程增加了額外的戰術維度。

敵人部位分成 Low、Mid、High 三種高度，各有自己的防禦與弱點。玩家能先破壞防禦使敵人倒下，再進一步切斷特定部位，使敵人永久失去部分戰鬥能力。

玩家得到的是戰術優勢，而不只是更高傷害。
此為設計原理示意，不代表每種敵人都有相同部位與破壞結果。
這個設計的厲害之處，是讓玩家實際改變敵人的狀態。

例如玩家可以考慮：先破壞腿讓敵人倒下、趁機攻擊原本難以觸及的頭部，還是先砍斷具有威脅性的攻擊部位？

一場 BOSS 戰因此從單純的數值競賽，變成有階段變化的戰術解題。

我的設計評價是：這比單純增加更多技能、更多職業，更容易形成讓玩家記住的遊戲特色。
3. Roguelite 的核心循環：讓每一次失敗都有意義

成功的 Roguelite 需要同時提供兩種不同的成長：
- Run Progression（局內成長）： 這一局因為獲得新技能、遺物和夥伴，逐漸變強。
- Meta Progression（局外成長）： 即使失敗，下一局仍能帶著新的解鎖內容重新挑戰。
真正讓玩家上癮的，不只是永久數值增加，而是每一局都能嘗試新的策略。

例如本輪主打高頻率攻擊，下一輪可能想嘗試破防控制，或依靠特定遺物形成特殊流派。

不過這也帶來一個風險：如果遊戲初期過度依賴永久數值成長，玩家會覺得自己不是因為策略失敗，而是因為刷得不夠久。

4. 美術與畫面：為什麼它特別有吸引力？









像素角色與細緻環境
以小型角色呈現戰鬥，讓場景與巨型敵人的尺度感更加突出。









光影與技能特效
利用粒子、光暈與明暗反差，讓像素美術產生更豐富的視覺層次。

它的視覺語言讓我想到 Octopath Traveler（歧路旅人），但不是只有像素角色這麼簡單。

我會把它拆成四層：
視覺層	使用的設計手法
角色	像素 Sprite、明確的角色輪廓
場景	具有立體層次的環境與地形
氛圍	景深、光暈、霧氣與環境光
戰鬥	高亮度技能特效、衝擊感、敵人狀態變化
這些是根據遊戲畫面歸納的視覺手法，不代表已確認其底層引擎或 Shader 實作。

這款遊戲提供的啟示，是獨立開發者不一定需要高成本的 3D 角色模型，也能營造有深度的場景。

像素 Sprite 可以降低部分角色製作成本，但燈光、特效、動畫、相機與場景層次仍然需要認真打磨。

5. Karma 系統：讓遊戲不只有戰鬥







steamcommunity.com


這是我認為可能被玩家低估的一項設計。

遊戲中，部分隨機事件會讓玩家在美德（Virtue）與罪惡（Sin）之間選擇。

例如面對一座墳墓，玩家可能可以偷取供品獲得資源，也可以獻上遺物換取美德。善惡選擇影響後續收益與角色發展。

Steam 商店
+1




這裡包含一個重要的設計原則：

選擇的價值，不在選項有多少，而在於每個選項是否有真正的代價。

如果偷取物品只有收益，卻沒有值得在意的後果，就不能形成真正的道德抉擇。

理想上，Karma 可以同時影響戰鬥能力、NPC 關係、事件分支，甚至結局。不過，目前遊戲仍在搶先體驗階段，官方也明確將完整的 Karma 系統列為後續開發目標，不能把未來規劃全部視為現有功能。

其中有一條批評，我覺得對遊戲設計者尤其重要。

好的戰術遊戲可以很難，但需要讓玩家有機會預判、準備或採用替代策略。

7. 如果從你的 Godot 遊戲開發方向借鏡
考慮到你之前規劃過手機直立式的 2D 冒險、文字 RPG 與倖存者遊戲，我不建議直接複製《The Severed Gods》的所有功能。

我會優先研究以下幾項：

第一優先：場景視覺層次

使用 Sprite2D、Parallax2D、CanvasItem Shader、PointLight2D 與粒子效果，嘗試營造有景深的像素場景。這很適合你想呈現的動畫世界與景色。




第二優先：戰鬥的可視化回饋

即使是即時動作遊戲，也可以借鏡破甲、弱點、擊倒與部位破壞的概念，讓玩家不只看到傷害數字，還能看到敵人的狀態改變。




第三優先：有代價的劇情選擇

在文字冒險與視覺小說中引入 NPC 關係、事件條件與選擇後果，讓玩家的決策影響後續故事，而不只是切換對話。
